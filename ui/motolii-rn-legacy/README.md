# Frozen legacy RN shell

This tree is retained only as historical implementation evidence and is read-only.
The current RN product source, app, and build target are all under `ui/motolii-rn/`.
Its archived package, workspace, scheme, and app identity use `MotoliiRnLegacy` so they cannot be mistaken for the product.
Do not install, build, edit, or copy product code from this directory unless the user explicitly unfreezes this exact path.
