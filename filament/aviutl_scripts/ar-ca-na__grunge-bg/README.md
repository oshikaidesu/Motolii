# グランジ背景

AviUtl ExEdit2 用のカスタムオブジェクトです。くしゃくしゃの紙・グランジ・汚れの背景を、画像素材なしでその場で生成します。GPU（ピクセルシェーダー）で描くので、シードを変えれば何枚でも別の絵が出ます。

![サンプル](https://raw.githubusercontent.com/ar-ca-na/aviutl2-grunge-bg/main/sample.png)

左上=くしゃくしゃ紙 / 右上=グランジ(ブロック) / 左下=グランジ(布) / 右下=汚れ(白黒)

## 動作環境

AviUtl ExEdit2 2.1.8 で確認しています。

## 導入

1. zip を展開して `グランジ背景.obj2` を `C:\ProgramData\aviutl2\Script\` に置く
2. AviUtl2 を起動すると「スクリプト・プラグインの追加」の確認が出るので、「このプラグイン・スクリプトを信頼して使用する」を押す
3. オブジェクト追加メニューの「グランジ背景」から置く

## 種類

| 種類 | 見た目 | 既定の色 |
|---|---|---|
| くしゃくしゃ紙 | 白い紙の細かい折り目。明暗は控えめ | 白 |
| グランジ(ブロック) | 灰色の地に四角い黒い塊・煙・黒い飛沫・白い引っかき傷 | 灰・黒 |
| グランジ(布) | 布目のある地に、横に擦れた濃色の汚れとさび色。下ほど暗い | 茶灰・紺・さび |
| 汚れ(白黒) | ぎざぎざの黒い地、反転する飛沫、束になった長い傷 | 白・黒 |

## 項目

| 項目 | 内容 |
|---|---|
| 種類 | 上の 4 つ。使わない項目は自動で隠れます |
| 幅 / 高さ | 出力する大きさ。0 なら画面（シーン）と同じ |
| 地の色 / 汚れの色 / 差し色 | 「なし」のままなら種類ごとの色で描きます |
| 透過 | しない / 明るい所を透過 / 暗い所を透過。汚れや陰だけを別の絵に乗せたいときに使います |
| 模様の大きさ[%] | 模様全体の拡大縮小 |
| 汚れ[%] | しみ・黒い塊・黒い面積など、その種類の主役になる汚れの量 |
| しわ・布目[%] | 紙の折り目の強さ、布の織り目の強さ |
| 飛び散り[%] | 丸い飛沫と細かい斑点 |
| 傷[%] | 引っかき傷の量 |
| ざらつき[%] | 粒子。白黒では細かいそばかすになります |
| ふちの暗さ[%] | 画面の端の焼け。布では下側の暗さ |
| 光の向き | くしゃくしゃ紙の光の方向（度） |
| コマ打ち[fps] | 0 で止まった絵。8〜12 にすると手描き風に絵ごと描き替わります |
| シード | 別の絵にする |

% の項目は **100 がその種類の標準**です。種類を切り替えても、既定値のままでサンプルの見た目になります。

## 使い方のこつ

- 文字の後ろに敷くときは、いちばん下のレイヤーに置いて「幅・高さ」を 0 のままにします。
- 手持ちの背景や写真に質感だけ足したいときは、「透過」を *明るい所を透過* にして上のレイヤーに重ねます。
- 「汚れ(白黒)」は、そのまま背景にするほか、透過と合成モードでマスク代わりにも使えます。

## 重さ

1920x1080 で 1 フレームあたり 17〜45ms（GPU による）。くしゃくしゃ紙がいちばん重く、種類によって変わります。置いた直後はシェーダーのコンパイルで数秒かかります。
