# 実機デバッグ手順

対象はAviUtl ExEdit2 2.1.5以上用「吹き出し背景@テキスト」v1.2.1です。普段の編集プロジェクトではなく、必ず新規プロジェクトまたは複製した検証用プロジェクトで確認してください。

## 0. 準備

1. 作業中のプロジェクトを保存します。
2. AviUtl ExEdit2をいったん終了し、再起動します。
3. 次の導入済みファイルがあることを確認します。

   ```text
   C:\ProgramData\aviutl2\Script\NatuNeko\吹き出し背景@テキスト.anm2
   ```

4. 旧所有ファイル`C:\ProgramData\aviutl2\Script\NNeko\吹き出し背景@テキスト.anm2`が削除され、旧`NNeko`内の他製品ファイルが残っていることを確認します。
5. さらに古い`C:\ProgramData\aviutl2\Script\TextBackgroundBalloon\テキスト背景・吹き出し.anm2`が存在しないことを確認します。
6. 新しい相対パスに対する信頼確認を行います。旧`module.ini`の信頼設定は複製しません。
7. 検証専用の新規プロジェクトを作ります。
8. エラーが出た場合に備え、画面全体を撮れる状態にします。

## 1. 最初の表示確認

1. タイムラインへ通常のテキストオブジェクトを追加します。
2. 文字列を`テスト字幕`、文字色を白にします。
3. テキストへアニメーション効果を追加します。
4. 新規環境ではカテゴリ「NatuNeko」から「吹き出し背景@テキスト」を選びます。既存環境で旧「NNeko」に残る場合は、「設定」→「オブジェクト追加メニューの設定」で対象のラベルを`NatuNeko`へ変更します。
5. 初期状態で、文字の背面に濃いグレーの角丸背景と下向きのしっぽが表示されることを確認します。
6. 初期値が`横余白 24`、`縦余白 16`、`背景色 #202020`、`背景透明度 20`、`角丸 16`、`オフセットX/Y 0`、`しっぽの向き 下`、`しっぽの位置 割合`、`割合位置 50`、`固定距離 50`、`しっぽの幅 72`、`しっぽの高さ 48`、`しっぽ角丸 16`、`先端オフセットX/Y 0`であることを確認します。`固定距離`は初期状態では非表示です。
7. 文字を変更すると、背景の横幅と縦幅が自動で追従することを確認します。

期待結果: テキストが前面、背景が背面にあり、文字や背景が切れません。

## 2. 背景だけの表示

次の順で値を変えます。

1. `しっぽの向き`を`なし`へ変更します。
2. `横余白`: -100 → -20 → 0 → 24 → 100
3. `縦余白`: -100 → -20 → 0 → 16 → 80
4. `オフセットX`: -40 → 0 → 40
5. `オフセットY`: -40 → 0 → 40
6. `背景透明度`: 0 → 50 → 100
7. `角丸`: 0 → 16 → 100

期待結果:

- 値に応じて滑らかに変化する
- 負の余白では背景だけが縮み、文字は切れない
- 大きな負の値でも背景が反転したりエラーになったりしない
- 正のXで文字だけが右、正のYで文字だけが下へ動く
- オフセットを変えても背景本体としっぽの付け根は動かない
- 背景から文字がはみ出す値でも、文字自体が画像領域で切れない
- 透明度100では背景が見えなくなる
- 四隅や半透明の外周に、不自然に濃い縁が出ない

## 3. しっぽの表示

1. `しっぽの向き`を上、下、左、右の順に確認します。
2. `しっぽの位置`を`割合`にし、各方向で`割合位置`を-100、0、100へ変更します。このとき`固定距離`が隠れていることも確認します。
3. `しっぽの位置`を`固定距離+`にし、`しっぽの幅`を36、背景の`角丸`を16、`固定距離`を80にします。このとき`割合位置`が隠れていることも確認します。
4. 上・下ではテキストを短文から長文へ変えて横幅を変え、左端から付け根中心までが80pxのままになることを確認します。左・右では複数行へ変えて縦幅を変え、上端から付け根中心までが80pxのままになることを確認します。
5. `しっぽの位置`を`固定距離-`へ変えます。上・下では右端、左・右では下端から付け根中心までが80pxのままになることを、文字量を変えて確認します。
6. `固定距離`を0、20、80、2000へ変更し、`固定距離+`と`固定距離-`で基準端が切り替わり、角丸やしっぽ幅へ食い込む値だけが安全な位置へ制限されることを確認します。
7. `しっぽの幅`を10、40、100へ変更します。
8. `しっぽの高さ`を10、28、100へ変更します。
9. `先端オフセットX`を-100、0、100へ変更します。
10. `先端オフセットY`を-100、0、100へ変更します。
11. 背景としっぽの色が見やすい状態で、しっぽの付け根を拡大表示します。
12. 各方向で`しっぽの幅`を40、`しっぽの高さ`を28、`しっぽ角丸`を16に戻し、背景の`角丸`を0、16、100、500の順に変更します。
13. 背景の`角丸`を100にして、`しっぽ角丸`を0、16、100、500の順に変更します。
14. 最後に`しっぽの向き`を`なし`へ戻し、しっぽだけが消えることを確認します。

期待結果:

- 4方向すべてで正しい辺からしっぽが出る
- `割合`では吹き出しの辺が伸縮すると割合に応じて位置が変わる
- `固定距離+`では、吹き出しが伸縮しても上・下は左端、左・右は上端からの距離が維持される
- `固定距離-`では、吹き出しが伸縮しても上・下は右端、左・右は下端からの距離が維持される
- `しっぽの位置`に応じて`割合位置`と`固定距離`の片方だけが表示される
- 端へ寄せても角丸部分へ不自然に食い込まない
- 角丸を500まで大きくしてもしっぽが消えず、直線部分が足りない場合は中央寄りで背景へつながる
- 背景の`角丸`を変えても、しっぽ先端の丸みは変わらない
- `しっぽ角丸`が0なら先端が尖り、1以上なら先端位置を保ったまま滑らかな円弧になる
- `しっぽ角丸`を変えても、背景四隅の丸みは変わらない
- 丸い先端と斜辺の接続に段差、くびれ、膨らみが出ない
- 正のXで先端だけが右、正のYで先端だけが下へ動く
- 先端を動かしても付け根の位置と幅は変わらない
- しっぽの付け根に隙間、横線、二重線、濃い継ぎ目が出ない
- しっぽ先端が画像領域で切れない
- しっぽの幅または高さを0にすると、先端オフセットに関係なくしっぽが消える
- `なし`では背景を残してしっぽだけが消え、しっぽ用の調整項目が隠れる

## 4. 文字内容とサイズ追従

同じテキストオブジェクトで次を順番に試します。

1. `短文`
2. `日本語 ABC 123`
3. 2～3行の文章
4. 非常に長い1行
5. 空文字
6. 半角スペースだけ
7. 全角スペースだけ

期待結果: 1～4は背景が文字量へ追従し、5～7はエラーや残像を出しません。空文字や空白だけの実際の表示は、AviUtl ExEdit2が返すテキスト画像サイズに左右されるため、そのまま記録してください。

## 5. 変形と効果順

1. オブジェクトを移動、拡大・縮小、回転します。
2. `ぼかし`を本効果より前へ置きます。
3. `ぼかし`を本効果より後ろへ置きます。

期待結果:

- 移動や変形で背景だけがずれない
- 本効果より前のぼかしは、先にテキストへ反映される
- 本効果より後ろのぼかしは、テキストと背景全体へ反映される

## 6. 保存・再読み込み

1. 検証用プロジェクトを新しい名前で保存します。
2. AviUtl ExEdit2を終了します。
3. 保存した検証用プロジェクトを開き直します。
4. 色、余白、テキスト位置、背景の角丸、しっぽの向き、しっぽの位置、割合位置、固定距離、しっぽ角丸、先端位置の値が保持されていることを確認します。

## 7. 動画出力

1. 2～3秒の短い範囲を、普段使う形式で出力します。
2. プレビューと出力動画を見比べます。

期待結果: 背景、しっぽ、透明度、テキスト位置、先端位置がプレビューと一致します。

## 不具合があった場合の記録

次の情報があると修正しやすくなります。

- 問題が出た手順番号
- 変更した設定名と値
- 入力した文字列
- 期待した見た目と実際の見た目
- プレビュー全体と設定欄が見えるスクリーンショット
- エラー文の全文
- 保存・再読み込み後だけ起きるか
- 動画出力だけで起きるか

不具合が再現したプロジェクトは、元の編集プロジェクトへ上書きせず、検証用ファイルとして残してください。
