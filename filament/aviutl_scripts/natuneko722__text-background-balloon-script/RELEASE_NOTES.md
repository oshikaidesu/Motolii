# リリースノート

## v1.2.1 - 2026-09-01

配布名義と標準配置を`NNeko`から`NatuNeko`へ移行した版です。描画機能と設定項目はv1.2.0から変更していません。

- AviUtl2内の初期分類を`NatuNeko`へ変更。
- 配布・導入先を`Script\NatuNeko\吹き出し背景@テキスト.anm2`へ変更。
- package ID `natuneko722.text-background-balloon-script`と正式名称は維持。
- 更新時は新しい所有ファイルを導入した後、旧`Script\NNeko\吹き出し背景@テキスト.anm2`だけを削除する移行手順へ変更。
- 旧`NNeko`と新`NatuNeko`は共有フォルダーのため、どちらもフォルダー全体を削除しない。
- スクリプトやパッケージは`aviutl2.ini`を直接編集しません。移行テストではAviUtl2の再登録によって対象ラベルが`NatuNeko`へ更新されました。ユーザー設定などにより旧分類が残る場合は、「オブジェクト追加メニューの設定」から手動で変更できます。

## v1.2.0 - 2026-08-26

吹き出しの大きさが変わっても、選択した端からしっぽまでの距離を維持できるようにした版です。

- `しっぽの位置`へ`割合`、`固定距離+`、`固定距離-`の3方式を追加。
- `割合`は従来どおり、辺の安全な可動範囲を-100～100%で指定。
- `固定距離+`は上・下で左端、左・右で上端を基準にする固定ピクセル距離として追加。
- `固定距離-`は上・下で右端、左・右で下端を基準にする固定ピクセル距離として追加。
- 固定距離は0～2000pxとし、負数を入力せず選択肢で基準端を切り替える方式を採用。
- 設定項目が増えたため、旧版を適用済みのオブジェクトでは効果を一度外して付け直す必要があります。

## v1.1.0 - 2026-08-24

背景としっぽの角丸を個別に調整できるようにし、吹き出しとして使い始めやすい初期値へ更新した版です。

- 角丸を大きくするとしっぽの有効幅が0になり、表示されなくなる問題を修正。
- 直線部分が足りない角丸背景では、しっぽを中央寄りへ制限し、付け根を背景内側へ重ねて接続するように変更。
- `しっぽ角丸`を追加し、背景の`角丸`とは別に先端の丸みを調整可能に変更。指定した先端位置は維持される。
- `表示形式`を削除し、`しっぽの向き`へ`なし`を追加。
- 新規追加時のしっぽを`下`、位置を`50`、幅を`72`、高さを`48`へ変更。その他の初期値は画面例に合わせて整理。

## v1.0.1 - 2026-08-22

名称と配置を管理しやすい共通ルールへ変更した更新版です。描画機能と設定値はv1.0.0から変更していません。

### 変更点

- 正式名称を「吹き出し背景@テキスト」へ変更。
- AviUtl2内の追加先を「NNeko」へ変更。
- 配置先を`Script\NNeko\吹き出し背景@テキスト.anm2`へ変更。
- READMEを、使い方と設定例を先に読める構成へ変更。
- 共有`NNeko`フォルダーを削除しない配布・アンインストール規則を追加。

### v1.0.0から更新する場合

- 同じパッケージIDの`.au2pkg.zip`をAviUtl2へ導入すると、旧パッケージをアンインストールしてからv1.0.1が導入されます。
- 手動配置の場合は、新版の導入後に旧ファイル`Script\TextBackgroundBalloon\テキスト背景・吹き出し.anm2`だけを削除してください。
- 既存プロジェクトでは旧効果を外し、「NNeko」から「吹き出し背景@テキスト」を付け直してください。

## v1.0.0 - 2026-08-22

「テキスト背景・吹き出し」の初回正式リリースです。

## 主な機能

- テキストサイズへ自動追従する角丸背景
- 背景と吹き出しの切り替え
- 負の値に対応する横余白・縦余白
- 背景を固定したまま調整できるテキストオフセットX / Y
- 上・下・左・右へ配置できる吹き出しのしっぽ
- しっぽの位置・幅・高さ・先端オフセットX / Y
- 背景色・透明度・角丸
- 画像上限内へ収める安全制限

## 対応環境

- AviUtl ExEdit2 2.1.5以上
- 動作確認環境: AviUtl ExEdit2 2.1.5
- 旧AviUtl 1.xは対象外

## 既知の制約

- 縦書きとテキストの個別オブジェクトは保証対象外です。
- テキスト以外へ適用した場合の見た目は保証しません。
- 設定ヘッダーが異なる開発版を適用済みの場合は、効果を一度外して付け直してください。
