# 相対移動+@PSD

PSDToolKit2のキャラクターIDまたは参照レイヤーを合図に、PSDへ相対移動を加えるAviUtl2用アニメーション効果です。ID空欄かつ参照レイヤー0の単体動作にも対応します。

`v1.0.0`では、`参照レイヤー=0`かつIDありのときにキャラクターIDから参照オブジェクトを自動検索します。実レイヤー番号を指定した場合はレイヤーを優先してID一致を要求しません。レイヤー0かつID空欄なら参照なしの単体効果として動作します。`通常`、`反復`、紙芝居人形向けの`反復+`、`ランダム`、起点X/Y、レイヤーに依存しない同期シード、動作別の設定表示、反復系の参照開始時リセットと周期終端復帰に対応しています。

## 使い方

1. PSDToolKit2公式の手順どおり、`最初に置くやつ@PSDToolKit`を配置します。
2. `セリフ準備@PSDToolKit`または`パーツ上書き@PSDToolKit`へキャラクターIDを設定します。
3. 動かしたいPSDファイルオブジェクトの`描画@PSDToolKit`より下に、`NNeko`分類の`相対移動+@PSD`を追加します。
4. `相対移動+@PSD`へ同じキャラクターIDを入力します。
5. `参照レイヤー`は初期値の`0`のままにします。`0`はID自動参照です。
6. 最初の確認では`動作=通常`、`起点X=0`、`起点Y=0`、`X=100`、`Y=0`、`Z=0`にします。
7. 固定移動を確認した後、`動作`を`反復`、`反復+`、`ランダム`へ切り替えます。

`参照レイヤー=0`かつIDありならID自動参照です。自動参照で発動しない場合は、手順2のオブジェクトがある実レイヤー番号を入力してください。例えばレイヤー11なら`11`です。`1`以上を指定すると自動検索を行わず、そのレイヤーの存在だけで動作するため、IDは空欄でも一致していなくても構いません。

PSDToolKit2のID連携を使わず単体の相対移動として使う場合は、`参照レイヤー=0`、`キャラクターID=空欄`にします。この場合は`相対移動+@PSD`自身の開始時刻を0として常時動作します。

キャラクターIDはPSDToolKit2と同じ形式を使えます。

- `akane`のような名前ID
- `L11`のような登録元オブジェクトのレイヤー番号
- `akane, aoi, L11`のようなカンマ区切り候補

ID自動参照で一致するIDがない場合は何も変更しません。連携取得に失敗した場合も、PSD画像と透明度には触れません。参照元がなくなった場合の反復系の動作は、後述の「参照終了後の復帰」を参照してください。

## 動作

参照条件を満たすか、ID空欄の単体動作になっていると、現在の`obj.ox`、`obj.oy`、`obj.oz`へ次の移動量を加算します。`起点X / 起点Y`は全動作に共通する相対的な基準位置です。

- `通常`: 起点XYを基準に、指定XYZを固定で加算します。
- `反復`: 参照オブジェクトの開始時刻を0として、`周期(秒)`ごとに起点→指定XYZ→起点を直線的に往復します。
- `反復+`: 参照オブジェクトの開始時刻を0として、周期ごとにX・Y・角度の最小～最大から目標姿勢を選び、起点・初期角度→目標姿勢→起点・初期角度と往復します。
- `ランダム`: 起点XYを中心とする±XYZの範囲内で、`周期(秒)`ごとに決まる移動先を滑らかにつなぎます。

ID自動参照と手動参照では参照オブジェクトの時刻を使います。`参照レイヤー=0`かつID空欄の単体動作では、この効果自身の時刻を使います。

`ランダム`と`反復+`は、同じシード、同じ参照時刻、同じ範囲設定なら、対象オブジェクトや参照オブジェクトのレイヤーが異なっても同じ結果になります。複数のPSDを同期させる場合は、シード、周期、範囲を揃え、参照オブジェクトの開始時刻も揃えてください。

### 表示される設定

`キャラクターID`、`参照レイヤー`、`動作`、`起点X`、`起点Y`は常に表示します。それ以外は動作に応じて切り替わります。`参照レイヤー=0`の意味は前述の使い方を参照してください。

- `通常`: X、Y、Z
- `反復`: X、Y、Z、周期(秒)
- `反復+`: 周期(秒)、シード、X・Y・角度の最小最大、なめらかさ、停止(秒)
- `ランダム`: X、Y、Z、周期(秒)、シード

### 参照終了後の復帰

`反復`と`反復+`では、参照オブジェクトが周期の途中でなくなっても、その場で動きを切りません。最後に確認できた参照時刻から同じ周期を続け、周期終端で起点X/Yと初期角度へ戻って停止します。`通常`と`ランダム`は、参照がなくなった時点で適用を終了します。

`参照レイヤー=0`かつID空欄の単体動作には参照終了がないため、効果が存在する間は選択した動作を続けます。

復帰処理はAviUtl2の共有スクリプト状態へ直前の参照時刻を一時保存して行います。このため、参照が存在するフレームを一度も処理せず、AviUtl2再起動直後やプロジェクトを開いた直後に参照終了後のフレームへ直接シークした場合は、過去の状態を推測せず発動しません。

### 反復+設定

- `X最小 / X最大`: 起点Xからの横方向の移動範囲です。
- `Y最小 / Y最大`: 起点Yからの縦方向の移動範囲です。
- `角度最小 / 角度最大`: Z軸回転の範囲です。回転中心は対象オブジェクトの中心です。
- `なめらかさ`: 0は一定速度、100は開始と停止が最も緩やかです。紙芝居人形では100を推奨します。
- `停止(秒)`: 往路で目標姿勢へ到着した後、復路へ入る前に止まる時間です。往路・停止・復路を合わせた長さが`周期(秒)`になります。
- `シード`: 同じ値なら、配置レイヤーや個別オブジェクト番号に関係なく同じ参照時刻で同じ動きになります。

各周期でX・Y・角度の目標値が決まり、角度は周期ごとに変化します。最小と最大を逆に設定しても内部で入れ替えて処理します。`停止(秒)`が周期以上の場合も、往路と復路をそれぞれ周期の5%以上残すよう安全に調整します。

### ID自動参照

`参照レイヤー=0`かつIDありでは、AviUtl2標準の`obj.getinfo("layer_max")`と`obj.getvalue`を使い、現在フレームにオブジェクトがあるレイヤーだけを検索します。その中から次の効果の`キャラクターID`が一致するレイヤーを参照します。

- `パーツ上書き@PSDToolKit`
- `パーツ上書き@PSD`
- `セリフ準備@PSDToolKit`
- `セリフ準備@PSD`

カンマ区切りで複数IDを指定した場合は左から順に探します。同じIDが複数レイヤーにある場合は、番号が最も小さいレイヤーを使います。特定のレイヤーを優先したい場合は`参照レイヤー`へ実番号を指定してください。実番号を指定した時点でレイヤー優先となり、キャラクターIDは判定に使いません。

過去版が発動しなかった原因は、レイヤー存在確認へ数値のレイヤー番号だけを渡していたことでした。AviUtl2では数値1個は現在オブジェクトのトラックバー番号として扱われます。v1.0.0では公式仕様どおり`layer11`のような文字列で存在確認し、その後に指定レイヤーの効果設定を読み取ります。PSDToolKit2の非公開な内部状態や、画像を差し替える連携処理は使用しません。

## CJF版から参考にした点

[aviutl2_cjf_psdanimation](https://github.com/ColorJellyFish/aviutl2_cjf_psdanimation)の非公式連携方式を参考にしました。

- PSDファイルオブジェクトの`描画@PSDToolKit`より下へ追加する配置
- 内部状態が取得できない場合に参照レイヤーを直接読む考え方
- 連携対象が見つからない場合は描画を変更せず終了する考え方

CJF版のソースコード自体は同梱していません。本スクリプトはパーツ切り替えアニメーションではなく、ID自動参照、手動レイヤー参照、または参照なしの単体相対移動だけを行います。

## 導入

必要条件:

- AviUtl2 / ExEdit2 `2.1.5`以降
- PSDToolKit2 `v2.0.0alpha10`

GitHub Releaseから`SubObjRelativeMotionEX_v1.0.0.au2pkg.zip`をダウンロードし、AviUtl2へドラッグ＆ドロップして導入します。ZIPを手動で展開する場合は、`Script\NNeko\相対移動+@PSD.anm2`を次へコピーします。

```text
Script\NNeko\相対移動+@PSD.anm2
```

標準構成の実パス:

```text
C:\ProgramData\aviutl2\Script\NNeko\相対移動+@PSD.anm2
```

AviUtl2を起動中の場合は、コピー後にすべて終了して再起動してください。設定項目が旧版のままなら、既存の効果を削除して追加し直します。

## 更新・削除

- 更新: 新しい`.au2pkg.zip`をAviUtl2へ導入します。手動更新ではAviUtl2を終了してから、`相対移動+@PSD.anm2`だけを置き換えます。
- 削除: AviUtl2のパッケージ管理から削除するか、手動配置では`Script\NNeko\相対移動+@PSD.anm2`だけを削除します。
- 共有親フォルダー`Script\NNeko`全体は削除しないでください。

## 対応範囲と制約

- ID自動参照の開始には、現在フレームに一致IDの`パーツ上書き@PSDToolKit`、`パーツ上書き@PSD`、`セリフ準備@PSDToolKit`、`セリフ準備@PSD`のいずれかが必要です。手動参照は指定レイヤーのオブジェクト、ID空欄の単体動作はこの効果自身が時間基準です。
- ID自動参照は現在フレームに存在するオブジェクトを毎フレーム検索します。同じIDが複数ある場合は最小レイヤーを選ぶため、別の参照元を使いたい場合は手動参照に切り替えてください。
- AviUtl2の`obj.getvalue`は無効状態の効果を取得対象にしないため、ID自動参照では参照元の`パーツ上書き`または`セリフ準備`を有効にしてください。
- ID自動参照はPSDToolKit2の内部状態を使用しません。
- ランダムのXYZは到達範囲の絶対値です。例えば`X=100`ならXは-100～100です。
- `反復+`の角度は`obj.rz`へ加算します。足元などを支点にした回転はまだありません。
- 参照終了後の復帰は、同じAviUtl2実行中に参照が存在するフレームを処理して一時状態を作れた場合に限ります。再起動直後の終了後フレームへの直接シークでは発動しません。
- 登場・退場、透明度、対象なし時非表示、監視パーツは今回の簡易版の対象外です。
- 保存・再読み込み、シーク、動画出力はまだ実機未確認です。
