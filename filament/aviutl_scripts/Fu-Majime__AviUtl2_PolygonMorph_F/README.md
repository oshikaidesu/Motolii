## パラメータ詳細

### 基本設定

| トラック名 | 説明 |
| :--- | :--- |
| **頂点数** | 正多角形の頂点数　数値の変化に応じて形状が滑らかにモーフィングされます。 |
| **サイズ** | 図形のサイズ　外接円の直径 |
| **ライン幅** | 線の太さ　大きいと塗りつぶし |
| **半径** | 角の丸まりの半径 |
| **星型歪み** | 辺の中点を中心に引き込み、星型にする（0%で正多角形） |

### 色・外観

* **色**: 図形のメインカラー
* **背景色**: 内側の塗りつぶし色
* **背景透明度**: 内側の塗りつぶしのアルファ値
* **角タイプ**:
  * `谷優先`: 頂点が丸まっていく
  * `先端優先`: 頂点の位置を維持して丸める

### モーフィング設定

* **補間方法**:
  * `回転`: 図形が回転しながら頂点が増減するように補間
  * `直線`: 頂点が所定の位置へ直線的に移動するように補間
* **回転補正**: 図形の向きを細かく調整できます
