# JpegNoise for AviUtl2

ToTTi氏の [jpegScript](https://github.com/Totti95U/jpegScript) をAviUtl2（ExEdit2）向けに移植・最適化したスクリプトです。 
なお、本スクリプトのHLSLへの移植およびコードの最適化には生成AIを利用しています。

## 機能概要

JPEG圧縮特有のブロックノイズや色のにじみ（不可逆圧縮劣化）を再現するアニメーション効果です。  
直前のオブジェクトに対する適用に加え、フィルタオブジェクトとしても動作します。

## 動作要件

* **AviUtl ExEdit2 (v2.00 beta46 以降)**

## パラメータ説明

### 圧縮設定
* **品質** (0 - 100)  
  圧縮の品質を指定します。値を下げるほど量子化ステップが粗くなり、ブロックノイズや色の劣化が強くなります。
* **インターレース** (1 - 64)  
  保持するDCT高周波成分のしきい値です。64ですべての成分を使用し、値を小さくするほど低周波成分のみが残りディテールが削ぎ落とされます。
* **透明度も圧縮** [チェックボックス]  
  有効にすると、アルファチャンネル（透明度）に対してもDCT変換と量子化ノイズを適用します。

### ブロック設定
* **サイズ倍率** (1 - 16)  
  基準となる8x8ピクセルのブロックサイズを仮想的に拡大します。数値を上げると粗いモザイク状の劣化になります。
* **グリッドズレ (Xズレ / Yズレ)** (-32 - 32)  
  ノイズの基準グリッドの位置をオフセットさせます。時間変化させることで、ブロック境界が動的に変化する演出が可能です。

## 配置場所

※ `ProgramData\aviutl2\Script\` 直下、またはその1階層下のフォルダに配置してください。
