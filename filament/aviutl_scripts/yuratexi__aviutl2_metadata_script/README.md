# Aviutl2 MetaData Script  
[ダウンロードはこちら](https://github.com/yuratexi/aviutl2_metadata_script/releases/latest)  
単純にオブジェクトにメタデータを埋め込むためのスクリプト。  
以下画像のように、文字が書けるだけです。
<img width="456" height="740" alt="image" src="https://github.com/user-attachments/assets/4fdb145b-73c4-41ad-8957-170e9abcf6d8" />    

任意のオブジェクトに対して、  
『フィルタ効果を追加→基本効果→metadata』  
を付与すると使えます。  
一応、aup2ファイル内に以下のように格納されます(これは上記画像の場合)  
```
[0.2]
effect.name=metadata
metadata=ここに自由に文字が書けるだけです\naup2ファイルにも反映されるので、プラグインやスクリプトからここを参照して\n何か処理をするみたいなことに使える？\nもしくは単純にコメントとしても使えるかも
```
なにかには使えるでしょう。きっと  
世にも珍しいたった34文字のプラグインなので、規約なんてものはありません。  
一応MITライセンスを付与してありますが...煮るなり焼くなり自由に使ってください。
