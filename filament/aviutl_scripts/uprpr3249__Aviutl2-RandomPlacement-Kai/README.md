# ランダム配置改 (@RandomPlacementKai.anm2)

AviUtl ExEdit2 用のアニメーション効果です。
1個のオブジェクトを**指定した個数ぶん複製し、指定した範囲へ一様ランダムに配置**します。

本体標準の「ランダム配置」は散らす範囲が1つの「範囲」トラックバーしか無く、
X/Y/Z を個別に指定したり球状に散らしたりが出来ません。
本スクリプトは**矩形 / 球形 / 円形**の3モードを持ち、各軸の幅や内側半径まで指定出来ます。

さらに、各複製の向きを**原点(0,0,0)へ向ける**オプションがあります（3D look-at）。

## 標準の「ランダム配置」との違い

| | 標準 | ランダム配置改 |
| --- | --- | --- |
| 配置範囲 | 「範囲」1つ（XYZ共通の立方体） | **矩形（X/Y/Z個別）/ 球形 / 円形(Z固定)** |
| 中空の分布 | 不可 | **内側半径**で殻状・ドーナツ状に出来る |
| 球状に散らす | 不可（立方体になる） | **体積一様の球**（中心に密集しない） |
| 向き | ランダム角度 / カメラの方向を向く | **原点(0,0,0)を向く**（+ 反転）/ ランダム角度 |
| 個数を変えたとき | 既存の点も動く | **既存の点は動かない**（個数をアニメーション出来る） |
| 再生位置を動かしたとき | 固定 | 固定 |

## 必要環境

- AviUtl ExEdit2（`.anm2` 形式のスクリプトが読める本体）
- 追加のプラグインやモジュールは**不要**です。ファイル1個で動きます

## インストール

1. [Releases](../../releases) から `@RandomPlacementKai.anm2` をダウンロードする
2. `C:\ProgramData\aviutl2\Script` へ置く
3. AviUtl2 を再起動する（または「キャッシュを破棄」）

ファイル名は**変えずにそのまま**置いてください。
先頭が `@` のファイルは複数登録形式として扱われ、中で宣言している `@ランダム配置改` が
効果の名前になります（ファイル名そのものは効果名になりません）。

## 使い方

1. 図形・画像・テキストなどのオブジェクトを1個置く
2. **フィルタ効果の追加 → 配置 → ランダム配置改**
3. Z方向を使う場合や、rx/ry 回転を立体的に見せたい場合は**カメラ制御**を併用する

## パラメータ

| 項目 | 内容 |
| --- | --- |
| 個数 | 複製する数 N（1〜2000） |
| シード | 乱数の種。変えると配置全体が引き直されます |
| 配置モード | `矩形` / `球形` / `円形(Z固定)` |
| X幅 / Y幅 / Z幅 | 矩形モードの各軸の範囲（全幅）。`0` にするとその軸は動きません |
| 半径 | 球形・円形モードの外側の半径 |
| 内側半径 | `0` より大きくすると中心が空いた殻状・ドーナツ状になります |
| 拡大率ランダム | ±何 % の範囲で拡大率をばらつかせるか |
| 原点方向を向く | ON で各複製の**表**が原点(0,0,0)を向きます |
| 向きを反転 | 表ではなく**裏**を原点へ向けます |
| ランダム角度 | 「原点方向を向く」が OFF のときに回転をランダムにします |

配置モードや「原点方向を向く」の状態に応じて、関係の無い項目は自動で非表示になります。

## 仕組み

配置系の効果と同じく、`obj.draw()` を個数回呼んでコピーを描いています。

```lua
for i = first, N, step do
  local x, y, z = place(i)          -- モードに応じた座標
  obj.draw(x, y, z, zoom, 1, rx, ry, rz)
end
```

### 乱数（フレームに依存させない）

本体の `obj.rand()` は**フレーム番号を引数に取る**仕様で、素直に使うと
再生位置によって配置が変わってしまいます。
本スクリプトは `(index, channel, seed)` だけを入力とする**純関数ハッシュ**を自前で持ち、
フレームを一切参照しません。よって配置は完全に固定されます。

インスタンス番号 `i` から直接値を引くので、**N を増やしても既存の点は動きません**。
個数トラックバーをアニメーションさせると、既に置かれた点はそのままに数だけ増えていきます。

```lua
local P = 67108859                    -- 2^26 未満の素数
local function rnd(i, ch, sd)
  local s = (i * 1103515 + ch * 12345701 + sd * 7654321 + 1) % P
  for _ = 1, 4 do
    s = (s * s + 3 * s + 1013904223) % P   -- 二次写像で非線形化
    s = (s * 48271) % P
  end
  return s / P
end
```

線形合同法を繰り返すだけだと、出力が `i` の一次式のままになって
**X座標とY座標が定数オフセットで相関し、点が直線・平面に整列してしまいます**
（実測で 20x20 のセルのうち 40 個にしか点が乗りませんでした）。
そのため各ラウンドに二次写像 `s^2` を挟んでいます。
法 `P` は 2^26 未満の素数なので `s*s < 2^53` に収まり、double でも丸め誤差なしに厳密計算出来ます。

改善後の実測値（N=4000）:

| 指標 | 値 |
| --- | --- |
| 2D 20x20 セル占有 | 400/400 |
| 3D 10x10x10 セル占有 | 977/1000 |
| lag-1 自己相関 | +0.024 |
| チャンネル間相関 | -0.025 |
| 一様性 chi2(9df) | 3.1（5%棄却限界 16.9） |

### 分布の一様性

- **球形**: 半径を `r^3` の逆関数でとります。単純に半径を一様にとると中心へ密集してしまいます。
  方向はアルキメデスの定理により `cosθ` を一様にとるので、極に偏りません
- **円形**: 半径を `r^2` の逆関数でとります（面積一様）
- 棄却法は使っていないので、処理時間は個数に対して線形です

### look-at（原点を向く）

座標系は **+X=右 / +Y=下 / +Z=奥** で、無回転のオブジェクトの表の法線は `-Z` です。
位置 `p` から原点への方向 `d = -p/|p|` へ `-Z` 軸を一致させるオイラー角を解きます。
`rz` は視線軸まわりの回転なので `0` で構いません。

**rx/ry/rz の回転合成順は `lua.txt` に記載がありませんが、実機で確認したところ
`Rx*Ry*Rz`（Rz, Ry, Rx の順に適用）でした。** よって解は次の通りです。

```
rx = atan2(-py, pz)
ry = asin(px / |p|)
rz = 0
```

`Ry*Rx*Rz` 前提の解（`rx = asin(-py/|p|)`, `ry = atan2(px, pz)`）は実機では正しく向きません。

「向きを反転」は `ry + 180` ではなく**位置ベクトルを反転させて解き直しています**。
外側の回転に 180 を足す方法は、内側の回転が 0 でないときに正しく反転しないためです。

### 個別オブジェクト

テキスト等で「個別オブジェクト」が有効だと、同じスクリプトがオブジェクト数ぶん呼ばれます。
`obj.index` / `obj.num` を見て自分の担当ぶんだけを間引いて描画し、
担当が無い場合は `draw_state` を立てて何も描きません。

## 検証について

AviUtl2 同梱の `luaJIT.dll` を直接ロードし、`obj` をスタブした状態でスクリプトを実行して
`obj.draw()` の引数を回収する形で検証しました。確認済みの項目は次の通りです。

- 矩形 / 球形 / 円形の範囲と分布の一様性、殻状分布
- look-at の正しさ（`Rx*Ry` で回転行列を再構成して方向ベクトルと突き合わせ、誤差 1e-8 以下。表・裏の両方）
- 同じシードで完全に同一の結果になること、シードを変えると全点が動くこと
- N を増やしても既存の点が動かないこと
- 個別オブジェクト時の間引き結果が通常時と一致すること
- 端数ケース（N=1、半径0、内側半径 > 半径のときの入れ替え）

## 未対応 / 制限

| 項目 | 挙動 |
| --- | --- |
| 個数の上限 | 2000。それ以上必要な場合は `--track@num` の最大値を書き換えてください |
| 時間変化 | 位置は時間に対して静止します（回転アニメーションは未実装） |
| 向きを原点以外へ向ける | 未対応（原点固定） |
| look-at 後の追加ランダム回転 | 未実装 |
| 色や透明度のランダム化 | 未実装 |

## 調査メモ（AviUtl2 スクリプト仕様）

一次資料は `C:\Program Files\aviutl2\lua.txt` と同梱の `script.anm2` 等です。

- AviUtl2 は Lua（既定で LuaJIT）。スクリプトは **UTF-8**、旧形式（`.anm` 等）は SJIS
- 配置先は `C:\ProgramData\aviutl2\Script`（1階層下のフォルダまで）
- **1オブジェクトからの複数描画は可能**。`obj.draw(ox,oy,oz,zoom,alpha,rx,ry,rz)` をループで呼びます
- `obj.draw()` を使うとスクリプト以降のフィルタ効果が実行されなくなるため、
  先頭で引数なしの `obj.effect()` を呼んで事前に適用しておきます
- 設定UIは先頭のコメントで定義します（`--track@` `--check@` `--select@` `--value@` など）。
  `--trackgroup@` でトラックバーをグループ化、`--hide@変数:条件` で条件付き非表示に出来ます
- `--check@` のデフォルト値が `0`/`1` なら変数は number 型、`true`/`false` なら boolean 型になります。
  `--hide@` の条件は数値比較なので、本スクリプトは number 型へ揃えています
- 個別オブジェクトとして複製する `obj.multiobject(num, func)` もあります
  （本スクリプトは軽量な `obj.draw()` 方式を採用）
- **rx/ry/rz の回転合成順は `lua.txt` に記載がありません。実機では `Rx*Ry*Rz` でした**

## ファイル構成

```
script/@RandomPlacementKai.anm2   スクリプト本体（1ファイル）
```

先頭が `@` のファイル名は AviUtl2 の**複数登録形式**で、`@名前` の行で効果名を宣言します。
効果名に日本語を使いつつファイル名を ASCII に出来るので、リリースの配布ファイルとして扱えます
（GitHub のリリースアセット名は非 ASCII 文字が落ちてしまいます）。
