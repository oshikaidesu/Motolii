# 連結ライン（AviUtl2 用カスタムオブジェクト）

2 つのレイヤーにあるオブジェクトの中心どうしを、実線または点線で繋ぐ AviUtl ExEdit2（AviUtl2）用のカスタムオブジェクトです。
繋いだオブジェクトを動かすと、線も毎フレーム追従します。

## できること

- 任意の 2 レイヤーのオブジェクトを線で繋ぐ（移動に追従）
- 実線 / 点線、太さ、色
- 端の形を「平ら」か「丸」から選ぶ
- 点線の長さ・間隔の調整と、点線が流れるアニメーション
- 表示割合で、線が始点から伸びるアニメーション
- 始点・終点の手前で線を止める（オブジェクトに線を重ねない）
- 始点・終点の位置をオブジェクトの中心からずらす
- 奥行き（Z）の違うオブジェクトを繋ぐとき、線の太さを手前か奥のどちらかに揃える（カメラ制御の有無を問わない）

## 動作環境

AviUtl ExEdit2（AviUtl2）。2.1.12 で動作を確認しています。

## 導入

1. [Releases](https://github.com/ar-ca-na/connection_line/releases) から zip をダウンロードして展開します。
   このページの `連結ライン.obj2` を開き、右上の「Download raw file」で保存しても構いません。
2. `連結ライン.obj2` を AviUtl2 のプレビュー画面へドラッグ＆ドロップします。
   または `C:\ProgramData\aviutl2\Script\`（その 1 つ下のフォルダでも可）に置いて AviUtl2 を再起動します。

## 使い方

1. 繋ぎたいオブジェクトを 2 つ、別々のレイヤーに置きます（例: レイヤー 1 と 2）。
2. 別のレイヤーに「連結ライン」を置き、繋ぎたい時間に表示されるよう長さを合わせます。
3. 「対象レイヤー1」「対象レイヤー2」に、1 のレイヤー番号を入れます。

線をオブジェクトの後ろに通したいときは、連結ラインを対象より番号の小さいレイヤーに置きます。
丸い点を並べた点線にするには、「端の形」を丸にし、「点線の長さ」を「太さ」と同じにします。

## 設定項目

| 項目 | 説明 |
| :--- | :--- |
| 対象レイヤー1 / 2 | 始点・終点にするオブジェクトのレイヤー番号 |
| 太さ | 線の太さ（px） |
| ラインの色 | 線の色 |
| ラインの種類 | 実線 / 点線 |
| 点線の長さ / 点線の間隔 | 点線 1 本の長さと、線と線の間のすき間（px）。実線のときは表示されません |
| 始点オフセットX / Y | 始点をオブジェクトの中心からずらす量（px） |
| 終点オフセットX / Y | 終点をオブジェクトの中心からずらす量（px） |
| 端の形 | 平ら / 丸。丸にしても線の長さは変わりません（端がはみ出さない） |
| 始点の空き / 終点の空き | 始点・終点から、線を描かずに空ける長さ（px）。円や枠の縁で線を止めたいときに使います |
| 表示割合 | 0〜100%。始点から何 % まで描くか。動かすと線が伸びるアニメーションになります |
| 点線の流れ | 点線が流れる速さ（px/秒）。プラスで始点から終点へ、マイナスで逆向きに流れます。実線のときは表示されません |
| 奥行き | 手前に揃える（既定） / 奥に揃える / そのまま。始点と終点の Z が違うとき、線を手前・奥どちらの深さに置くか。揃えると線の太さと点線の長さが一定になります。「そのまま」は深さに合わせて太さが変わります。どれを選んでも、画面上の線の端は対象の中心に合います |

線の不透明度は、連結ラインの「透明度」で変えられます。

## 注意

- 線が追従するのは、各オブジェクトの基準座標（X・Y・Z）です。アニメーション効果（振動など）でずらした分は線に反映されません。
- 対象レイヤーにその時点のオブジェクトが無いときは、線を描きません。
- 設定項目は後ろに足しているので、v1.0.0 で作った編集データもそのまま読めます。
  ただし v1.2.0 で足した「奥行き」は既定が「手前に揃える」なので、Z の違うオブジェクトを繋いでいた線は太さが一定に変わります。前の見た目に戻すには「そのまま」を選んでください。
- 線の深さを揃えると、同じ深さにある対象と線が重なります。カメラ制御の対象では、重なった部分が混ざって見えることがあります。気になるときは「始点の空き」「終点の空き」で避けてください。
- カメラ制御を使うときは、連結ラインと対象のオブジェクトの両方を「カメラ制御の対象」にしてください。
