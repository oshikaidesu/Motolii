# 画像ループ改 (@ImageLoopKai.anm2)

AviUtl ExEdit2 用のアニメーション効果です。
オブジェクトの画像を**タイル状に縦横へ繰り返し並べ**、速度を与えると**継ぎ目なくスクロール**します。

標準の「画像ループ」に加えて、交互反転(ミラー)・行/列ずらし(レンガ積み)・間隔・タイル拡大率・
**ループ毎の拡大率変化**に対応しています。

## 必要環境

- AviUtl ExEdit2（`.anm2` 形式のスクリプトが読める本体）
- 追加のプラグインやモジュールは**不要**です。ファイル1個で動きます

## インストール

1. [Releases](../../releases) から `@ImageLoopKai.anm2` をダウンロードする
2. `C:\ProgramData\aviutl2\Script` へ置く
3. AviUtl2 を再起動する（または「キャッシュを破棄」）

ファイル名は**変えずにそのまま**置いてください。
中で宣言している `@画像ループ改` が効果の名前になります。

## 使い方

1. 画像・図形・テキストなどのオブジェクトを置く
2. **フィルタ効果の追加 → 配置 → 画像ループ改**

## パラメータ

| 項目 | 内容 |
| --- | --- |
| 範囲 | `回数指定`: 横回数×縦回数ぶんだけ並べる / `画面全体`: 画面を埋め尽くす |
| 横回数 / 縦回数 | 回数指定のときの枚数（1〜100） |
| タイル拡大率 | タイル1枚の大きさ（%） |
| 間隔X / 間隔Y | タイルの中心どうしの距離を、タイルの大きさに対する % で指定。`0` = 全部ぴったり重なる / `100` = すき間なく接する / `200` = タイル1枚ぶん空く |
| ループ毎拡大率 | 基準のタイルから1つ離れるごとに大きさを何倍にするか（%）。`100` で変化なし |
| 拡大の向き | ループ毎拡大率の基準。`中心から外へ` / `左から右へ` / `上から下へ` |
| 速度X / 速度Y | スクロール速度（px/秒） |
| オフセットX / オフセットY | 並び全体のずらし量。画面上でドラッグも出来ます |
| 行ずらし / 列ずらし | 奇数行(列)をセルの何 % ずらすか。レンガ積みなどに |
| 反転 | `なし` / `左右交互` / `上下交互` / `上下左右交互` |
| 整数座標に丸める | タイルの境目ににじみが出る場合に ON |

## 仕組みとメモ

- 出力サイズのキャンバスを `tempbuffer` に用意し、必要な範囲のタイルを `obj.drawpoly` で描いてから
  オブジェクトの画像を置き換えています
- 反転やずらしは「絶対タイル番号」の偶奇で決めるので、スクロールしても模様が入れ替わりません
- 回数指定のときは、ちょうど 横回数×縦回数 枚だけを描きます。スクロールではみ出した分は反対側から回り込みます
- タイルが細かすぎる場合は、偶数×偶数枚の「ブロック」を1枚描いてそれを並べる2段階描画に切り替えます
- 描く枚数・面積に上限があるので、拡大率を極端に小さくしたりループ毎拡大率を極端にしても固まりません
  （代わりに、極端な設定では端が欠けることがあります）

## ファイル構成

```
script/@ImageLoopKai.anm2   スクリプト本体（1ファイル）
```
