# Unmult

## is何

* Knoll UnMultと同様な動きをするエフェクトです
* 黒背景、または白背景に重ねられた画像からα値を復元します

## ダウンロード

* Releasesからzipをダウンロードしてください

## インストール

* ダウンロードしたzipを解凍し、Unmult.anm2をスクリプトフォルダにコピーします

## アンインストール

* Unmult.anm2をスクリプトフォルダから削除します

## 使用方法

* アニメーション効果からUnmultを適用します

### パラメーター

* 背景色
    * 何色の背景に重ねられたものとして処理するかを指定します
