ブラウザ表示（AviUtl2Browser_H）のコンテンツ置き場

このフォルダに、index.html を置いたフォルダか、それを zip にして拡張子を .abc にしたファイルを置きます。
原作 aviutl_browser 向けのコンテンツもそのまま使えます（.abc はこのフォルダへ、呼び出し用の .obj / .anm は一つ上の browser フォルダへ）。

汎用オブジェクト「ブラウザ表示」では、ここに無いコンテンツも「コンテンツ」で直接選べます。
コンテンツの作り方は原作の README（https://github.com/oov/aviutl_browser）と同じです。
