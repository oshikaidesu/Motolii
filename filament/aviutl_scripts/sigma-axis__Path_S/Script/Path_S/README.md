## 導入方法

ダウンロードした `aviutl2_script_Path_S-v*.**.au2pkg.zip` を AviUtl2 のウィンドウにドラッグ & ドロップしてください．

初期状態だと「オブジェクトを追加」や「フィルタ効果を追加」メニューの「Path_S」以下に各種オブジェクトやフィルタ効果などが追加されています．
- 「オブジェクト追加メニューの設定」や「トラックバー移動メニューの設定」の「ラベル」項目で分類を変更できます．

##  パラメタの説明

追加されるオブジェクトやフィルタ効果には一部，共通した設定項目があります．

それに加えて各オブジェクトやフィルタごとに固有の項目もあります．

### 共通の設定項目

####  頂点数

パスに含まれる "頂点" の個数を指定します．

- [「線タイプ」](#線タイプ)が `折れ線`，`補間移動` の場合 :arrow_right: 指定する点の個数がそのまま "頂点" の数．
- 「線タイプ」が `2次ベジェ曲線`，`3次ベジェ曲線` の場合 :arrow_right: 制御点を除いた点の個数が "頂点" の数．

最小値は 2 (主に線を描画するもの) または 3 (主にパス内部を描画するもの), 初期値は 4.

####  線タイプ

パスの曲線の形状を指定します．

| 線タイプ | 例 | 備考 |
|:---:|:---:|:---|
| `折れ線` | ![折れ線の例](https://github.com/user-attachments/assets/194f2213-9d25-44e6-a710-fbea72aa4f09) |  |
| `補間移動` | ![補間移動の例](https://github.com/user-attachments/assets/9c5d575d-0211-4d6d-9fa7-0f6bd605c5e9) | トラックバー移動方法の「補間移動」と同じ計算式． |
| `2次ベジェ曲線` | ![2次ベジェ曲線の例](https://github.com/user-attachments/assets/96fb023e-2243-4b0e-b3d4-db04d3745da5) | |
| `3次ベジェ曲線` | ![3次ベジェ曲線の例](https://github.com/user-attachments/assets/a3563699-19e5-4ab8-9267-613989b88fa7) |初期値． |

初期値は `3次ベジェ曲線`.

####  点リスト

アンカーで操作した点がここに記録されます．基本的に手入力による設定は想定していません．

この項目をコピーして，[「頂点数」](#頂点数)[「線タイプ」](#線タイプ)も合わせると，同じパスを別オブジェクト・フィルタ効果で再現できます．

####  アンカー基準

*フィルタ効果のスクリプトでの設定です．*

アンカー位置の基準点を選びます．次の選択肢があります:

| アンカー基準 | 説明 |
|:---:|:---|
| `回転中心` | オブジェクトの回転中心． |
| `左上` | 画像の左上の端 |
| `上` | 画像の上の端 |
| `右上` | 画像の右上の端 |
| `左` | 画像の左の端 |
| `中央` | 画像の中央の端 |
| `右` | 画像の右の端 |
| `左下` | 画像の左下の端 |
| `下` | 画像の下の端 |
| `右下` | 画像の右下の端 |

初期値は `中央`.

####  曲線精度

曲線を描画する際，一旦折れ線で近似しますが，その近似精度を指定します．指定した数値分のピクセル数以下の距離間隔の折れ線で近似します．

最小値は 1, 最大値は 128, 初期値は 8.

####  スナップ設定

アンカーで指定した位置を，特定の座標や角度で揃えます．初期値状態だとスナップは無効です．

> [!IMPORTANT]
> 実際のアンカー位置を記録先である[「点リスト」](#点リスト)はこのスナップの影響を受けません．ここでのスナップ設定は，この「点リスト」とスナップ設定をもとに，描画の前処理として点の位置を再調整する機能です．
>
> なので例えば，スナップが有効の状態でアンカー位置を調整し，そのあとでスナップを無効にしたりスナップ設定を変えたりすると，アンカーを動かしていなくても描画結果が変わることがあります．
>
> また，この設定は [`PI`](#pi) で上書きできません．`PI` で上書きした「点リスト」に対しても影響しません．

次の設定項目があります:

- **グリッド**

  格子状にスナップします．ベジェ曲線の場合は制御点以外がスナップの対象です．

  次の選択肢があります:

  - `なし`
  - `横のみ`
  - `縦のみ`
  - `縦横`

  初期値は `なし`.

- **間隔X** / **間隔Y**

  「グリッド」が `なし` 以外の場合に有効．グリッドでのスナップの間隔を X, Y それぞれでピクセル単位で指定します．

  最小値は 1, 最大値は 1000, 初期値は 40.

- **グリッド表示**

  「グリッド」が `なし` 以外で，対象オブジェクトが選択中の場合に有効．スナップするグリッドをプレビュー画面に表示します．この設定は動画出力には影響しません．

  初期値は OFF.

- **隣との角度**

  隣の点からの角度でスナップします．ベジェ曲線の場合，制御点以外に有効です．

  次の選択肢があります:

  - `なし`

    スナップしません．

  - `90°` / `45°` / `30°` / `15°` / `5°`

    隣の点からの角度を指定した角度の倍数に揃えます．

  計算手順の問題で，アンカー順序の影響を受けます．基本的には直前の点との角度のみでスナップします．ループしている場合，最後の点は直前の点に加えて最初の点との角度も考慮します．

  初期値は `なし`.

- **制御点の角度**

  ベジェ曲線の場合でかつ，制御点のみに有効です．制御点を角度でスナップします．加えて 0 長の制御点になるようにもスナップします．

  次の選択肢があります:

  - `なし`

    スナップしません．

  - `90°` / `45°` / `30°` / `15°` / `5°`

    角度を指定した角度の倍数に揃えます．

  初期値は `なし`.

- **隣の制御点**

  ベジェ曲線の場合でかつ，制御点のみに有効です．同じ点から伸びている隣の制御点と角度や長さを揃えます．

  次の選択肢があります:

  - `なし`
  - `角度`
  - `長さ`
  - `角度と長さ`

  計算手順の問題で，アンカー順序の影響を受けます．基本的には「前の点から出発する」方向を指定する制御点のみがスナップの対象で，「前の点に入る」制御点に合わせます．ループしている場合，「ループの始点に入る」制御点も，「ループの始点から出発する」制御点にスナップします．

  初期値は `なし`.

- **スナップ距離*

  スナップする際の距離のしきい値をピクセル単位で指定します．この距離より近い場合にスナップします．

  最小値は 0, 最大値は 200, 初期値は 8.

- **塗り透明度**

### パスマスクσ / パスマスク(ライン)σ / パス部分フィルタσのパラメタ

####  強さ

*「パスマスクσ」と「パスマスク(ライン)σ」のみの項目です．*

マスクによる影響の強さを指定します．

% 単位で指定，最小値は 0, 最大値は 100, 初期値は 100.

####  反転

フィルタ効果の影響する範囲を反転します．

初期値は OFF.

> [!TIP]
> 「パスマスクσ」において，[「範囲」](#範囲--塗り範囲)を `内側反転` や `奇偶反転` にした場合とは影響が異なり，[「追加幅」](#追加幅--塗り追加幅)を変化させたときに膨張する方向が変わってきます．

####  移動X / 移動Y / 拡大率 / 回転

指定したパスを，各頂点を操作せず拡大・回転・平行移動することができます．

[「アンカー切り替え」](#アンカー切り替え)が ON の場合，「移動X」と「移動Y」をアンカーによるマウス操作でも動かせるようになります．

- **移動X / 移動Y**

  平行移動の量をピクセル単位で指定します．

  最小値は -4000, 最大値は 4000, 初期値は 0.

- **拡大率**

  % 単位で指定，最小値は 0, 最大値は 5000, 初期値は 100.

- **回転**

  時計回りの度数単位で指定，最小値は -3600, 最大値は 3600, 初期値は 0.

####  アンカー切り替え

プレビュー画面のアンカーを，[「点リスト」](#点リスト)の操作と，[「移動X」と「移動Y」](#移動x--移動y--拡大率--回転)の操作とで切り替えます．

- OFF の場合は「点リスト」のアンカーを表示・操作．
- ON の場合は「移動X」と「移動Y」のアンカーを表示・操作．

初期値は OFF.

- この項目は [`PI`](#pi) による操作ができません．

####  追加のフィルタ効果 / 追加スクリプト

*「パス部分フィルタσ」のみの項目です．*

パスで囲った範囲に適用するフィルタを，後続フィルタかスクリプトでの直接記入かを選びます．

- **追加のフィルタ効果**

  | 追加のフィルタ効果 | 説明 |
  |:---:|:---|
  | `後続フィルタ` | 「パス部分フィルタσ」よりも後に配置したフィルタ効果を適用します． |
  | `スクリプト実行` | 直下のスクリプト記入欄 (「追加スクリプト」) に記述されたスクリプトを実行します． |

  - `後続フィルタ` 指定のとき[「追加フィルタここまで」](#追加フィルタここまで)がある場合，そこよりも前のフィルタ効果が対象になります．

  初期値は `後続フィルタ`.

- **追加スクリプト**

  「追加のフィルタ効果」で `スクリプト実行` を選んだ場合に有効です．ここに記述されたスクリプトが，パスで囲った範囲に対して適用されます．

  初期値はサンプルとして次を記述しています:

  ```lua
  obj.effect("グラデーション",
    "形状","凸形",
    "角度",30,
    "開始色",0x00ff00) -- グラデーション適用
  obj.cx=obj.cx+100 -- 位置もずらせる
  ```
  - 「追加スクリプト」は [`PI`](#pi) による操作ができません．

### パスに沿って配置σのパラメタ

####  位置

オブジェクトを配置する位置を，パス全体の長さからの割合で % 単位で指定します．[「ループ」](#ループ)が ON の場合，0 % を下回った分はパスの終了点から，100 % を上回った分はパスの開始点からカウントされます．

最小値は -200, 最大値は 200, 初期値は 0.

####  回転

オブジェクトの回転角度を指定します．

時計回りの度数法で指定，最小値は -3600, 最大値は 3600, 初期値は 0.

####  パスに沿って回転

オブジェクトの角度をパスに沿って調整します．

初期値は ON.

####  個別位置ズレ

個別オブジェクトのときにのみ有効な設定です．個別オブジェクトそれぞれの配置間隔を，パス全体の長さからの割合で % 単位で指定します．

最小値は -200, 最大値は 200, 初期値は -5.

####  範囲外

[「位置」](#位置)や[「個別位置ズレ」](#個別位置ズレ)による計算で，開始点より前や終了点より後ろになった場合の処理を指定します．

1.  `非表示` :arrow_right: 開始点より前や終了点より後ろの場合は表示しません．
1.  `始点のみ表示` :arrow_right: 開始点より前の場合，開始点に表示します．終了点より後ろの場合は表示しません．
1.  `終点のみ表示` :arrow_right: 開始点より前の場合は表示しません．終了点より後ろの場合，終了点に表示します．
1.  `表示` :arrow_right: 開始点より前や終了点より後ろの場合，それぞれ開始点や終了点に表示します．

- [「ループ」](#ループ)が OFF のときのみ有効な設定です．

初期値は `非表示`.

####  パスの表示

設定したパスを点線で表示します．動画出力時にはやプレビュー時にはこの点線は表示されません．

初期値は OFF.

- この項目は [`PI`](#pi) による操作ができません．

### 輪郭パスσのパラメタ

####  対象

輪郭線の選び方を指定します．次の選択肢があります:

| 対象 | 説明 |
|:---:|:---|
| `1個` | アンカーで指定した点に近い輪郭線 1 つだけが対象．アンカーは時間経過で動かせる． |
| `複数` | アンカーで指定した点に近い輪郭線が対象．アンカーは複数指定可能． |
| `全て` | 画像内の全ての輪郭線が対象． |

また，[「開始位置」や「終了位置」](#開始位置--終了位置)に影響する輪郭線の開始点は次の通りです:

- `1個` または `複数` の場合，アンカーに近い点が開始点．
- `全て` の場合，輪郭の最も上段にある点のうち，一番左．

初期値は `1個`.

####  X / Y / 対象個数 / 点リスト

[「対象」](#対象)が `1個` または `複数` のときに，輪郭線をアンカーで選びます．

- **X / Y**

  [「対象」](#対象)が `1個` の場合に有効，アンカーの位置をピクセル単位で指定します．

  最小値は -4000, 最大値は 4000, 初期値は $(0, 0)$.

- **対象個数**

  [「対象」](#対象)が `複数` の場合に有効，選択する輪郭線の個数を指定します．

  初期値は 2.

- **点リスト**

  [「対象」](#対象)が `複数` の場合に有効，アンカーで操作した点がここに記録されます．基本的に手入力による設定は想定していません．

  - 点の個数は [「対象個数」](#対象個数)で指定します．

  初期値は `-100,0,100,0`.

検出する輪郭線は，指定した点から上下左右の 4 方向を探索して最も近くに見つかったものになります．また，アンカーはオブジェクトの不透明部分に置く必要があります．

####  αしきい値 / 角で隣接扱い

オブジェクトの輪郭線を抽出する際の設定です．

- **αしきい値**

  輪郭線になるアルファ値の境界を % 単位で指定します．

  最小値は 0, 最大値は 100, 初期値は 50.

- **角で隣接扱い**

  ON の場合，角で隣接している不透明ピクセルがつながっているとみなします．

  - [Region_S の「角で隣接扱い」](https://github.com/sigma-axis/aviutl2_script_Region_S#角で隣接扱い)と同等の設定項目です．

  初期値は OFF.

####  境界精度

境界を折れ線で近似する際の精度を調整します．数値が小さいほど精度が高くなり，折れ線の頂点数や処理時間が増えます．

複数の頂点が同一直線状にあるとみなして折れ線を簡略化する際の限界距離を，ピクセルの % 単位で指定します．

最小値は 10, 最大値は 200, 初期値は 50.

####  時計回りに揃える

通常は輪郭線の頂点は時計回りですが，「穴」を囲う輪郭線は反時計回りです．これを全て時計回りに揃えるかどうかを指定します．

初期値は ON.

####  モード / 合成モード / 元画像透明度

輪郭線のパスと元画像の合成方法を指定します．

- **モード**

  元画像との前後関係を指定します．

  - `前方から合成`: 元画像の上に輪郭線のパスを描画します．
  - `後方から合成`: 輪郭線のパスの上に元画像を描画します．

  初期値は `前方から合成`.

- **合成モード**

  描画の際の合成モードを指定します．

  初期値は `通常`.

- **元画像透明度**

  合成の際の元画像の透明度を % 単位で指定します．

  最小値は 0, 最大値は 100, 初期値は 0 (完全不透明).

####  追加のフィルタ効果 / 追加スクリプト

合成前にパス部分に対して追加のフィルタ効果を適用することができます．指定方法は[「パス部分フィルタσの追加のフィルタ効果 / 追加スクリプト」](#追加のフィルタ効果--追加スクリプト)と同様です．

- **追加のフィルタ効果**

  `なし`, `後続フィルタ`, `スクリプト実行` の 3 つから選択できます．

  - `後続フィルタ` 指定のとき[「追加フィルタここまで」](#追加フィルタここまで)がある場合，そこよりも前のフィルタ効果が対象になります．

  初期値は `なし`.

- **追加スクリプト**

  「追加のフィルタ効果」で `スクリプト実行` を選んだ場合に有効です．ここに記述されたスクリプトが，パスの画像に対して適用されます．

  初期値は[「パス部分フィルタσの追加スクリプト」](#追加スクリプト)と同じです．

  - 「追加スクリプト」は [`PI`](#pi) による操作ができません．

### `PI`

- 一部は別スクリプトからの利用を想定した項目になっています．利用する場合は `Path_S.lua` を `require` して，その API も併用してください．

##### スクウェアσの `PI` の `radii`

> [!NOTE]
> [Basic_S の「四隅丸め」の `PI` の `radii`](https://github.com/sigma-axis/aviutl2_script_Basic_S/wiki/四隅丸め#pi-の-radii) と同じ形式です．

次の形式が指定できます:

1.  number 型 / `{ uniform = r }` の table 型

    四隅の半径を一律に指定．[「丸角縦横比」](#丸角縦横比)は `0` 指定に相当 (真円).

1.  `{ uniform = { x, y } }` の形式の table 型

    四隅の半径を，横幅が `x`, 高さが `y` になるように一律に指定 (楕円).

1.  `{ r1, r2, r3, r4 }` の形式の table 型

    四隅の半径を独立に指定．[「丸角縦横比」](#丸角縦横比)は `0` 指定に相当 (真円).

1.  `{ { x1, y1 }, { x2, y2 }, { x3, y3 }, { x4, y4 } }` の形式の table 型

    四隅の半径を，横幅が `x1`, ..., 高さが `y1`, ... になるように独立に指定．

角の指定順序は左上から時計回りです．また，上記の指定法は混在させることもできます:
```lua
radii = { uniform = 10; { 16, 8 }, nil, 20, nil }
```
- 左上は $16 \times 8$, 右上は $10 \times 10$, 右下は $20 \times 20$, 左下は $10 \times 10$.

##  同梱のスクリプトファイル `Path_S.lua` について

他スクリプトからの利用も想定したものになっていて，`local path_s = require("Path_S")` から各種 API を呼び出せます．

「パスマスクσ」「パスマスク(ライン)σ」に関しては `obj.effect(...)` を使わずとも `path_s.path_mask_area(...)` や `path_s.path_mask_line(...)` から適用できます．各種パスの曲線を折れ線に変換するなどといった API も用意しています．

`Path_S.lua` にドキュメントコメントを残しているので，詳しい仕様はそちらを参照してください．

##  既知の問題

1.  [「パス部分フィルタσ」](#パス部分フィルタσ)では，一部のフィルタ効果は後続に置いたり，スクリプトで呼び出しても「部分的に適用」されるような挙動にはなりません．

    - 「ランダム配置」や「球体(カメラ制御)」など，フレームバッファに直接描画したり，カメラ制御を前提としたり，配置を変えるフィルタ効果などが当てはまることが多いです．

    - 個別オブジェクト化するフィルタ効果に対しても正しく動作しません．

### 非推奨化されたスクリプト

以下は今は非推奨なスクリプトで，メニューからは追加できなくなっています．これらを利用しているプロジェクトなどでは引き続き機能しますが，新しい方法に移行するのを推奨します．

- **パス部分フィルタσここまで**

  [「輪郭パスσ」](#輪郭パスσ)の追加に伴って，[「追加フィルタここまで」](#追加フィルタここまで)を利用するように統合．
