# Mathy_Su for AviUtl2

数学的な曲線を AviUtl2 で自在に操るためのアニメーション効果セットです。
従来のカスタムオブジェクト版 (`obj2`) は廃止され、すべてアニメーション効果 (`anm2`) に統合されました。

## 主な機能

- **豊富な曲線**: 螺旋、代数曲線、サイクロイド、多角形など多数対応。
- **透明度制御**:
    - **元画像透明度**: 親オブジェクト自体の透明度を制御します。
    - **線透明度**: 描画される線の透明度を独立して制御します。これを 100 にし、元画像を 0 にすることで「線のみ」を描画可能です。
- **Z軸拡張**: 2次元の曲線に奥行きを与え、3D空間での演出が可能。
- **線表示機能**: オブジェクトの軌跡を線として描画可能（「線透明度」トラックバーで制御）。
- **位置置換 / 線上に配置**: オブジェクトを動かすか、パスを相対位置として扱うかを選択可能。
- **配置位置とシフト**: `配置位置` でパス上の移動、`シフト` で起点（0%地点）のずらしが可能です。
- **ヘルプ表示**: スクリプト内からパラメータの意味、公式、形状の特徴、PIキーを確認可能。
- **パラメータインジェクション (PI)**: トラックバーの制限を超えた値を外部から注入可能。

- 双曲螺旋 (Hyperbolic Spiral)

- 双曲線関数 (Hyperbolic Function)
- 分数関数 (Rational Function)

## 使い方

1.  AviUtl2 の「アニメーション効果」から `Mathy_Su` を選択します。
2.  各トラックバーでパラメータを調整します。
    - ほとんどのパラメータは最大 `10000` まで、`0.01` 刻みで調整可能です。
    - `配置位置` および `シフト` は **％単位 (0〜10000%)** です。`100` でパスの一周分となります。
    - `元画像透明度` と `線透明度` を使うことで、オブジェクトと線の表示を自在に切り替えられます。
3.  詳細なパラメータの説明、形状の特徴、PI のキーを確認したい場合は `Help` をオンにしてください。
4.  トラックバー以上の値を設定したい場合は、テキストボックスに PI 形式（例: `{ a=50000 }`）で記述してください。

## インストール
`c:\AviUtl2\data\Script\Suzuke\` に以下のファイルを配置してください：
- `@Mathy_Su.anm2`
