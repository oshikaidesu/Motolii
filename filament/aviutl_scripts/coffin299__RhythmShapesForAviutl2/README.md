# RhythmShapes for AviUtl2

AviUtl ExEdit2 の中で、音声の拍や音量に合わせて円、四角、三角、多角形、線を動かすカスタムオブジェクトです。スペクトラム表示ではなく、リズムに合わせて図形が出て、拡大し、回転し、移動するモーショングラフィックスを1つのオブジェクトで作れます。

## 機能

- BPMグリッド、手動BPM、音声からの打音検出
- 低音、中音、高音、全体音量による動き
- Scatter、Grid、Orbit、Radial の配置
- 塗りとアウトライン
- 6つのプリセットと、項目を自分で割り当てるカスタム

図形はスクリプトが頂点を計算して描きます。外部のSVGや画像素材はありません。

## 対応環境

- AviUtl ExEdit2 2.1.14
- Windows 10 64bit 以降

## 使い方

1. タイムラインに音声を置く。
2. メディアオブジェクトから RhythmShapes を追加し、画面中央に置く。
3. 初期プリセットはフラット図形です。空色の背景に、白い矩形・円・三角・縦棒・鍵盤状の格子が組まれ、帯域と拍でわずかに伸びます。
4. 拍に正確に合わせるときは、同期方式を BPMグリッド にし、AviUtl2 のグリッドへ BPM を設定する。グリッドが無いときは手動BPMとオフセットを使う。
5. 個数、サイズ、色、拡大、回転、移動、減衰は、プリセットを選んだあとでもトラックバーで変えられる。

オブジェクトの長さを、動かしたい区間に合わせます。再生を途中から始めても、位置と拍は時刻から計算し直します。

## 設定

### 同期

- 同期方式: BPMグリッド / 手動BPM / 自動検出
- 拍分割: 1、2、4、8
- BPM とオフセット: グリッドが空のときの拍、または手動の拍。オフセットはミリ秒
- 検出感度、最小間隔、低音・中音・高音の重み: 自動検出の打音判定

自動検出のとき、BPM と拍分割は隠れる。グリッドと手動のとき、検出の項目は隠れる。

### 図形

- プリセット
- 図形と配置。カスタム以外ではプリセットが決めるため隠れる
- 個数（最大 64）、サイズ、色、塗り、アウトライン、線幅、透明度、頂点数、シード

シードが同じなら、Scatter と Radial の位置はシークしても変わらない。

### アニメーション

- 拡大、回転、移動、減衰、強拍強調
- イージングと、拡大・回転・移動・透明度・色・線幅の反応先。カスタムのときだけ表示する

反応先は、拍、強拍、音量、低音、中音、高音、打音です。詳細は [docs/motion.md](docs/motion.md) にあります。

### 詳細

計測ログをオンにすると、音量、拍、処理時間を AviUtl2 のログへ1フレームずつ出します。書き出し中はログが増えるので、普段はオフのままにします。

## プリセット

| 名前 | 内容 |
| --- | --- |
| Beat Burst | 打音で図形が跳ねる |
| Geometric Orbit | 円周上の図形が回転する |
| Rhythm Grid | 格子が拍に合わせて動く |
| Bass Pulse | 低音で図形が膨張する |
| Minimal Motion | 小さい三角の格子 |
| フラット図形 | 白い幾何学の構図が帯域でわずかに伸びる |

追加方法は [docs/presets.md](docs/presets.md) にあります。

## 既知の制約

- 打音検出は、そのフレームで取得した音声窓だけを見る。`obj.getaudio` に過去の任意時刻を指定する引数は、2.1.14 の `lua.txt` に無い。
- 窓の長さは最大 8192 サンプルである。自動推定の BPM は参考値で、動きには使わない。短い窓では推定できないことが多い。
- `spectrum` の周波数軸は、フーリエが取れないときの仮定であり、公式には等間隔とは書かれていない。
- シーン時刻は `(frame_s + frame) / framerate` として BPM の `start` と比べる。この対応は文書にあるフィールドからの組み立てで、実機のグリッドと一致することは未確認である。
- `--require` は付けていない。別の AviUtl2 が起動中で、プレーンな 2.1.14 の `obj.getinfo("version")` を読めなかった。
- 同じ理由で、音声の値域、フーリエの本数、BPMリストとシーン時刻の対応、`script_time`、プレビューと書き出しの画素一致、長時間の負荷は未測定である。図形数 64、PCM 8192、描画バッファ一辺 3840 は実測前の初期値である。
- 星やハートなどの装飾図形は無い。
