# 放射クリッピング

オブジェクトを放射状に区切り、指定した割合の領域を透明にするスクリプトです。

## パラメーター

| パラメーター (単位) | 範囲 | 初期値 | 説明 |
|---|---:|---:|---|
| 数 (個) | 1 ~ 100 | 4 | 放射状に分割する区間の数 |
| 基準角 (°) | 0 ~ 360 | 0 | クリッピングの基準となる角度 |
| 割合 (%) | 0 ~ 100 | 50 | 各区間のうち、透明にする角度の割合 |

## 仕様

- オブジェクトの中央を基準に、放射状にクリッピングします。
- 各区間は同じ角度幅になります。
- 各区間のうち、指定した割合を透明にし、残りを表示します。
- 基準角が 0° の場合、右方向を中心とした領域が透明になります。
- 基準角は時計回りに指定します。
- 透明領域と表示領域の境界には、アンチエイリアスが適用されます。

## 割合の例

- 0% : クリッピングせず、すべて表示します。
- 50% : 各区間の半分を透明にします。
- 100% : すべて透明にします。
