##  アクリルσ

オブジェクトの半透明部分を，磨りガラスのように背景をぼかして透過しているような見た目にします．

![アクリルσのデモ](https://github.com/user-attachments/assets/1481730c-0b80-49e7-adb1-4dfc5b921bfe)

### アクリルσのパラメタ

####  基準透明度 / 基準色

アクリル背景にする部分の透明度と色を指定します．

![基準透明度の適用例](https://github.com/user-attachments/assets/2c8b435a-9767-4c97-b541-046d19335bad)

- **基準透明度**

  アクリル背景にするピクセルの透明度を % 単位で指定します．半透明処理の基準となって，以下のように処理されます．

  - 「基準透明度」と同じ透明度のピクセル
    - アクリル背景になります．
    - 元のピクセルの色情報は無視されます．
    - オブジェクトのピクセルとしては完全不透明になります．
  - 「基準透明度」より不透明なピクセル
    - アクリル背景に元オブジェクトの情報が描画された見え方になります．
    - 元のピクセルの色情報は，アクリル上の描画物として反映されます．
    - オブジェクトのピクセルとしては完全不透明になります．
  - 「基準透明度」より透明なピクセル
    - 境界部分のアンチエイリアスによる半透明部分という扱いになり，半透明なアクリル背景になります．
    - 元のピクセルの色情報は無視されます．
    - オブジェクトのピクセルとしては半透明になります．

  最小値は 0, 最大値は 100, 初期値は 100.

- **基準色**

  基準となる半透明ピクセルに描画されたと想定される色の計算に使われます．省略可能．

  - アクリル背景にしたい部分が単色の場合に指定すると，フリンジが抑えられます．
  - 指定した場合でも，指定色以外の色の半透明部分にはフリンジが発生することがあります．

  ![基準色の適用例](https://github.com/user-attachments/assets/05f9328d-df01-4f96-bf7e-693bebbabc0d)

  初期値は `未指定`.

####  透過輝度 / 輝度補正 / 透過彩度

背景がアクリル部分に映り込む際の色調を補正します．

- **透過輝度**

  背景の明暗の変化が反映される割合を % 単位で指定します．

  最小値は 0, 最大値は 200, 初期値は 50.

- **輝度補正**

  アクリル部分の輝度を調整します．輝度に指定値が加算されます．% 単位で指定．

  最小値は -100, 最大値は 100, 初期値は 0.

- **透過彩度**

  背景の色彩の変化が反映される割合を % 単位で指定します．

  最小値は 0, 最大値は 200, 初期値は 100.

####  着色 / 着色輝度 / 着色彩度

アクリル部分に指定色で着色できます．

- **着色**

  初期値は `4050ff` (青).

- **着色輝度**

  指定色の輝度が反映される割合を % 単位で指定します．

  最小値は 0, 最大値は 100, 初期値は 0.

- **着色彩度**

  指定色の色彩が反映される割合を % 単位で指定します．

  最小値は 0, 最大値は 100, 初期値は 0.

####  範囲 / 縦横比 / 光の強さ

アクリル部分に映り込む背景をぼかします．[Basic_S の「小数ぼかし」](https://github.com/sigma-axis/aviutl2_script_Basic_S/wiki/小数ぼかし)の設定項目と同等です．(ぼかしは三角分布で処理されます．)

- **範囲**

  ぼかしの大きさをピクセル単位で指定します．

  最小値は 0, 最大値は 1000, 初期値は 20.

- **縦横比**

  ぼかしの縦横比を % 単位で指定します．正だと縦方向の範囲が縮小，負だと横方向の範囲が縮小します．

  最小値は -100, 最大値は 100, 初期値は 0.

- **光の強さ**

  ピクセルの輝度成分の重みを強くします．大きくすると明るいピクセルがより強調されたぼかし結果になります．

  最小値は 0, 最大値は 60, 初期値は 0.

####  ノイズ / シード / ドットサイズ

アクリル部分にノイズを乗せて，ザラザラした質感を表現することができます．

- **ノイズ**

  ノイズの強さを，ノイズによる輝度の変化量として % 単位で指定します．

  最小値は 0, 最大値は 100, 初期値は 4.

- **シード**

  ノイズのランダムさを決定するシードを指定します．

  - 0 以上だと同じシードでも別オブジェクトだと別の乱数になります．
  - 負だと同じシードなら別オブジェクトでも同じ乱数になります．

  最小値は -65536, 最大値は 65535, 初期値は 10000.

- **ドットサイズ**

  ノイズの拡大率を % 単位で指定します．

  最小値は 100, 最大値は 6400, 初期値は 100.

####  移動X / 移動Y / 拡大率 / 回転 / 画面基準で配置

透過した背景に対して，平行移動 / 拡大縮小 / 回転を設定できます．

回転・拡大の中心はアンカー位置です．

- **移動X/Y**

  平行移動量をピクセル単位で指定します．プレビュー画面のアンカーを操作することでも指定できます．

  最小値は -4000, 最大値は 4000, 初期値は 0.

- **拡大率**

  拡大率を % 単位で指定します．

  最小値は 1, 最大値は 10000, 初期値は 100.

- **回転**

  回転角度を度数法で指定します．

  最小値は -1440, 最大値は 1440, 初期値は 0.

- **画面基準で配置**

  上記の各種操作の基準点 (アンカーの初期位置) を変更します．
  
  - OFF の場合は，オブジェクトの回転中心．
  - ON の場合は，画面の中央．

  初期値は OFF.

####  背景色

オブジェクトの背景に透明ピクセルがある場合に有効な設定です．

この場合アクリル部分も半透明になり，背景の一部分が透けてそのまま表示されてしまうことがあります．不透明な背景色で覆うことで隠す目的で指定します．

![背景色の適用例](https://github.com/user-attachments/assets/d03c88fc-026c-4a3f-92be-c2a9f5425d4a)

初期値は `未指定`.

####  PI

パラメタインジェクション (parameter injection) です．初期値は空欄. テーブル型の中身として解釈され，各種パラメタの代替値として使用されます．また，任意のスクリプトコードを実行する記述領域にもなります．

```lua
{
  base_alpha = num,       -- number 型で "基準透明度" の項目を上書き，または nil.
  base_color = num_false, -- number 型で "基準色" の項目を上書き，false で未指定，または nil.
  mul_luma = num,         -- number 型で "透過輝度" の項目を上書き，または nil.
  add_luma = num,         -- number 型で "輝度補正" の項目を上書き，または nil.
  mul_chroma = num,       -- number 型で "透過彩度" の項目を上書き，または nil.
  tint_color = num,       -- number 型で "着色" の項目を上書き，または nil.
  tint_luma = num,        -- number 型で "着色輝度" の項目を上書き，または nil.
  tint_chroma = num,      -- number 型で "着色彩度" の項目を上書き，または nil.
  blur = num,             -- number 型で "blur::範囲" の項目を上書き，または nil.
  blur_aspect = num,      -- number 型で "blur::縦横比" の項目を上書き，または nil.
  blur_luma_weight = num, -- number 型で "blur::光の強さ" の項目を上書き，または nil.
  noise_intensity = num,  -- number 型で "noise::ノイズ" の項目を上書き，または nil.
  noise_seed = num,       -- number 型で "noise::シード" の項目を上書き，または nil.
  noise_size = num,       -- number 型で "noise::ドットサイズ" の項目を上書き，または nil.
  move_x = num,           -- number 型で "移動X" の項目を上書き，または nil.
  move_y = num,           -- number 型で "移動Y" の項目を上書き，または nil.
  scale = num,            -- number 型で "拡大率" の項目を上書き，または nil.
  rotate = num,           -- number 型で "回転" の項目を上書き，または nil.
  anchor_screen = bool    -- boolean 型で "画面基準で配置" を上書き，または nil. 0 を false, 0 以外を true として number 型も可能．
  back_color = num_false, -- number 型で "背景色" の項目を上書き，false で未指定，または nil.
}
```
- テキストボックスには冒頭末尾の波括弧 (`{}`) を省略して記述してください．

##  レンズσ

オブジェクトの色や形状から曲面を生成し，ガラス塊がレンズ屈折しているように背景を合成します．

![レンズσのデモ](https://github.com/user-attachments/assets/4e423f21-4ece-4955-b926-eba17cc8ed0e)

### レンズσのパラメタ

####  透過輝度 / 輝度補正 / 透過彩度

「アクリルσ」での[「透過輝度」「輝度補正」「透過彩度」](#透過輝度--輝度補正--透過彩度)やと同等です．

- **透過輝度**

  最小値は 0, 最大値は 200, 初期値は 80.

- **輝度補正**

  最小値は -100, 最大値は 100, 初期値は 0.

- **透過彩度**

  最小値は 0, 最大値は 200, 初期値は 80.

####  表面輝度 / 表面彩度

レンズの表面に元画像の色を反映させます．

- **表面輝度**

  元画像の輝度が反映される割合を % 単位で指定します．

  最小値は 0, 最大値は 200, 初期値は 20.

- **表面彩度**

  元画像の色彩が反映される割合を % 単位で指定します．

  最小値は 0, 最大値は 200, 初期値は 80.

####  背景距離

オブジェクトに対する背景の奥行きを調整します．オブジェクトと背景が離れているほど，レンズとしての屈折の影響で離れた点が映り込み，より歪んだ見た目になります．奥行方向のピクセル単位で指定．

最小値は -1000, 最大値は 1000, 初期値は 200.

####  起伏 / 丸み

レンズとしての形状を調整するパラメタです．

- **起伏**

  レンズの凹凸の，奥行き方向の全体的な大きさを調整します．

  後述の[「輪郭起伏」](#輪郭起伏--輪郭丸み)や[「輝度起伏」](#輝度起伏--輝度丸み)，[「色境界起伏」](#色境界起伏--色境界丸み--色境界しきい値)は割合指定になっていて，これらの大きさの基準値です．

  奥行き方向のピクセル単位で指定．レンズとしての厚みにも反映され，大きくすれば，より歪んだ見た目になります．

  最小値は 0, 最大値は 1000, 初期値は 32.

- **丸み**

  レンズの曲面の，横幅 (画面方向 / 水平方向) の全体的な大きさを調整します．

  後述の[「輪郭丸み」](#輪郭起伏--輪郭丸み)や[「輝度丸み」](#輝度起伏--輝度丸み)，[「色境界丸み」](#色境界起伏--色境界丸み--色境界しきい値)は割合指定になっていて，これらの大きさの基準値です．

  また[「平滑化」](#平滑化)による，ぼかし処理でのピクセルサイズにも影響します．

  画面上のピクセル単位で指定．

  最小値は 0, 最大値は 4000, 初期値は 32.

####  輪郭起伏 / 輪郭丸み

レンズとしての形状を調整するパラメタで，アルファ値で決定される部分です．

- **輪郭起伏**

  オブジェクト輪郭部分の，奥行き方向の変化幅を調整します．輪郭部分を楕円柱の形状としたときの，奥行き方向の半径をピクセル単位で，[「起伏」](#起伏--丸み)からの割合として % 単位で指定します．
  
  負の値を指定すると，逆に内部が輪郭部より凹んだ形状になります．

  最小値は -100, 最大値は 100, 初期値は 50.

- **輪郭丸み**

  オブジェクト輪郭部分の曲面の，横幅を調整します．輪郭部分を楕円柱の形状としたときの，画面方向 (上下左右方向 / XY 軸方向 / 水平方向 / 奥行きでない方向) の半径をピクセル単位で，[「丸み」](#起伏--丸み)からの割合として % 単位で指定します．

  最小値は 0, 最大値は 100, 初期値は 50.

####  輝度起伏 / 輝度丸み

レンズとしての形状を調整するパラメタで，輝度で決定される部分です．

- **輝度起伏**

  オブジェクトの輝度変化に応じた，奥行き方向の変化幅を調整します．最小輝度 (黒) と最大輝度 (白) とでのレンズの厚みの差を，奥行き方向のピクセル単位で，[「起伏」](#起伏--丸み)からの割合として % 単位で指定します．

  正の値だと明るい色の部分が厚く，暗い色の部分が薄くなります．負の値だと逆です．

  最小値は -100, 最大値は 100, 初期値は 0.

- **輝度丸み**

  オブジェクトの輝度変化に応じた曲面の，横幅を調整します．輝度変化に対して適用するぼかし処理の「範囲」の 2 倍をピクセル単位で，[「丸み」](#起伏--丸み)からの割合として % 単位で指定します．

  ぼかし処理の「範囲」の最大値による制約上，変化幅は最大 2000 ピクセルです．

  最小値は 0, 最大値は 100, 初期値は 50.

####  色境界起伏 / 色境界丸み / 色境界しきい値

レンズとしての形状を調整するパラメタです．色の境界 (色エッジ) によって決定される部分です．

- **色境界起伏**

  オブジェクトの色境界からの距離に応じた，奥行き方向の変化幅を調整します．色エッジを楕円柱の形状としたときの，奥行き方向の半径をピクセル単位で，[「起伏」](#起伏--丸み)からの割合として % 単位で指定します．

  正の値だと色エッジ部分が窪みます．負の値だと色エッジ部分が上に突き出た形状になります．

  最小値は -100, 最大値は 100, 初期値は 0.

- **色境界丸み**

  オブジェクトの色境界からの距離に応じた曲面の，横幅を調整します．色エッジ部分を楕円柱の形状としたときの，画面方向の半径をピクセル単位で，[「丸み」](#起伏--丸み)からの割合として % 単位で指定します．

  最小値は 0, 最大値は 100, 初期値は 50.

- **色境界しきい値**

  オブジェクトの色変化を検出するしきい値を，% 単位で指定します．隣り合うピクセルの色成分やアルファ値との差が，このしきい値よりも大きい部分を色エッジとして判定します．

  オブジェクトの完全透明な外側部分も，色エッジとして判定されます．

  最小値は 0, 最大値は 100, 初期値は 4.

####  平滑化

屈折や反射，ハイライトなどの計算は，そのままだとジャギーになっているため，滑らかにするための処理が必要です．その際に利用するぼかし処理の強さを調整します．形状がギザギザしている場合に大きくしてみてください．

![平滑化が0と十分大きい場合の例](https://github.com/user-attachments/assets/b599e4fa-f308-4485-8fd3-942892f587e2)

また，レンズ形状の “峰” や “谷” を滑らかにする効果もあります．

最小値は 0, 最大値は 1000, 初期値は 100.

- ぼかし処理の「範囲」のピクセル単位での数値は，次の式で決定します: $m\sqrt{R}$.

  ここに $m$ は「平滑化」の指定値の，% 単位での値． $R$ は[「丸み」](#起伏--丸み)の指定値．

####  形状可視化

編集中に，レンズの凹凸の形状を可視化して確認します．レンズとして厚い部分が明るく，薄い部分が暗く表示されます．

![形状可視化のデモ](https://github.com/user-attachments/assets/0443ed47-8451-4849-be47-8ddbc24ace3e)

- [「背景距離」](#背景距離)と[「平滑化」](#平滑化)の影響は可視化には反映されません．

- このフィルタ効果をオブジェクト設定ウィンドウに表示中の場合のみ有効です．

  他オブジェクトを選択中やプレビュー再生中，動画出力中などでは自動的に無効化されます．

  オブジェクト設定右上の「プレビュー編集の操作をロック」が有効な場合も，自動的に無効化されます．

初期値は OFF.

####  屈折率

レンズとしての[屈折率](https://ja.wikipedia.org/wiki/屈折率)を % 単位で指定します．

最小値は 100, 最大値は 400, 初期値は 150.

####  色収差

[色収差](https://ja.wikipedia.org/wiki/色収差)の効果の強さを調整します．屈折による位置ずれを % 単位で補正します．負の値で色の順序が逆転します．

最小値は -100, 最大値は 100, 初期値は 3.

####  光角度 / 光沢 / ハイライト / シャドウ / 光角度を画面基準

オブジェクトにハイライトや影の効果を付けます．

- **光角度**

  ハイライトの光源の方向を，画面上を 0 とする時計回りで，度数法で指定します．

  「ハイライト」の方向であり，また「シャドウ」の逆方向にもなっています．

  - 光源方向は厳密には，画面方向は「光角度」，奥行き方向は画面の平面から 30° 浮いた，手前から奥の方向へ入射します．

  最小値は -1440, 最大値は 1440, 初期値は -20 (上方向，やや左).

- **光沢**

  反射の鋭さを調整します．高い数値だと，反射範囲は狭いが強い光に，低い数値だと，範囲は広いが弱い光になります．

  「ハイライト」と「シャドウ」の両方に影響します．

  最小値は 0, 最大値は 100, 初期値は 70.

- **ハイライト**

  光源と同じ方向の部分を白く光らせます．光の強さを調整します．

  最小値は 0, 最大値は 400, 初期値は 30.

- **シャドウ**

  光源と逆方向にある透過背景を暗くします．暗くなる強さを調整します．

  最小値は 0, 最大値は 400, 初期値は 30.

- **光角度を画面基準**

  オブジェクトの Z 軸回転や，カメラ制御でのカメラ回転を変化させたとき，光源の向きを画面基準で固定するか動かすかを指定します．

  - OFF だと Z 軸回転やカメラ制御を変化させても，オブジェクトの同じ部分が光ります．(画面基準の方向は変わります．)
  - ON だと Z 軸回転やカメラ制御を変化させても，画面基準の方向は変わりません．(オブジェクトは違う部分が光ります．)

  初期値は OFF.

####  範囲 / 縦横比 / 光の強さ

[「アクリルσ」の対応する設定項目](#範囲--縦横比--光の強さ)と同等です．

- **範囲**

  最小値は 0, 最大値は 1000, 初期値は 0.

- **縦横比**

  最小値は -100, 最大値は 100, 初期値は 0.

- **光の強さ**

  最小値は 0, 最大値は 60, 初期値は 0.

####  ノイズ / シード / ドットサイズ

[「アクリルσ」の対応する設定項目](#ノイズ--シード--ドットサイズ)と類似の設定です．オブジェクト全体にノイズを乗せて，ザラザラした質感を表現することができます．

- **ノイズ**

  最小値は 0, 最大値は 100, 初期値は 0.

- **シード**

  最小値は -65536, 最大値は 65535, 初期値は 10000.

- **ドットサイズ**

  最小値は 100, 最大値は 6400, 初期値は 100.

####  移動X / 移動Y / 拡大率 / 回転 / 画面基準で配置

[「アクリルσ」の対応する設定項目](#移動x--移動y--拡大率--回転--画面基準で配置)と同等です．

- **移動X/Y**

  最小値は -4000, 最大値は 4000, 初期値は 0.

- **拡大率**

  最小値は 1, 最大値は 10000, 初期値は 100.

- **回転**

  最小値は -1440, 最大値は 1440, 初期値は 0.

- **画面基準で配置**

  初期値は OFF.

####  背景色

[「アクリルσ」の対応する設定項目](#背景色)と同等です．

初期値は `未指定`.

####  色収差順序

[「色収差」](#色収差)で分離する光成分の順序を変更できます．選択肢は以下の通り:

- `RGB` (「赤緑青」の順．)
- `GBR` (「緑青赤」の順．)
- `BRG` (「青赤緑」の順．)

なお「色収差」の設定値を正負を反転することで，順序を反転できます．

初期値は `RGB`.

> [!TIP]
> 現実世界では初期値の `RGB` が正しい順序です．

####  PI

パラメタインジェクション (parameter injection) です．初期値は空欄. テーブル型の中身として解釈され，各種パラメタの代替値として使用されます．また，任意のスクリプトコードを実行する記述領域にもなります．

```lua
{
  mul_luma = num,         -- number 型で "透過輝度" の項目を上書き，または nil.
  add_luma = num,         -- number 型で "輝度補正" の項目を上書き，または nil.
  mul_chroma = num,       -- number 型で "透過彩度" の項目を上書き，または nil.
  face_luma = num,        -- number 型で "表面輝度" の項目を上書き，または nil.
  face_chroma = num,      -- number 型で "表面彩度" の項目を上書き，または nil.
  lift = num,             -- number 型で "背景距離" の項目を上書き，または nil.
  lens_amplify = num,     -- number 型で "起伏" の項目を上書き，または nil.
  lens_round = num,       -- number 型で "丸み" の項目を上書き，または nil.
  edge_amplify = num,     -- number 型で "輪郭起伏" の項目を上書き，または nil.
  edge_round = num,       -- number 型で "輪郭丸み" の項目を上書き，または nil.
  luma_amplify = num,     -- number 型で "輝度起伏" の項目を上書き，または nil.
  luma_round = num,       -- number 型で "輝度丸み" の項目を上書き，または nil.
  col_amplify = num,      -- number 型で "色境界起伏" の項目を上書き，または nil.
  col_round = num,        -- number 型で "色境界丸み" の項目を上書き，または nil.
  col_thresh = num,       -- number 型で "色境界しきい値" の項目を上書き，または nil.
  smooth = num,           -- number 型で "平滑化" の項目を上書き，または nil.
  refr_idx = num,         -- number 型で "屈折率" の項目を上書き，または nil.
  chrm_abrr = num,        -- number 型で "色収差" の項目を上書き，または nil.
  light_angle = num,      -- number 型で "光角度" の項目を上書き，または nil.
  refl_power = num,       -- number 型で "光沢" の項目を上書き，または nil.
  refl_light = num,       -- number 型で "ハイライト" の項目を上書き，または nil.
  refl_shadow = num,      -- number 型で "シャドウ" の項目を上書き，または nil.
  light_screen = bool,    -- boolean 型で "光角度を画面基準" を上書き，または nil. 0 を false, 0 以外を true として number 型も可能．
  blur = num,             -- number 型で "blur::範囲" の項目を上書き，または nil.
  blur_aspect = num,      -- number 型で "blur::縦横比" の項目を上書き，または nil.
  blur_luma_weight = num, -- number 型で "blur::光の強さ" の項目を上書き，または nil.
  noise_intensity = num,  -- number 型で "noise::ノイズ" の項目を上書き，または nil.
  noise_seed = num,       -- number 型で "noise::シード" の項目を上書き，または nil.
  noise_size = num,       -- number 型で "noise::ドットサイズ" の項目を上書き，または nil.
  move_x = num,           -- number 型で "移動X" の項目を上書き，または nil.
  move_y = num,           -- number 型で "移動Y" の項目を上書き，または nil.
  scale = num,            -- number 型で "拡大率" の項目を上書き，または nil.
  rotate = num,           -- number 型で "回転" の項目を上書き，または nil.
  anchor_screen = bool    -- boolean 型で "画面基準で配置" を上書き，または nil. 0 を false, 0 以外を true として number 型も可能．
  back_color = num_false, -- number 型で "背景色" の項目を上書き，false で未指定，または nil.
  chrm_abrr_order = str,  -- string 型で "色収差順序" の項目を上書き，または nil.
}
```
- テキストボックスには冒頭末尾の波括弧 (`{}`) を省略して記述してください．

####  PI の `chrm_abrr_order`

指定できる string は以下の通りです:

```lua
"RGB", "GBR", "BRG"
```

##  TIPS

1.  大きい画像に対して適用したときや，[「背景距離」](#背景距離)などが大きい場合などでオブジェクトが正しく表示されず，ログ表示に次の形式のエラーが記録されることがあります:

    ```log
    [SCRIPT] [レンズσ@Lens_S] invalid buffer type. name=cache:lens_s/lens/orig#226
    [SCRIPT] [レンズσ@Lens_S] invalid buffer type. name=cache:lens_s/lens/temp1#226
    ```

    これは AviUtl2 が管理する一時画像キャッシュが足りない場合に起こることのあるエラーです．AviUtl2 の設定ファイル `system.conf` 内の `[Config]` 以下にある `TemporaryImageCacheSize` の数値を変更することで，一時画像キャッシュの最大値を増やすことができます．

    - `TemporaryImageCacheSize` の初期値は `16000000` で， $4000 \times 4000$ ピクセル相当です．

    - `system.conf` を直接編集するのではなく，アプリケーションデータフォルダに `system.conf` のコピーを作成して，そのコピーを編集することを推奨します．上書き変更の必要のない項目は，コピーしたファイルからは削除しても問題ありません．詳細は `system.conf` 内のコメントを参照．

      - 参考リンク: https://docs.aviutl2.jp/usage#レイアウト

        `style.conf` に関する記載ですが，`system.conf` に関しても通用する部分があります．

##  既知の問題

1.  [「レンズσ」](#レンズσ)の光線計算では，オブジェクトに対して垂直な視点を前提しています．なので立体回転させたオブジェクトに対しては必ずしも正確な見え方にはなりません．
