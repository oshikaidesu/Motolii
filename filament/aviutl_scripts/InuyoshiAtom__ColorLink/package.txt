ColorLink v1.0.0

AviUtl2用のカラー連動スクリプトです。

複数のオブジェクトに「カラーリンク」を追加し、
1つの「カラーマスター」から色をまとめて変更できます。

【主な機能】

・色A / 色B / 色C の3色を一括管理
・カラーリンク側で A / B / C を選択
・自分より上にある最も近いカラーマスターを自動参照
・マスターレイヤー番号の指定不要
・複数のカラーマスターを同一タイムライン内で使用可能
・外部プラグイン不要

【基本的な使い方】

1. タイムラインに「カラーマスター」を追加します。
2. その下のレイヤーに、色を変更したいオブジェクトを配置します。
3. 対象オブジェクトへ「カラーリンク」を追加します。
4. カラーグループ A / B / C を選択します。
5. カラーマスターの色A / 色B / 色Cを変更します。

カラーリンクは、自分より上にあるレイヤーを検索し、
最も近いカラーマスターを自動的に参照します。

カラーマスターが見つからない場合は何も処理しません。

【注意】

大量のカラーリンクを使用する場合や、
カラーマスターと対象オブジェクトのレイヤーが極端に離れている場合は、
処理負荷が増える可能性があります。
