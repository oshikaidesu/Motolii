# Changelog

## 2.0.1 2026-08-14

- 半開きなどの中間口形状を保持せず、閉じ口と開き口の間を1フレームずつ遷移する音量駆動方式へ変更
- 連続する口形状欄に同じレイヤーが設定されている場合、その重複を除いて表示上の停滞を防止

## 2.0.0 2026-08-04

- 3形状以上では密集した発音ピークのうち強いものだけを500ms間隔で最大開口にし、約80ms保持して短い点滅状の形状変化を抑制
- 90ms以下の閉じ口点滅だけを中間口へ統合し、100ms以上の発音間では閉じ口へ戻るよう調整
- 短い間隔で連続する類似音では最大開口を保持し、「ああ」「おお」などで口形状が音ごとに往復する動きを抑制
- 3形状以上の口パクで中間口と最大開口を時間基準で保持し、形状数による変化頻度の差を抑制
- 公開名を`PSDToolKit Natural LipSync`へ変更し、自然な口パクを目指す現在の方針へ説明と配布名を統一
- 厳密な旧状態判定モジュールを`LipSyncAviUtl1Legacy.lua`へ改名
- 旧モジュール名との互換性を廃止し、MtU固有に見える公開API名を削除
- 変換ツール・配布パッケージ・カタログを新しい汎用名へ統一
- カタログ用バイナリハッシュが安定するようネイティブビルドを再現可能化

## 1.8.3 2026-08-03

- AviUtl1のPSDToolKit口パク解析をAviUtl2用ネイティブモジュールとして実装
- 16-bit PCM WAVでAviUtl1互換のFFT・リサンプリング・状態判定に対応
- 日本語読みとスペクトル変化を使う発話追従モードを追加
- 中間口形状がある立ち絵で、近接する発音間を半開き状態で接続
- `.anm2` / `.obj2`を複数ドラッグ＆ドロップできる変換ツールを追加
- AviUtl2カタログで扱える`.au2pkg.zip`形式の配布に対応
