# colorQuantizeAnm2

色N値化スクリプト

AviUtl ExEdit2 version 2.0beta20 で動作確認

## 使い方

[Releases](https://github.com/nssuperx/colorQuantizeAnm2/releases)から @colorQuantize.anm2 をダウンロード

フィルタのラベルは**色調整**

### 通常

![通常](./imgs/通常.png)

|パラメータ|説明|
|---| ---|
|色数|だいたいここで指定した色数になる|
|しきい値ずれ量|色を変えるしきい値をずらす|
|しきい値曲線|しきい値の間隔を少しずらす|
|開始色|グラデーションの開始色と同じ意味|
|終了色|グラデーションの終了色と同じ意味|

計算は適当なので思ったように色の分割ができないときがある

### グレースケール

![グレースケール](./imgs/グレースケール.png)

**通常**のグレースケール専用版。開始色`000000`, 終了色`ffffff`固定

ディスプレイスメントマップ素材を作るときなどに使う

### bit数

![bit数](./imgs/bit数_3.png)

bit数3のとき

|パラメータ|説明|
|---| ---|
|bit数|RGB各成分で使えるbit数のイメージ|

|bit数|使える色数|
|---|---|
|8|2^8^3 = 16,777,216|
|4|2^4^3 = 4,096|
|2|2^2^3 = 64|

### bit数（RGB別）

![bit数RGB別](./imgs/bit数_r2g3b8.png)

赤bit数2, 緑bit数3, 青bit数8のとき

**bit数**のRGB各成分で別々のパラメータを設定できる
