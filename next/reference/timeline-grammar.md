# Timeline 操作文法(正典)

裁定144の成果物。**コードから独立した操作体系の意味論**であり、egui 版 `timeline_editor`(スクラッチ9,059行)が消えてもこの文法は残る。iced Timeline 移植はこの台帳を発注仕様とする。

- 一次資料(採集原文): [docs/reviews/2026-08-21-timeline-grammar-surveys/](../../docs/reviews/2026-08-21-timeline-grammar-surveys/) — R1=egui版抽出(file:line つき)/ R3=商用公式(AE修飾キー表)/ R4=NeoUtl(AviUtl慣習、AGPL につき意味のみ)/ R5=Lottie圏・現代エディタ
- 本書の書き分け: **正**=正典(移植で実装する意味)/ **否**=意図的不採用(理由つき)/ **候**=採用候補(利用者の実機裁定待ち)

## 0. 拘束(既決 — この台帳より上位)

1. **AE 型の自由な絶対時間配置**。レーンは詰め保証を持たない。trim family(ripple/roll/slip/slide/insert/overwrite/lift/extract/sync lock)は**採らない**(2026-08-19 裁定、egui 実装にも型として存在しないことを R1 が確認済み)
2. **undo = edit タイムラインの時間移動**(裁定2/47/48)。egui 版の GestureId+明示スタックは機構ごと移植しない。持ち越すのは「**1ドラッグ=1確定単位**」という粒度だけ(裁定118(b): 同一 at への batch)
3. **編集 intent は `SetTiming` 1本**(裁定51)。egui 版の prepare_set_clip_start / trim_in / trim_out / split という別入口は旧 D2 の事情であり、Grab 種別ごとの意味論だけを引き継ぐ
4. **ダブルクリック不使用**(egui 版の設計原則を正典へ昇格)。選択・並べ替え・跳ぶが同じ場所に重なる面では、2回目の押下が別操作の途中と区別できない。例外を作る時は個別裁定
5. 再生と掴みは相互排他: **ドラッグ中に Space は効かない**(時間が流れると何が起きたか読めなくなる)。逆に再生中でも locator 連打(M タップ)は止めずに打てる
6. **ショートカット・修飾キーをハードコードしない**(利用者裁定 2026-08-21、裁定146): 本書が定義するのは**意味アクション**(例: `RetimeSelection` / `ToggleSnapDisable` / `AddLocatorAtPlayhead`)とその**既定割当**であり、割当は keymap 層で後から自由に変更できる。実装はアクション名→キーの表を1箇所に持ち、pane コードはアクションだけを見る。本書のキー表記(Cmd+D 等)はすべて「既定割当」の意味で読む

## 1. 文法定数(ジェスチャの物差し)

egui 版の実測値を初期正典とする(出典 R1。iced 移植で ui_scale への追随は要検討、ヒット幅は物理 px 床)。

| 定数 | 値 | 意味 |
|---|---|---|
| SNAP_PX | 7px | スナップの画面距離しきい値(**時間でなく画面距離** — ズームに不変) |
| TRIM_EDGE | 8px | bar 端の掴み幅。**幅 24px 未満の bar は端を差し出さない**(誤トリム防止) |
| キー菱形ヒット | 12×12px | 描画は 8×8。**当たりは絵より大きい**(bar 端と同じ思想) |
| 開閉/M・S・L ヒット | 16×16px | fold ▸▾ / params ◇◆ / M・S・L 各ボタン |
| LOOP_GRAB | 8px | ループ帯端の掴み許容(同距離なら Out 優先 — 伸ばす操作が多い) |
| EDGE_PAN / RATE | 28px / 0.8 | 縁ドラッグの自動パン開始距離と速度 |
| 矩形選択の最小 | (egui 既定) | NeoUtl は 3px 未満=クリック扱い(候: 明示閾値を持つか) |

**ヒット判定は押した瞬間の座標で行う**(正)。ドラッグ開始が報告される時点でポインタは既に数 px 動いており、報告時点の座標だと「右端を掴んで左へ引く」が本体掴みに化ける(R1 M-2 の明記されたバグ修正)。

## 1.5 面の構成(zone の分業 — 裁定147)

Timeline は5つの面から成り、**各面の仕事を混ぜない**:

| 面 | 中身 | 原則 |
|---|---|---|
| **レーンバー(行ヘッダ列)** | スウォッチ+レイヤー名+M/S/L+開閉(▸▾ 子・◇◆ params) | **行の恒久 ID 面**。視覚正本は mock ui-scale-and-z の行ヘッダ列。選択・並べ替え・リネーム・右クリックの起点 |
| **ルーラ帯** | ループ帯(最上段)+locator 帯+目盛+playhead | 時間の目印とスクラブ |
| **クリップ面** | bar・キー菱形・marquee | **時間の面。レイヤー名を描かない**(裁定147) — 名前はレーンバーの仕事。クリップ上の余白は将来の**キーフレームオーバーレイ(操作中の行のキーを最前面に出す)**のために空けておく |
| **ナビゲータ帯** | 下端のパン/ズーム | 全体像 |
| **縦スクロールバー** | 溢れた時のみ | §5.5 |

**名前をクリップに描かない理由**(利用者裁定 2026-08-21): 今の iced 第1波はシェイプ名を bar に直描きしているが、キーフレームを bar 上へオーバーレイする段になると必ず衝突して読めなくなる。名前の住所はレーンバーに一本化する。M/S/L も**レーンバーで設定できる**(mock どおり — メニュー経由だけにしない)。

## 2. クリップ(bar)

- **move(本体ドラッグ)** 正: 未選択なら掴んだ瞬間に単独選択へ差し替え。掴んだ瞬間の値を基準に**絶対値で出し直す**(delta 蓄積ではない — 桁落ち・追い越しに強い)。複数選択は選択集合の root(祖先が未選択のもの)だけを動かし子孫の二重移動を消す。**Group 移動は子の全 param キーが同 delta で追従**。塊制約: 集合の誰かが 0 秒/終端に当たったら全員そこで止まる。スナップ対象= 0秒・終端・playhead・ループ両端・他 clip の start/end・全キー時刻(AE の「意味のある時間点」と同型)。**Alt でスナップ一時無効**(AE は逆極性=Shift で有効。egui 版の「常時有効・Alt で切る」を正典とする — 吸着既定は CapCut/Resolve とも整合)
- **trim(端 8px)** 正: 単独 clip の start/end のみ動かす。隣接・後続への連動なし(拘束1)。**In/Out トリムでキーは動かない・本体 move でキーは追従する**(AE 公式と egui 実装が一致 — この対は文法の背骨)
- **split** 正: playhead 位置で分割(Cmd+K / メニュー)。端ちょうど・clip 外は**黙ってスキップ(失敗ではない)**。Group は切れない(拒否であって失敗ではない)
- **Esc = ドラッグ中キャンセル** 正: 掴んだだけで未移動なら no-op。NeoUtl には無い・AE 公式は明記なしだが、egui 版の「Esc で掴む前へ戻す」を正典とする(M13: 操作の可逆の明示)
- 確定はマウスアップ。**ドラッグ中プレビュー → 確定1回**の内部形は next では transient overlay(store 実装済み)+確定 Intent 1発が正解形(NeoUtl のプレビュー座標分離と同型)
- 候: **Quick Offset(千鳥)** — AE 2025 の Cmd+Option+ドラッグ(先頭固定・末尾フルオフセット・中間均等)。Jitter は Stagger を一級操作化、LottieFiles は Duplicator に統合。MV 用途(拍ずらし)に効くので第2波候補

## 3. キーフレーム(菱形)

- **時刻ドラッグ** 正: 全 param で掴める(Position 限定は撤廃済み)。0秒〜終端 clamp、スナップ・端パンは clip と共通の面を使う
- **選択** 正: クリック=単独 / Cmd=トグル / Shift=範囲。Delete は**キー選択が層選択より優先**
- **同時刻衝突** 正: 複数キー移動は移動方向でソートしてから書く(delta≥0 なら遅いキーから)
- **イージング** 現状: Hold/Linear/Ease in-out の3種を右クリックから(Position のみ — **未決の穴、§7-1**)
- **キー群のリタイム** 正(裁定146): 複数キー選択後、範囲端のキーを**Cmd+ドラッグ**(既定割当)で選択範囲内の全キーを比例伸縮。アクション名 `RetimeSelection`。各社バラバラだった領域(LottieFiles=Shift / Rive=Alt / Cavalry=専用ツール、R5 横断観察4)に Motolii の規約として確定 — Shift(スナップ系)・Alt(無効化系)と役割が重ならない
- 候: **菱形の形でイージング状態を語る**(LottieFiles: 菱形/丸/矢印)。情報密度は上がるが描画語彙が増える — トンマナ裁定と一緒に
- 否: キーフレームサムネイル(Lottielab)— LottieFiles 自身が「視覚ノイズ」として恒久無効化した前例あり

## 4. 選択・並べ替え・構造編集

- **行クリック** 正: 素=単独 / Cmd=足し引き / Shift=**anchor(直前に触った行)から見えている順で範囲**。閉じた Group 内は範囲に入らない(「見えているとおりに採れる」)
- **marquee** 正: 空白面からのみ発火(行が先にヒットを取る)。**行に掛かるだけでは選ばず、時間方向も bar と重なっていること**(空白時間帯を囲んで全選択される事故の防止)。キーが掃かれたら行選択でキー選択を消さない
- **空白クリック** 正: 選択全解除。NeoUtl の「空白ドラッグ=シーク兼選択」は**採らない**(1ジェスチャ1意味 — シークはルーラの仕事)
- **並べ替え(左レール上下ドラッグ)** 正: 落とし先は**行ではなく行間の境界**。開いた Group の先頭子境界=Group 内先頭。自分の子孫へは落とせない。**ドラッグ中 Document 不変・確定1回**・時刻は変えない
- **Group 化(Cmd+G)** 正: 親が揃わない選択は拒否(位置が誰にも言えなくなる)。解除も1 undo 単位
- **Duplicate(Cmd+D)** 正: 複製後は増えた方を選ぶ。候: **Alt+ドラッグ複製**(LottieFiles/Cavalry/Lottielab の共通文法 — スナップ無効 Alt と文脈で衝突しないか要検分)
- **Cmd+A** 正: 見えている行だけ
- 否: NeoUtl のリップルモード・「左に詰める」系 — 拘束1(gapless 系の語彙)

## 5. 面(ルーラ・ループ・locator・ナビゲーション)

- **スクラブ** 正: ルーラ帯の押下維持で追随・掴んだら再生停止・フレーム丸め。候: AE の **Alt+スクラブ=再生を止めない**
- **ループ帯** 正: ルーラ最上段が専用面。引いたら即 on(別キーで有効化させない)。端 8px=リサイズ(**反対端は掴んだ瞬間の値で固定** — 追い越しで区間が畳まれない)・中=平行移動・空白=新規(左右どちらから引いても同じ)。最短1フレーム保証。**L でループ on/off**(帯は消えない — 引き直さず戻せる)
- **locator** 正: **M タップ=playhead へ即置き**(名前入力に入らない・同一フレーム連打は1つに畳む・再生中でも打てる — 曲を聴きながらの用途が本義)。ドラッグ移動・クリックでジャンプ・右クリックで削除。メニューからの追加は即リネーム状態
- **ホイール文法** 正(AE/Premiere 同型): 素/二本指=縦スクロール(x/y 同時に効く)・Shift+ホイール=横パン・Cmd+ホイール=**カーソル下の時刻が動かないアンカーズーム**・ピンチ=ズーム。実装注意: パン/スクロールは**生ホイール値**(平滑値は指を止めても流れ続ける)、ズームだけ平滑値(指数で効くため)
- **ナビゲータ帯** 正: 下端。中=パン(掴んだ時刻を窓中心へ)・knob 端 6px=片側固定ズーム。MIN_SPAN=0.25秒
- **矢印キー** 正: playhead を 1(Shift で 10)フレーム — **選択も clip も動かさない**(AE/Premiere 同型)。テキスト入力中は横取りしない
- 候: **Show Only Animated / 選択のみ表示**(R5 横断観察5: 「今アニメートしているものだけ見せる」が現代の共通思想)。Motolii は既に params ◇◆ の行開閉を持つ — その既定を「キーを持つ行だけ」にする案

### 5.5 地味な意味論(忘れがちだが文法の一部 — 利用者指示 2026-08-21)

- **縦スクロール** 正: 行領域は独立 viewport(pane 総高は層数不変 — [Timeline パネル意味論](../../docs/reviews/2026-08-20-timeline-pane-semantics.md)の不変量)。スクロール位置・zoom・fold は **Session 状態**(Document に乗せない、同決定)。スクロールバーは内容が溢れた時だけ出現、knob 最小 24px(掴めない knob を作らない)
- **端パン** 正: ドラッグ全種(move/trim/キー/locator/marquee)で共通に効く(EDGE_PAN=28px)。ドラッグの種類ごとに有無が違うと「効いたり効かなかったり」の無反応系違反(M13)になる
- **カーソル形状は意味の予告** 正: 掴める=Grab / 掴んでいる=Grabbing / 端=ResizeHorizontal / 空白面=Crosshair / 禁止=NotAllowed(ロック中)。触れそうな物には必ず予告を出す(Q0「触れそうで触れない物は不合格」の逆写像)
- **ホイールの奪い合い** 正: ルーラ上とクリップ面上で同じホイールの意味を変えない(NeoUtl はルーラ=ズーム/面=横スクロールと分けているが、**採らない** — 場所で意味が変わるホイールは予告できない)。意味の切替は修飾キーだけで行う(§5 ホイール文法)
- **ドラッグ中の見た目更新** 正: プレビューは毎フレーム、Document 書き込みは確定1回(transient overlay)。ドラッグ中に他の行・キーも**プレビュー座標で追随表示**する(NeoUtl と同型 — 動かしている物だけ動くと着地位置が読めない)
- **スクロール方向(上下反転)は文法の対象外** 正(利用者裁定 2026-08-21): natural scrolling 等の OS 入力慣習は winit/iced 層が透過するものをそのまま受け、**アプリ内で再反転しない・既定では反転設定も作らない**(慣れの範疇)。将来足すなら設定パネルの候補というだけで、この台帳の意味論には含めない

## 6. メニュー・その他の正典規則

- **右クリックは対象を先に選択してから開く**(選択とメニュー対象の食い違い防止)。空白メニューは**押した瞬間の時刻を控える**(表示中にポインタが動いても位置がずれない)
- **メニュー内で Document を触らない** — 行ループ中の木の変更は位置がずれる。Action を貯めてループ外で1回
- **M・S・L** 正: 状態は Document から読む(ボタンに状態を持たない)。**継承ロックは薄く見せるが自分では外せない**(点灯させない)・解除操作は理由つき拒否(M13)
- **リネーム** 正: Enter(単一選択時)/メニューからインライン TextEdit。空名拒否・同名 no-op
- **OS ドロップ取り込み** 正: 1ドロップ=1 undo 単位。**曲が無い project への音声=soundtrack**(CapCut/Ableton 同型)。置き場が無ければ台帳を触る前に拒否(素材だけ入る中途半端を作らない)
