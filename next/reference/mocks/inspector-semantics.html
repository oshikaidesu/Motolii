S5 ヒーロー = propertyRow の列(値そのもの)。chrome(panelHeader/modeTabs/footer)は縁 — この枠内に最大コントラストを置かない(S5b)
panelHeader の縁バー(3px)= way-inspector アクセント。現行実装: 対応なし(ident_band が名前欄に統合、独立 panelHeader 帯は無い)
modeTabs(Effect⇄Custom)= 意味の別世界(browser の4タブ裁定143と同型)。解禁束: 意味起草タスク#14 と同根(Custom側の意味が起草されるまで予約地)
selectionSummary: shapeGlyph(種別図像)+M/S。現行: M のみ配線済み(ident_band、簡略形)。S は幅予約のみ(reserved_glyph — solo 未実装、engine/store 側の別レーン)。shapeGlyph は救出台帳へ
propertyRow 左3px = 値型の色(--property-color)。FX 行では型(scalar/vector/angle/…)、TRANSFORM/APPEARANCE 行ではプロパティ個別色。M/S/L 相当の rail glyph は Timeline 側と同族(裁定164: 意味役割が新しい時は専用ロール)
Fill 行(color picker + Recent swatches)。現行実装: 対応なし(parameterKind.color 型・色プロパティが実装に無い)。解禁束: 色プロパティ型+Recent色履歴(browser 側の Recent 束とは別モデル)
effectStackToolbar〜effectGroup: FX スタック全体。現行実装: 対応なし(I-ratio台帳で確定済み — effect stack/mode tabs/selection summary/extension tabs/notes panel は Q0 スコープ外)。drag reorder・複数選択→Group・rename(F2)・enable(ON/OFF)・advanced折りたたみ・ungroup、いずれも救出台帳へ
parameterContextMenu/effectContextMenu(右クリック)。解禁束: 右クリック基盤(browser semantics の S6 併存原則と同じ束 — 唯一の入口にしない)。F2/⌘C/⌘V/⌘D/⌫ のキーボード等価は救出元 script に実装済み(意匠のみ未転写)
extensionTabs+extensionPanel(Tags/Notes)。現行実装: 対応なし(Custom mode 自体が無い)。解禁束: タグ束(map D、browser semantics の Collections/tag editor と同根)
footer: 静的ヒント文のみ実装済み(hint_row)。statusDot と動的ステータス文(「Fill changed to … in this preview」等)は解禁束: 局所プレビュー通知 — 現行は操作結果を文言化して返す口が無い
