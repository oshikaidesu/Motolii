# 色のパネル：意図から並べる（10/29 夜、ユーザーと）

色の棚（golf_noise.md ⑬）は、手本を探して当てに行くと外れ続けたので、ユーザーの意図から並べ直す。ここに書くのはユーザーの言葉をまとめたもの。作るのは、全部そろってから。

## 色のパネルを見るとき、いるもの

1. **スポイト**：まず要る。
2. **カラーサークル**：CLIP STUDIO PAINT で見かけたもの（色相の輪と、中の四角）のままで大丈夫。
3. **グラデーション**：追加で要る。
   - 色のつなぎ方（補間の方法）は、プリセットにそのまま記録されるようにしたい（つなぎ方ごと保存して、呼び出すと同じつなぎ方で出る）。
4. **パレット**：特別扱いしない。普通の色のブロックと同じように並ぶ。
   - 考えた筋道：「パレットはどうやって登録するのか」→「ユーザーが選ぶ」と考えると、パレットだけ別物にする理由がない。

## 選んでもらった答え（10/29 夜）

- **色のブロック**：色はみんな同じ四角で 1 か所に並ぶ。写真から取った 6 色などのまとまりの間には、細い区切りの線だけが入る（名前は出さない）。
- **増やし方**：
  - 今の色を＋で 1 つずつ（CLIP のカラーセットの「色の追加」）
  - 写真から何色かまとめて
  - 舞台で選んだ物の色から
- **グラデーションのプリセット**：色のブロックと同じ所に、1 つの四角として並ぶ。
- **パネルを横に広げたら**：色のブロックの 1 段に入る数が増える（並びは縦のまま）。
- **色のつなぎ方**：全部選べるように（そのまま RGB、目に自然 OKLab・CAM16、色相で回る、段で切り替わる）。つなぎ方はプリセットにそのまま記録される。
- **並べ方の感じ**：「レンガ CSS みたいな感じかなぁ、Pinterest か？」（メイソンリー：大きさの違うまとまりを、レンガのように隙間なく積む）

## 試しの絵（10/29 夜、チャットに出した物）

狭い枠と広い枠を並べて出した。上から、スポイト・今の色・16 進／CLIP のような色相の輪と中の四角／グラデーションの帯と色の点、つなぎ方（RGB・OKLab・CAM16・Hue・Steps）／色のブロック。色のブロックは、まとまり（自分の色・写真から・グラデーション 3 つ・セット・選んだ物から）ごとに細い線で区切り、レンガのように詰める。広い枠では 1 段に入る数が増える。最後に＋。

## 色のブロックはレンガ（10/29 夜、ユーザー）

「全部が正方形の色のブロックはなんだか変だと前々から思っていた。ポスターデザインは色の環境、スペースの環境があって生まれるものだから、何かしらランダムで横方向だったり縦方向だったり。だからこそのレンガ CSS にしたい」

- 色のブロックは、大きさも縦横もそれぞれ違うレンガ。大きさは、その色がそこで占める面積（写真から取ったパレットは写真の中の割合を既に持っている：_Pal の shares。書類の色は画面のどれだけを塗っているか）。
- 詰め方は Flutter の flutter_staggered_grid_view（大きさの違うタイルを詰める部品）が使える。

## まとまり（10/29 夜、ユーザー：「方向性は合ってるけど、まとまりがなくなった。次はまとまりを考えて」）

ばらばらに見えた原因：塊の外形が不ぞろいで穴が空いていた、塊どうしの大きさに決まりが無かった。
直し方の考え：外は整える、中で遊ぶ。塊の外形はきれいな長方形、中は色の面積でその長方形を隙間なく割る（割り方で縦長・横長が混ざる：ツリーマップ）。並べ方の 2 案（絵：reports/screen/colour_brick2_1029.png）
- A：同じ大きさのレンガを、段ごとに半分ずらして積む（本物のレンガ積み）
- B：高さだけそろえ、幅は色の数で変え、段の両端をそろえる（写真の一覧の詰め方）

## 区切りと入口（10/29 夜、ユーザー：「区切りは四角である必要があるのか、幅を変えると穴が生まれる」「区切りは後からどう見分ける」「そもそもパレットはどう決めるのか、入口が考えられていない」）

- 区切りを四角にしない：色を 1 本の流れにして、同じ高さのレンガを左から並べ、段の両端をそろえて詰める。幅を変えても段ごとに詰め直すだけで穴は空かない。レンガの幅は色の面積の割合で決まり、細いレンガは縦長、太いレンガは横長に見える。まとまりは流れの中の一続き（段をまたいでよい）。
- 見分け方：まとまりの中は細い隙間、まとまりの間は広い隙間（近いものは仲間に見える）。手を乗せたまとまり全体に枠、下の詳細の欄に名前・出どころ（写真）・色の数。
- 入口（どれもマウスだけで、物の上で）：流れの最後の＋で今の色を 1 つ／写真をパネルに落とす・Media の写真を右クリック「パレットにする」／舞台で選んで右クリック「色をパレットにする」／この書類の色（自動の 1 まとまり）を右クリック「残す」。直すのは、レンガを引いて別のまとまりへ・並べ替え、右クリックで「この色を消す・今の色に置き換える・ここで分ける・まとまりを消す」。
- 絵：reports/screen/colour_flow_1029.png

## 弁当グリッドとサイコロ（10/29 夜、ユーザー：「色はもっと楽しい UI であるべき」「登録した後は正方形がずっと続きそう」「段区切りでなく弁当グリッド」「どこかにサイコロマーク、押すと大きさがうにょうにょ変わる」→ 動く試作を見て「ああそうだよ、こんな感じだ」）

- 段で並べず、弁当（ベントー）グリッド：大きさの違う箱（1×1・2×1・1×2・2×2・3×2…）が縦にも横にも組み合わさって詰まる。大きい割合の色は大きな箱になりやすい。
- 新しく足した色も形をもらう（正方形が続かない）。
- サイコロ：押すと箱の大きさと並びが組み変わり、弾むように（バネのように行き過ぎて戻る）新しい形へ動く。パネルの幅を変えた時も同じように動く。
- 動く試作：reports/screen/colour_bento_1029.gif（8 列、密に詰める並べ方＝CSS grid の dense と同じ、動きは elasticOut）。
- 作る時の部品の候補：箱の詰め方は flutter_staggered_grid_view（StaggeredGrid の Quilted・Staggered）、動きは Flutter 自身の暗黙のアニメーション（AnimatedPositioned など）とバネの曲線（Curves.elasticOut）。

## 作った所（10/30）

弁当グリッド（サイコロ、幅に合わせて列が増える、弾まずキビキビ：ユーザー「弾まずにキビキビ動く感じがいい」）、CLIP のような色相の輪と四角、手を乗せたパレットだけ明るく残る（パレットの間に隙間は開けない：開けると幅やサイコロで穴が出る）。まだ：グラデーションのつなぎ方をプリセットごと残す、写真を落として取り込む。
