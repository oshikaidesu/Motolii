# ファイル・履歴・ヘルプの画面の照らし合わせ（10/25）

Motolii に画面そのものが無い所（reports/screens.md）のうち、始める画面・ファイル・読み込み・取り消しの履歴・ヘルプ・確認とまちがいを、お手本 10 本（＋Adobe は比べるだけ）の公式から集めた。数は「その項目を持っているお手本の数」。

出典：Cavalry（cavalry.studio/docs）、Blender（docs.blender.org/manual）、DaVinci Resolve 20 リファレンスマニュアル、Final Cut Pro（support.apple.com/guide/final-cut-pro）、Ableton Live 12（ableton.com/en/live-manual/12）、クリスタ（help.clip-studio.com）、Figma（help.figma.com）、Rive（rive.app/docs）、Jitter（help.jitter.video）、Spline（docs.spline.design）。Adobe（After Effects・Premiere）は比べるだけ。行ごとの URL は集めた時の記録（scratchpad/screens/raw/）にある。

## 始める画面・初めての時

| 項目 | お手本 | 数 | Motolii |
|---|---|---|---|
| ひな形（テンプレート）から始める | Blender・Ableton・Figma・Jitter・Spline | 5 | 無い |
| 始める画面に最近の文書 | Blender のスプラッシュ・Resolve のプロジェクトマネージャー・Figma の Recents・Spline の Home | 4 | 無い（起動すると一時フォルダに Untitled） |
| アプリの中の手引き・レッスン | Ableton の Learn View・Cavalry の Getting Started Guides | 2 | 無い |
| 初めての時の設定 | Blender の Quick Setup・Resolve | 2 | 無い |
| 新しいことの知らせ（What's New） | Blender | 1 | 無い |
| 始める画面から前の続きを戻す | Blender | 1 | 無い |
