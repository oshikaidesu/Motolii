# 壊し屋 1 の報告（カードを手で扱う見本）

読んだもの：`skin/book/lib/sets/inspector/cards_table.dart`（以下 行番号はこのファイル）、`cards_set.dart`、`integration_test/cards_test.dart`、`reports/card_ui/<見本>/*.png`。
何も動かしていない。コードと撮った絵だけで判定した。

テストが通っているのは「上手くいく順」だけ。下はどれもテストに入っていない手順。悪い順に並べる。

## 1. 「速さ」を触ると波が暴れる。窓を開けている時間が長いほどひどくなる（絵が壊れる）

- 手順：波カードの「速さ」タイルを横に少しこする。または「速さ」に揺れ / ノイズを重ねる。
- 起きること：行 273 は `sin(s * waveS * 2.4 - phase)`。`s` は窓を開けてからの秒数で、ずっと増える（行 196-199）。
  - こすった時：速さが Δ 変わると、波の位置が `s × Δ × 2.4` だけ飛ぶ。開いて 1 分なら、0.05 こすっただけで約 7 ラジアン飛ぶ。
  - 揺れ / ノイズを重ねた時：実際の速さは `waveS + s × waveSの変化の速さ` になる。揺れなら 1 分後に毎秒 180 ラジアンほど上乗せされ、10 分後にはちらつきになる。
- なぜ悪い：思いつき→動く絵の途中で、ただ値を触っただけで動きが壊れる。壊れ方は時間で変わるので、何が原因か分からない。
- 最小の直し：位相を毎フレーム足していく（`phase += waveS * dt`）。または `s` を 1 周期で巻き戻す。

## 2. タイルの印（チップ）は、少しでもつまむと消える。別のタイルへ移せない。戻せない

- 手順 A：半径に揺れ ×3 を乗せる → チップを掴んで、大きさのタイルへ持っていって放す。
- 手順 B：チップを少しだけずらして、同じタイルの上で放す（気が変わった）。
- 起きること：チップは `Draggable<String>`（行 478）。どのタイルも `DragTarget<Beh>` なので（行 425）、String を受け取る所が窓のどこにも無い。だから `wasAccepted` は必ず false になり、行 483 の `t.lift(id)` が走る。A も B も「外れる」。移らない。×3 の強さも消える。取り消しは無い。
- もう一つ：掴んでいる間、値はまだ動いている（07_pulling_noise_off.png では半径が 174px のまま桃色）。放すと何が起きるかが前もって見えない。「乗せただけで先に効く」の逆、つまり外す時の前触れが無い。
- 怪しい所：チップはこすり用の `GestureDetector(onHorizontalDragUpdate)`（行 434-435）の中にある。チップを横に引くと、値をこする方が勝つかもしれない（ジェスチャの取り合い）。手で確かめる価値あり。
- なぜ悪い：物差し 7（外せない・戻せない）と物差し 4（自由）の両方に当たる。手が一番やりそうな「付け替え」ができず、失敗すると強さごと消える。
- 最小の直し：タイルが `Beh` と「付いている印」（id+Drive）の両方を受け取るようにする。別のタイルに落としたら移す。落とした先が元のタイルなら何もしない。消すのは手札の上か、窓の外へ捨てた時だけにする。

## 3. タイルの数字が嘘をつく（何が効いているか読めない）

- 3a 数×ずれ：手順は、ずれを「数」に重ねる。
  - タイルは行 455 で `t.at(v.id, s, 0, 12)` を出す。数は1つの値なので（perCopy false）コピーは 0 番扱い。ずれの0番は -1 なので、12 − 45×0.22 = 2.1 → 3 に丸められ、**タイルは「3」**と出る。
  - 舞台は行 266 で `at('count', s, 0, 1)`。コピー数 1 だと、ずれは 0（行 48）なので**舞台は 12 個のまま**。
  - チップは付いて数字も変わるのに、絵は何も変わらない。しかもタイルの数字は絵と食い違う。
- 3b ずれ / ランダム：タイルはコピー 0 番の値だけを出す。ずれの 0 番は必ず一番下の端なので、44px が「20px」と出る（07/08 の絵の大きさ 20px）。ランダムは 0 番だけ決まった量ずれた数字が出る。自分が入れた数字（44）は表には出ない。裏返した時だけ見える。
- 3c 入れ替えの前触れが結果と違う：手順は、揺れの付いた半径の上に、ノイズを持って行って止める。行 96 で揺れ、行 97 でノイズの両方を足すので、前触れは「揺れ＋ノイズ」。放すと入れ替えなので結果は「ノイズだけ」。数字の色も古い方の色（行 456 `(d ?? Drive(over!))`）。さらに薄いチップ（行 461）が古いチップの真上に重なり、古い方が見えにくい。
- 3d 同じカードを重ねる前触れが無い：同じカードを持って行くと、行 97 と行 461 がどちらも「同じ印なら何もしない」ので、×2 になる様子が見えない。見えるのは枠の色だけ。
- なぜ悪い：物差し 2（起きた事が分かる）と物差し 6（数値が残る）。自分で入れた数字にすぐ届かない。
- 最小の直し：タイルの大きい数字は常に自分の値（v.v）にし、動きは横の小さな帯（最小〜最大の幅とコピーの点）で見せる。前触れは「放した後の状態」を一度だけ計算して出す。数は1つの値なので、コピーごとの動き（ずれ）は受け付けないか、手札の上で暗くする。

## 4. 範囲の端で動きが消える。こすっても数字が動かなく見える

- 手順：不透明（100%、上限 100）に揺れ。回転（0°、下限 0）に揺れ。波の高さ（0px）に揺れ。色相（72°）に ×3。
- 起きること：行 98 の `clamp(lo, hi)` で、半分の時間（または半分のコピー）が端に張り付く。回転と色相は本来ぐるっと回る値なのに、端で止まる（行 274 の `% 360` は clamp の後なので意味が無い）。回転に揺れを乗せると「片側にだけ回って、半分は止まる」カクつきになる。
- こすり：大きさを 10px に下げてずれを付けると、0番は 10px に張り付く。土台を 10〜34 の間でこすっても、タイルは「10px」のまま変わらない。こすりが効いていないように見える。
- 最初の見本（重ねる）では、波の高さが 0 なので、高さに何を乗せても半分しか出ない。
- なぜ悪い：乗せたのに「効いていない」と思われる。外して乗せ直しても同じ。
- 最小の直し：回転・色相は clamp でなく巻き取り（mod）にする。他は端に寄った時、振れ幅を中心側へ寄せる（例：振れを `min(v−lo, hi−v)` に収める）。

## 5. 裏も伏せも「見えるけど触れない」所だらけ

- 裏（行 346-350）：
  - 印は `_Chip`（外せない、行 405）。外すには表に戻すしかない。
  - 裏の行は DragTarget ではない。手札を落としても、何も言わずに消える。
  - 数字はこすれない。物差し 6 の「数値にすぐ届く」は、裏では見るだけ。
  - 足した行は全部「0」（行 349）。「親 0」「空間 0」「グラデーション 0」「遅れの起点 0」など意味の無い数字が並ぶ（裏返す/01_start.png）。
  - 動いている値も、裏では土台の数字しか出ない。
- 伏せ（行 366）：中身ごと消えるので、付いている印も全部見えない。頭にも「印あり」の表示が無い。
  - 伏せたまま「裏」を押すと、見えない所で裏表が切り替わる。起こした時に、急に裏が出てくる。
  - 複製を伏せると、数は 1、半径は 0 に戻る（fallback）。輪が真ん中の星 1 つに縮む。「効かない」の意味としては合っているが、前触れが無いと驚く。
- 最小の直し：裏の行も表と同じ部品（こすれる、落とせる、印を外せる）にする。伏せたカードの頭に、付いている印を小さく並べる。伏せている間は「裏」ボタンを消す。

## 6. 「光る」が残り続けて、関係ない時に光る / 光るべき時に光らない

- `flash` は一度入ると消えない（行 121。誰も null に戻さない）。タイルの光は、行 437 の鍵 `ValueKey(t.flash == v.id ? d?.power : 0)` が変わった時だけ始まる。そのため次のことが起きる。
  - 外した時に光る：印を外すと d が null になり、鍵が `ValueKey(null)` に変わる。光が新しく始まり、しかも Pop.accent の色で光る（08_noise_off.png の半径タイルがうっすら色付き）。外したのに、乗せた時と同じ合図が出る。
  - 裏から表に戻す、または伏せから起こすと光る：タイルが作り直される（行 366 の AnimatedSwitcher / SizedBox）。新しい `_TileState` の begin は `flash == id ? 1 : 0` なので、**最後に乗せたタイルがもう一度光る**。
  - 光らない時：乗せた直後のタイルに別のカードを乗せる（強さ 1→1、鍵が同じ）と光らない。×3 にさらに同じカードを乗せても、強さは 3 のまま（行 116）なので何も起きない。上限に来たという合図も無い。
- 最小の直し：光は「乗せた回数」のような数で鍵を作り、`lay` の時だけ増やす。光り終わったら `flash = null` にする。×3 で受けた時は、首振りなど「もう無理」の合図を出す。

## 7. 数に揺れ / ノイズを乗せると、星が全部飛び回る

- 行 266 で毎フレーム n が変わる。行 271 の角度 `2π i / n` も、揺れの位相 `i / n`（行 47）も n で決まる。そのため数が 1 増えるたびに、**全部の星**の場所と揺れの位相が一度に飛ぶ。乗せる前に止めて見るだけ（前触れ）でも輪がちらつく。
- 直し：増えた / 減ったコピーだけを出し入れする（角度は最大数で割る、または増えた分を外側にフェードさせる）。数にはランダムだけ受けるようにする手もある。

## 8. 並べ替えで変わるのは「波と複製」の組だけ

- `copiesFirst`（行 147-150）は、名前で 2 枚だけを見ている。見た目や色を複製より上へ動かしても、舞台は何も変わらない。題では「並べ替えると効く順が変わる」と言っているのに。
- 波が先（輪ごと）にしていても、高さ・速さにずれやランダムを乗せると、行 268 でコピーごとに値が変わる。輪ごとに動くはずが、結局 1つずつ動く。順番の約束と食い違う。
- 掴める所は、色の四角と名前だけ（行 332-339）。頭の空いている所（Spacer）を掴んでも何も起きない。
- 「重ねる」の見本では波の高さが 0 なので、並べ替えても何も変わらない。
- 直し：効かない並べ替えは、その場で元に戻る（跳ね返る）ようにする。頭全体を掴める所にする。

## 9. どこに落とせるかが、持ち上げただけでは分からない。落とせない所では黙って消える

- 手札を持ち上げても、受けるタイルは光らない。枠が出るのは真上に来た時だけ（行 446）。
- 舞台・カードの頭・裏の行・伏せたカードに落とすと、手札は何も言わずに消える（Draggable が戻る動きも無い）。
- 物差し 1。直し：持ち上げている間は、受けるタイル全部を薄く縁取る。受けない所の上では、持っているカードを暗くする。

## 上位 6 つ（まとめ）

1. 速さ × 経過時間：こするだけで波が飛ぶ。揺れを乗せると時間とともに暴れる（行 273）。
2. 印をつまむと必ず消える：付け替えも、元に戻すこともできない。強さも消える（行 478-484）。
3. タイルの数字が嘘：数×ずれでタイルは 3、舞台は 12。ずれは常に最小の端が出る。入れ替えの前触れは「古い＋新しい」（行 96-97、266、455）。
4. 範囲の端で動きが消える：回転・色相・不透明・高さ。こすっても数字が止まって見える（行 98）。
5. 裏と伏せ：見えるが触れない。裏の数字は全部 0。伏せると印が見えない（行 346-366）。
6. 光り方が狂う：外した時・表に戻した時に光る。入れ替えや ×3 では光らない（行 121、437）。
