# 評価役（わかりやすさ）3回目

立場：After Effects と Cavalry を知っている人が、この見本を初めて開いたつもりで見た。前の評価役のファイルは読んでいない。
見たもの：重ねる 15枚、裏返す 4枚、順番 3枚、伏せる 2枚、投げる 6枚、束ねる 5枚、舞台に落とす 7枚（撮り直しの途中に一度フォルダが消えたので、撮り終わってから全部見直した）。コードは cards_table.dart と cards_set.dart。比べたのは今の窓 window_1017_handcards.png。

## 点数（合格 8、どれも 6 以上）

| 項目 | 点 | 理由（どの絵か） |
|---|---|---|
| 1. 掴める物が分かる | 5 | 良い点：掴んだ瞬間に落とせるタイルが全部縁取られ、「数」だけ縁取られない（重ねる/02, 05）。悪い点：掴める物の多くに掴める印が無い。手札（揺れ・ずれ…）は今の窓のデスクのボタン（Ease, Wiggle…）と同じ見た目なので、押すものに見える。押しても何も起きない（コードはドラッグだけ）。カードを棚に戻す取っ手は見出しの 14px の色の四角だけ（投げる/05）。タイルを束ねるには名前の帯を長押しする（束ねる/02）が、絵のどこにもそうと分からせる物が無い。 |
| 2. 起きた事が分かる | 6 | 良い点：重ねると、タイルに丸い印・±の幅・星ごとの線が出て、舞台もすぐ変わる（重ねる/03, 06）。悪い点：±56 → ±98（重ねる/04）に単位が無く、「同じカードをもう一枚重ねた」ことが数字の変化でしか分からない。星ごとの線は 4px の高さしかなく、ほとんど読めない。順番を変えて意味があるのは「複製」と「波」の組だけ（コードは名前で決め打ち）。それなのに、どのカードを動かしても上から光る（順番/03）ので、全部の順番に意味があるように見える。「輪ごと」と「1つずつ」の違いも、止まった絵ではほとんど見分けられない（順番/01 と 03）。 |
| 3. 速い | 7 | 「星を1つずつ揺らす」は手札を1枚値に落とすだけ（重ねる/03）。舞台に落とす方でも2手（舞台に落とす/05）。ここは本当に速い。減点：幅を正確に詰めるには、印を押して開き、こすって合わせるしかない。数字を打ち込めない（重ねる/08, 09）。 |
| 4. 自由 | 7 | 運ぶ・重ねる・移す・外すが全部手でできる（重ねる/10〜12）。減点：裏返すと伏せるは見出しの小さなアイコンを押す操作で、手でカードを扱う感じが無い。舞台の輪で選べる値は「大きさ・半径・1つずつ回す・色相」の4つに決め打ちで、位置などには届かない（舞台に落とす/02）。 |
| 5. 今の窓に馴染む | 7 | 値のタイル（名前・大きな数・右上の棒グラフ）は今の窓のインスペクタと同じ。手札はデスクのタイルに似ている。合わない所：今の窓の見出しは「折りたたみ矢印＋アイコン＋名前」だが、見本は「点6つ＋色の四角＋名前」。裏返すアイコンが読めない（裏返す/01 ではヘッドホンか錠前に見える）。棚のカード（散らす・波）は小さな札で、手札とも見出しとも違う第三の形になっている。 |
| 6. 数値が残る | 5 | 表のタイルは数字を押せば打ち込める（重ねる/14, 15）。ただ、押せるという印は無い。打ち込めない数字が多い：裏の行（位置 X など、裏返す/01）はこするだけ。揺れの「幅」「速さ」（重ねる/08）もこするだけ。束の数字（束ねる/03）は押しても何も起きない。正確に詰めたい時ほど届かない。 |
| 7. 壊れない | 5 | 取り消し（↶ と ⌘Z）はあり、外したノイズも戻る（重ねる/13）。壊れている所：束ねる/05「1つずつ回すが束に入る」で入っていない。束は2つのままで、「1つずつ回す」に束1の印が無い。見えない出口：束をほどくのはダブルタップだけ。束は端に着くと黙って止まる（束ねる/04 は大きさが下限の 10px で止まったが、理由はどこにも出ない）。印を開くと「±92」の文字が丸い印に重なって読めない（重ねる/09）。 |

平均 6.0。不合格（8 に届かず、6 未満が 1・6・7 の3つ）。

## 直すべき5つ（大事な順）

1. **束が壊れていて、ほどき方も見えない**（束ねる/05, 03）
   3つ目の値が束に入らない。持ち上げ方は名前の帯の長押し、ほどき方はダブルタップで、どちらも見えない。
   → 揺れなどの印と同じ決まりに揃える。タイルの束の印（束1）を掴んで別の値に落とすと入る、手札に落とすと抜ける。持ち上げる場所には点6つの取っ手を描く。

2. **打ち込めない数字をなくす**（裏返す/01, 重ねる/08, 束ねる/03）
   裏の行、揺れの幅と速さ、束の数字を、表のタイルと同じく「押せば打ち込める」にする。決まりが1つになるので、説明が要らない。

3. **カードの取っ手を1つにまとめる**（投げる/05）
   今は、並べ替えが点6つ、棚に戻すのが 14px の色の四角で、取っ手が2つあり両方小さい。
   → 見出し全体を取っ手にする。縦に動かせば並べ替え、棚まで運べば外す。棚の上に来たら、手札と同じように「外す」と大きく出す。

4. **順番に意味があるふりをやめる**（順番/01〜03）
   意味があるのは「複製」と「波」だけなのに、全部のカードが光る。
   → 「1つずつ/輪ごと」の札そのものを押して切り替えられるようにし、並べ替えは見た目の整理だけにする。全部の順番に本当に意味を持たせるなら、効いた順をカードの横に番号で出す。

5. **手札が押すボタンに見えるのに、押しても何も起きない。裏返すアイコンも読めない**（重ねる/01, 裏返す/01）
   → 手札を押したら、最後に触った値に重なるようにする（AE の「選んでからエフェクトを当てる」の流れが、ドラッグ無しで通る）。裏返すアイコンは「カードがめくれる」形にするか、カード名を押すと裏返るようにする。

## 壊れている所・迷う所

- 束ねる/05：「1つずつ回す」が束に入っていない（絵の名前と中身が違う）。
- 束ねる/04：束が端に着いて止まっても、どの値が止めたのか出ない。
- 重ねる/04：同じカードを2枚重ねた印が無く、±の数が増えるだけ。単位も無い。
- 重ねる/05：断られた値（数）には縁が出ないだけで、断られたと分かる印が無い。カードがタイルを隠してしまう。
- 重ねる/09：印を開くと「±92」の文字が丸い印に重なる。
- 重ねる/11：運んでいる印が指の下の小さな丸だけで、何を運んでいるのか読みにくい。行き先の「外す」は分かりやすい。
- 「波」のカード（舞台全体を波打たせる値の組）と「揺れ」の手札（値を揺らす）は、どちらも正弦波で動く。Cavalry を知っている人には、同じ物が2か所にあるように見える。どちらを使えばいいか迷う。
- 投げる/04：棚が空になると、下に何も無い帯だけが残る。そこが棚だと分かる物が無い。
- 舞台に落とす/02：舞台に輪が出ている間、インスペクタのタイルも全部縁取られたまま。落とせる場所が2か所同時に光るので、どちらに落とすのか迷う。
- 伏せる/01：伏せたカードは数字が全部隠れる。AE の fx スイッチなら、切っても数字は見えたまま。
- 裏の行（裏返す/03）には ± の幅が出ない。どれだけ揺れているかは、60px の短い線でしか分からない。
- 取り消しの矢印は 26×22px と小さく、題の右端にある。
