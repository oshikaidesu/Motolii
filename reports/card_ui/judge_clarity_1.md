## 直すべき5つ（大事な順）

1. **動いている値で元の数字が消える**（重ねる/03：180px → 125px、05：20px が止まって出る）
   → タイルは元の数字を大きくはっきり出し続け、動く幅は数字の下の細い帯（最小〜最大の幅と、今の位置の点）で見せる。1つずつ違う時は、星の数だけ短い縦線を並べた小さな列にすれば「12個がばらばら」が一目で分かる。

2. **行動カードに自分の数値が無い**（どの絵にも無い。強さは ×1〜×3 だけ）
   → 刺さった印を押すか開くと、そのタイルの下に揺れ自身のつまみ（幅・速さ・ずらし）が出る。×2 を重ねる手つきは「幅を足す」と同じ意味にして、数字でも見えるようにする。×3 から下げる手が要る。

3. **掴める物と落とせる場所が、掴む前には分からない**（重ねる/01）
   → 手札は Desk の押すタイルと見分けが付く形にする（少し重なった扇形、端がめくれる、など「持てる」形を借りる）。掴んだ瞬間に、落とせるタイル全部がそろって薄く縁取られる。見出しには掴み手の印を置く。舞台の説明文は無くす。

4. **裏が作り物で触れず、落とせない**（裏返す/01, 03：全部 0、拡大 X/Y も 0）
   → 裏の行も表と同じ値として扱う：本当の数値、横に引いて変えられる、行動カードを落とせる。位置 X/Y はよく揺らすので、表に出すか、裏に落とした値が表に上がってくるようにする。

5. **順番が効くカードと効かないカードの区別が無い**（順番/01→03 は止め絵ではほとんど違わない。見た目・色は動かしても何も起きない）
   → 順番が意味を持つカードの間にだけ、つなぎの印（矢印か線）を出す。入れ替えた瞬間、舞台の星に「輪ごと／1つずつ」の違いが分かる短い動きを見せる。効かないカードの並べ替えは、意味が無いことが分かる形にするか、そもそもさせない。

## 壊れている・紛らわしい状態

- ずれを大きさに乗せると（05）タイルは「20px」で止まる。1つ目の星＝最小値を出しているだけで、12個の違いは読めない。青地に青字で灰色に見え、効いていないように読める。
- ×2 で半径が上限 300px に張り付き、輪が舞台からはみ出す（04）。動きが上限で切れて、星が下に固まる。
- 揺れを半径に乗せると、星1つずつ位相がずれるので輪がいびつな卵形になる（03）。輪全体が呼吸すると思った人は裏切られ、輪ごとにする選び方も無い。
- 引きはがした後もタイルが光る（08）。「付けた」時と同じ光で、外れたのに付いたように読める。
- 外す手は 18px の丸だけ。ドラッグ中にどこでも離すと外れる。×3 → ×2 の段は無い。
- 1つの値に2枚重ねられない（重ねると入れ替わり、前のカードは何も言わずに消える）。
- 伏せたカードは中身ごと閉じるので、その値に何が刺さっていたかが消える（伏せる/01）。
- 並べ替えは複製と波の間でしか効かない（コードで固定）。他は動かしても絵が変わらない。
- 順番/02：運んでいる波カードが色カードの数字（72°, 62%）を半分隠し、どこに入るかの隙間が見えない。
- 重ねる/02：掴んだカードが落とす先のタイル（半径）を覆って、名前が読めない。上に来たことは右上の小さな印でしか分からない。
- 裏の「大きさ」が複製と見た目の両方にあり、どちらの大きさか分からない。
- 数（数＝12）にも揺れを乗せられ、星の数が増えたり減ったりしてちらつく（コード上、受け付けが全部の値）。
- コードの棚／着る／束ね（shelf, wear, tie, bundles）は画面から届かない。見本の説明にある「自由に扱える」の一部はまだ無い。

## 注記

判定の途中で cards_set.dart / cards_table.dart が書き換わった。「投げる」（棚のカードを舞台に投げて付ける）と「束ねる」（タイルを長押しして別のタイルに落とす）の2つが加わっている。この判定はそれより前のコードと、4つの使い方（重ねる・裏返す・順番・伏せる）の絵だけを見たもの。最後の行「棚・束ねは画面から届かない」と、項目4の同じ指摘は今は古いかもしれない。2つの新しい使い方は絵が無いので見ていない。
