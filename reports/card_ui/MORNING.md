# カードの夜：朝のまとめ（2026-10-19）

## 触れる所
Widgetbook の「インスペクタ案 > カード」。窓は Terminal の「カード」タブで開いてある（閉じていたら下の1行）。
```
skin/book で: flutter run -d macos --dart-define=LAB_ROUTE='/?path=インスペクタ案/カード/重ねる'
```
使い方は7頁（どれも同じ1つの台。始めの状態だけ違う）：重ねる／裏返す／順番／伏せる／投げる／舞台に落とす／束ねる。
撮った絵（手で触る順）：reports/card_ui/<頁>/NN_*.png（45枚）。

## できること（今の窓のカードとタイルのまま、手つきだけ足した）
- 手札（揺れ・ずれ・ノイズ・ランダム）を値のタイルに重ねる → その値が星1つずつ動く。乗せただけで舞台が先に動く、落とせる所は持った瞬間に縁取り、断る所（数）では運ぶカードが灰色に×
- 同じカードをもう一度 → 幅が増える。違うカード → 入れ替え（幅と速さは残る）
- 印を押す → その揺れ自身のつまみ（幅・速さ・シード、ずれは起点 端／中／逆）。印を別の値へ運ぶ → 移る（相手の印とは入れ替わる）。手札へ運ぶ → 外す
- 手札を押す → 最後に触った値に付く（AE の「選んでから当てる」）
- 手札を星に持っていって止める → 値の輪（大きさ・半径・1つずつ回す・色相）、向きで選ぶ
- カードの見出しを持つ → 上下で並べ替え（効く順：波の札に「1つずつ／輪ごと」、札を押しても入れ替わる）、棚へ運べば外れる
- 棚のカード（散らす・波）を舞台かインスペクタに投げる → 付く
- 裏返す → 全部の数値（こすれる、打てる、カードも重ねられる）。伏せる → 効かない（付いている印は小さく見える）
- タイルの名前の帯を長押しで持ち上げ、別のタイルに落とす → 束。束をこすると全部が同じ割合で動き、どれかが端で止まる（止めた値が赤）
- どの数字も押せば打てる。取り消し ⌘Z／やり直し ⇧⌘Z（運んでいる間・こすっている間は効かない）

## 先例（4言語、research_notes/card_ui/SUMMARY.md）
4言語すべてに出た型：重ねると効く（Stacklands）、枠に入れる（Cultist Simulator）、並び順が効く順（Balatro）、落とす前に結果を見せる（Slay the Spire）。見本に入れたのは表の「見本に入れた」の列。入れていない尖った物：置いた場所で意味が変わる（Zodiac Mountain）、文を切って貼る（Cut the Cards）、持った時に相手へ線（Backpack Battles）。

## 正直なところ
- cards_table.dart が 1,791 行。見本としては重い。中身（doc.h の behaviour と `_by`）にはつないでいない。本物にするなら、手つきの決まり（何をどこに落とすと何が起きる）だけ持っていき、値・揺れ・束は doc.h の物を使う
