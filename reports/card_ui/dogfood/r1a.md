# 手で触る試験 r1a

目標：「輪で6つの四角を全部動かす。輪の何かを変えると、四角が全部いっしょに変わる（回る、大きくなるなど）」

## 1. できたか
**できた。** 23手（最初の `look` を含む。絵 002〜023）。
このうち最初の8手は手探りで、何も起きないか、つなぎ方が分からなかった。つなぎ方が分かってからは14手で、6つをつないで確かめるまで行けた。

## 3. 一番詰まった所
絵 002〜008。輪の Rotation の値を「持って」どこかへ運ぶ方法を探していた。
- ふつうのドラッグ（2・3・7手目）は何も起きず、画面にも何も出なかった（少なくとも離した後の絵には何も残らない）。
- 舞台の四角の上へ運ぶ（AE のピックウィップのつもり）のは、長押ししても効かなかった。
- 結局「名前の所を長押し → 下の列へ運ぶ」でだけカードになった。これは4つ目の当てずっぽうで、たまたま当たった。長押しが要ること、行き先が舞台の四角ではなく下の列であることは、絵からは分からなかった。

## 4. 「こうなっていると思った・あると思ったのに無かった」もの
- 値のタイルを舞台の四角の上へ落とせば、その四角の同じ値につながると思った（AE のピックウィップ風）。効かなかった。
- 値をふつうにドラッグすると何か動く（持ち上がる・影が出る）と思った。離した後の絵では何も変わらず、「こすって値が変わったのか、持ったのか」も分からなかった（値は 0° のままだった）。
- 6つ同時に選んで一度につなぐ方法があると思った（S1〜S6 をまとめて選ぶなど）。見つからなかったので1つずつ6回つないだ。
- 下の列の右の空の枠（四角を選んだ時に出る）が何の場所なのか分からなかった。

## 5. どうやって効いていると分かったか
- 絵 011：S1 の Rotation タイルに「↗R」の印が出た → R からもらっていると読めた。
- 絵 022：輪の Rotation タイルに「→6」と出た → 6つに渡していると読めた。
- 絵 023：輪の Rotation を 0° → 122° にすると、6つの四角がすべて同じ角度に傾いた。これで目標どおり動いていると確かめた。
