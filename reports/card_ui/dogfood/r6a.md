# テスター r6a（初めて触る人）

## 1. できたか
**できた。9手**（最初の「look」を入れて9手、実際の操作は8手）。

目標：星の輪の値を1つ選んで、四角たちの親分にする。その値を変えたら3つ以上の四角が一緒に変わるようにする。そのあと四角を1つ外して、残りがまだ付いてくるか確かめる。

## 3. 一番詰まった所
大きく詰まった所はない。迷ったのは最初だけ：001 で「親分にする」ためのボタンや「つなぐ」という文字がどこにもなく、値の名前の左の小さな点々（⠿）を見て「これを掴んで運ぶのかな」と思った。ここは推測。点々が小さく、掴めることがはっきりとは分からなかった。

## 4. 「こうなっていると思った・あると思ったのに無かった」もの
- R の値を右クリックや長押しすると「つなぐ」「親にする」のようなメニューが出ると思ったが、試す前に運ぶだけで済んだ（無いかどうかは確かめていない）。
- 札「A」を見ても、どちらが親でどちらが子かは書かれていない。一覧の先頭が「Ring · Size」なので R が元だと読んだが、向きを示す印はなかった（今回はどちらを動かしても皆が動く作りかもしれない。確かめていない）。
- 外したあと S4 が元の大きさ（44px 相当）に戻ると思っていたが、大きいまま残った。困りはしないが、少し意外だった。

## 5. どうやって効いていると分かったか
- **006**：R の Size を 44→78px にすると、星と一緒に S1・S2・S4 の3つが大きくなり、札の無い S3・S5・S6 は元の大きさのまま。親分として効いているのが見えた。
- **008**：一覧から Square 4 を外すと、S4 の名前から「A」が消えた。
- **009**：R の Size を 54px に下げると、S1・S2 は一緒に小さくなり、S4 だけ大きいまま残った。外した四角は付いて来ず、残りはまだ付いて来ることを確認した。
