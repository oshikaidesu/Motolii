# ドッグフーディング r4b

目標（使う人の言葉）: 「四角が星に反応してほしい。星の色が変わったら、四角すべての色も変わるように」

## 1. できたか

**できた。11手**（最初の `look` を含む。002〜012）。当てずっぽうは 0。

## 2. 1手ごとの表

| 番号 | したこと | 期待したこと | 起きたこと | 迷い |
|---|---|---|---|---|

| 2 (003) | 左上の四角 S1 をタップ | 四角が何で色を持っているか見たい | S1 が選ばれ、右に Layer と Fill（Hue 160°, Lightness 60%）。四角も Fill の Hue で色が決まると分かった | 0 |

## 3. 一番詰まった所

大きく詰まった所は無い。少し迷ったのは 004 の絵で、「星の Hue を四角につなぐ入口はどこか」を探した所。Hue のタイルの名前の左にある「⠿」の点々だけが手がかりで、それを掴んで引くのは推測だった（当たった）。

もう一つ、005 でつないだ直後は四角の色が何も変わらなかったので、一瞬「失敗したか」と思った。名前の横に「→S1」「S1 ↗R」が出たのでつながったと分かったが、実際に効くかは星の色を動かすまで分からなかった。

## 4. 「こうなっていると思った・あると思ったのに無かった」もの

- 6つの四角に一度でつなぐ方法が見つからなかった。同じ引く動きを6回くり返した。まとめて選んで落とす、または「四角すべて」に落とせる場所があると思ったが、見える所には無かった（舞台の空いた所に落とすことは試していない。思いつかなかった）。
- つないだ瞬間に四角の色が星と同じ色になると思っていた。実際は元の色のままで、その後に星が動いた分だけ動く（それぞれ違う色のまま一緒に回る）。目標の「星の色が変わったら四角も変わる」には合っているが、「同じ色にそろう」と思っている人は戸惑いそう。

## 5. どうやって効いていると分かったか

- 006 の絵: 星の Hue を 72°→185° に変えたら、つないだ S1 だけが緑→紫に変わり、まだつないでいない S2〜S6 は変わらなかった。
- 012 の絵: 6つ全部つないだ後に星の Hue を 185°→91° に変えたら、四角6つすべての色が一斉に変わった（S1 水色、S4 緑、S2 黄緑、S5 水色、S3 緑、S6 青）。四角の名前には全部「↗R」、星の名前には「R →6」、Hue のタイルには「→6」と出ていた。
