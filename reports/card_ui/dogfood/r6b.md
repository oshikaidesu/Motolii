# 手で試した記録 r6b（初めて触る人として）

目標: 星の輪（R）の値1つで、四角を3つ以上まとめて動かす。そのあと四角1つだけ外して、残りがまだ動くのを見せる。

## 1. できたか

**できた。8手**（最初の「見るだけ」を含む。触った操作は7手）。

## 3. 一番詰まった所

2手目の前（絵 002）。「つなぐ」ためのボタンや印がどこにも書いていないので、何をすればつながるのか探した。値の名前の左の点々（⠿）が唯一の手がかりで、「掴めるなら運べるかも」と当てずっぽうで四角の上へ落とした。うまくいったが、落とす前に「ここに落とせる」という案内は見えていなかった（ドラッグ中の絵は見ていないので、途中で枠が出ていたかは分からない）。

## 4. 「こうなっていると思った・あると思ったのに無かった」

- デザインの「トークン」のように、つないだ四角は**全部同じ色**になると思っていた。実際は、それぞれ元の色のまま、輪を動かした分だけずれる（S1 はピンク、S4 はオレンジ、S2 は赤っぽいピンク、とばらばら）。「全部同じ値になる」つもりの人は、一瞬「効いていない？」と思うかもしれない。
- つないだ瞬間に四角の色が変わらないので、つながったかどうかは名札「A」でしか分からない。
- 外すのは、四角の側（S4 を選んでその Hue から外す）でやるのかと思っていたが、輪の側の名札の一覧から外せた。これは分かりやすかった。

## 5. どうやって効いていると分かったか

- 絵 006: 輪の Hue を 72°→212° にしたら、名札「A」の付いた S1・S4・S2 の3つだけ色が変わり、名札の無い S3・S5・S6 は変わらなかった。
- 絵 008: 一覧から Square 4 を外すと、S4 の「A」が消えた。
- 絵 009: もう一度輪の Hue を 212°→287° にしたら、S1（ピンク→オレンジ寄り）と S2（ピンク→黄色）は変わり、S4 はオレンジのまま動かなかった。残りの2つはまだつながっている。
