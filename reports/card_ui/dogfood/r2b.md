# ドッグフーディング r2b

目標（ユーザーの言葉）: 「CSS の変数のように、1つの数で 6つの四角の色をまとめて動かせるようにする」

## 1. できたか

**できた。16手**（数えたのは窓が受け取った自分の手。数え方の注意は下）。

- 確かめ方: S1 の Hue を 160° から 348° へこすったら、6つの四角が全部同時に緑から赤に変わった（絵 018）。
- 数え方の注意: 始めに `tap 750 158` を 2回送ったが、2回とも帳面（inbox / done）がまっさらに戻されて消えた（その間にフォルダが作り直されたように見えた）。3回目で通った。この 2回は数に入れていない。
- 別の誰かの手が混ざった: 帳面に自分の送っていない `005 tap 1120 164` が入っていた（S1 の Hue タイルのあたりを押す手）。絵には何も変化が無かったので先へ進めたが、同じ {DIR} を別の試す人も使っていた疑いがある。

## 3. 一番詰まった所

絵 003〜004。S1 を選ぶと下に**空っぽの枠**が出たので「ここが変数を置く所だ」と思って押したが何も起きなかった。結局、Hue タイルを名前の所で持ってその枠へ引いたら、枠ではなく右のカードの列にカードができた。「値を引いて外へ出せる」こと自体は当てずっぽうで、見て分かる合図は無かった。

次の小さな迷いは絵 009〜010。2つ目は引いてつなげたが、S3 を選んだら Hue タイルに枠がついていたので「カードを押すだけでいいのでは」と賭けたら当たった。そこから先は早かった。

## 4. 「あると思ったのに無かった」もの

- 空っぽの枠の意味。押しても何も起きず、何を入れる所なのか分からない。実際に引いた値は枠ではなく隣のカードの列に入った。
- 「変数」そのもの（どの物にも属さない数）。できたのは「S1 の Hue を他の 5つが見る」形で、S1 が親になる。S1 を消したり S1 だけ色を変えたくなったらどうなるのかは見えない。
- 6つまとめて選んで一度につなぐ手。1つずつ選んで押すのを 5回くり返した。
- 値を外へ引き出せるという合図（名前の帯に持ち手の点はあるが、小さくて引くものだと気づかなかった）。

## 5. できたことがどう分かったか

- 絵 008, 010, 012, 014, 016: つないだ四角の Hue タイルに「↗S1」が出て、数字が S1 と同じ 160° になり、四角の色が緑にそろった。
- 絵 017: 元の S1 の Hue に「→5」と出て、5つに配っていることが読めた。
- 絵 018: S1 の Hue 1つをこすっただけで 6つ全部が赤（348°）に変わった。ここで「1つの数で 6つの色を動かせている」と確かめた。
