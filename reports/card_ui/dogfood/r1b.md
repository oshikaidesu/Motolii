## 3. 一番詰まった所
絵 003〜006。値を「持ち上げる」方法を探していた。下の空き枠は置き場に見えたが、タイルをふつうに引くと値がこすれるだけ（004）。名前を長押ししてから引いたらカードになった（006）が、これは当てずっぽう。長押しが要ることを示すものは見当たらなかった。

## 4. 「こうなっていると思った・あると思ったのに無かった」もの
- つないだ瞬間、つながれた側の四角が約2倍に大きくなった（007, 010, 012…）。タイルは 90px のままで、実際に描かれる大きさと数字が合わない。「同じ値になる」と思っていたので驚いた。どうやら元の値が足されている（自分の 90 + S1 の 90）ように見えるが、それは推測。中身の数字（実際の値）が見えない。
- 四角の番号が見た目の並び（横）と違い、縦に S1→S3、S4→S6。右上が S2 だと思った。
- 値を持ち上げるのに長押しが要る、という合図。ふつうに引くとこすりになる。
- 2つ目からは「選んで手札を押すだけ」でつながったのは楽だった。けれど、これも試してみて分かったことで、押す前は分からなかった。

## 5. どうやって分かったか
- 絵 017：S1 の Size に「→5」と出て、5つに渡していると分かった。
- 絵 018：S1 を 32px にこすると、ほかの5つの四角も一緒に小さくなった。
- 絵 019：90px に戻すと、5つも一緒に大きくなった。1つの値で全部が動いている。
