# テスター r7b（はじめて触る人）

## 1. できたか
**できた。8手**（最初の `look` を含む。実際に操作したのは7手）。

目標: 輪（R）で何かを動かすと、3つ以上の四角が一緒に動く。そのあと1つを外して、外したものは動かず、残りはまだ動くのを確かめる。

## 3. 一番詰まった所
大きく詰まった所はなかった。少しだけ迷ったのは最初（絵 002）で、「輪の値を四角につなぐ」入口がどこかを探した。値の名前の左の小さな「⠿」をつかんで四角に落とせばいいと推測したが、ガイドがないので当てずっぽう半分だった。うまくいったのは運。

## 4. 「こうなっていると思った・あると思ったのに無かった」もの
- 外し方を、最初は「四角を選んでその四角の Size から外す」ものだと思っていたが、輪の側の名札を押すと一覧が出る形だった。こちらのほうが早かったので困らなかった。
- 運ぶ途中に「どこに落とせばいいか」の光り方がどうなるかは見ていない（一気に運んだので）。
- 無いと思って困ったものはなかった。

## 5. どうやって効いていると分かったか
- 絵 006: 輪の Size を 44px → 78px にすると、星と一緒に S1・S2・S4 が大きくなり、名札の付いていない S3・S5・S6 は元の大きさのまま。3つが従っているのが見えた。
- 絵 008: × のあと、舞台の S4 から「A」が消えた。
- 絵 009: Size を 55px に下げると星・S1・S2 は小さくなり、S4 だけ大きいまま残った。外した1つは止まり、残りはまだ従っているのが見えた。
