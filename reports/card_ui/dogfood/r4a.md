# ドッグフーディング 4回目 A（r4a）

目標（使う人の言葉）: CSS の --angle のように、全部が読む1つの値。6つの四角の傾きを、1つの操作でまとめて決めたい。

## 1. できたか
できた。5手（look を含む。実際に画面に触ったのは4手）。当てずっぽうは1手（3手目）。

## 2. 1手ごとの表

| 番号 | したこと | 期待したこと | 起きたこと | 迷い |
|---|---|---|---|---|
| 1 (002) | look | 始めの画面を見る | 左に星の輪 R、右に四角 S1〜S6、右の板に R の値（Layer / Copies / Wave / Fill）、上に R S1..S6 の札 | 0 |
| 2 (003) | 上の札「S1」を押す | S1 の値が右の板に出る | S1 が選ばれ、Layer（Size 90px・Rotation 0°・Opacity 100%）と Fill が出た | 0 |
| 3 (004) | S1 の「Rotation」の名前（左に掴む点々がある所）を、舞台の何も無い所（四角と星の間）へ引いて落とす | 何かが起きるか試す。全部に同じ値を配る形になれば良いと思った | S1 の名前が「S1 →6」、他が「S2 ↗S1」…「S6 ↗S1」になり、Rotation の札にも「→6」が出た。6つが S1 の傾きにつながったと読めた。ただし星の輪 R も「R ↗S1」になった | 2 |
| 4 (005) | S1 の Rotation の数字を右へこする | 全部の四角が一緒に傾く | 84° になり、6つの四角すべてが同じだけ傾いた（星の輪も回った） | 0 |
| 5 (006) | 同じ数字を左へこする | 小さい角度でもう一度確かめる | 19° になり、6つの四角すべてがはっきり19°傾いた | 0 |

## 3. 一番詰まった所
003 の絵。「1つの値を全員に読ませる」ための入口がどこにあるか分からなかった。値の名前の左にある点々（⠿）が「掴める」印に見えたので、引いてみるしかなかった。落とす先も、四角1つずつに落とすのか、空いた所に落とすのか分からず、空いた所に落としたのは当てずっぽう。結果的にそれが一発で正解だった。

## 4. 「こうなっていると思った・あると思ったのに無かった」もの
- 「6つの四角だけ」をつなぎたかったのに、四角でない星の輪 R まで S1 の傾きにつながった（「S1 →6」の6は S2〜S6 と R の6つ。四角は S1 を入れて6つ、R は余分）。同じ名前（Rotation）を持つ物すべてがつながるので、つなぐ相手を選ぶ／外す方法が見えなかった。今回は外し方は探していない。
- CSS の変数のように「どの物にも属さない、独立した1つの操作」を作る場所は見当たらなかった。S1 自身の Rotation が親になる形。S1 も他と一緒に動くので目標には足りているが、「S1 を選ばないと操作が出ない」点は少し意外。
- 落とす前に、空いた所に落とすと全部につながるという手がかり（文字や印）は絵の中に見えなかった。

## 5. どうやって分かったか
- 004 の絵: 舞台の名前が「S1 →6」「S2 ↗S1」…に変わり、Rotation の札に「→6」が付いたので、つながったと分かった。
- 005 の絵: S1 の数字を 84° にしたら、6つの四角すべてが同じ向きに傾いた。
- 006 の絵: 19° にしたら、6つの四角すべてがはっきり同じ角度で傾いた。ここで「1つの操作で全部の傾き」が効いていると確かめた。
