## 手つきの候補（先例が来たら入れ替える）
- 値の行に重ねる → その値が動かされる（behaviour の _by）
- 山の順番を入れ替える → 効く順が変わる
- 裏返す → 表はつまみ数個、裏は全部の数値
- 束ねる → マクロのカード
- 半分重ねる → 2枚の設定を混ぜる
- 伏せる → 一時的に効かない
- 舞台の物に投げる → その物にカードが付く
- 手札 → 作ったカードを持っておく、別の物に使う
- 上に乗せただけで効きが見える（落とす前）
- 同じカードに落とすと合わさる、違えば入れ替わる（猫之城）
