## お手本の順番（決めたこと）

- 時間とキー：Ableton。描く：Figma（Illustrator は比べるだけ）。動画にしか無いもの：Cavalry・Blender・Jitter・Rive・Theatre.js・Spline。絵とレイヤー：クリスタ。動画の切り詰め：Resolve・Final Cut。トラックパッド：Apple。
- **Adobe 全般は比べるだけ**（古い縛りを避けるための操作が多い）。新しいツールのどれにも無い操作は「Adobe だけ」と印を付けて疑う。
- 第三者の記事は、公式と照らしてから使う。
- 手元からではなく、お手本の側から全部持ってきて当てはめる。

## 仕組みごと無いもの（1 つずつ足すより先に決める）

1. **見つけるための仕組み**：命令の表から、メニュー・右クリック・検索・キー・ヒントを全部作る（VS Code の形、MIT。Flutter の PlatformMenuBar・MenuAnchor）。これが無いと、ほかに何を足しても初めての人は見つけられない → discoverability.md
2. **右クリック**：お手本はどこにでもある。Motolii は値の行だけ
3. **コピーと貼り付け**：物・キー・見た目・時間。文字の欄だけ
4. **グループと入れ子**、**選び方**（深い所、同じ物、反転）
5. **時間の編集**：切る・まとめる・リップル・スリップ・範囲
6. **キーの編集**：グラフでキー、複製、伸び縮み、焼く、繰り返し、キーの上に重ねる
7. **値のつなぎ**：出っ張りでつなぐ（Cavalry）、ドライバ（Blender）
8. **見る・動く**：拡大のキー、手のひら、寄る、パネルを隠す
9. **書き出しの中身**：外の ffmpeg を文字列で組んで、速さ 60・CRF 17 で決め打ち。GStreamer の書き出しプリセット（.gep）と encodebin に任せれば、形式と画質の選択肢も GStreamer から出る → export_map.md
10. **文書の設定**：コマの速さと長さがどこからも変えられない
11. **新しい文書・設定・ファイル・ヘルプの画面**

## 今日直したもの（コミット済み、テスト 141 本通る）

- MIDI ビュー：強さ・時刻は bladeSk、曲線は Godot の Tween（MIT）に任せた
- 音だけのファイルの判定 → GStreamer、ロールの大きさ → ThorVG、ペンの線の読み取り → Skia
- トラックパッド：タイムライン・ステージ・関係のパネルで 2 本指とピンチ。ほかのドラッグ 13 か所は 2 本指をドラッグとして取らない
- 書き出しの画面を Esc・⌘. で閉じる
- カメラのカードの Target の選び札を文書の層に

## Ableton に合わせたもの（10/25 夜、今の動きを変えてよいと決めた後）

| 何 | 前 | 今（Live 12 マニュアルの節） |
|---|---|---|
| ⌘R | 書き出し | 選んだ層・選んだロケーターの名前（42.5、42.19） |
| ⌘⇧R | — | 書き出し（42.3） |
| Space | 今の位置から再生・止める | 始めた所から再生、止めるとそこへ戻る（42.20） |
| ⇧Space | — | 止めた所から続ける（42.20） |
| ← → | 1 コマ送り | 選んだキー、無ければ選んだ帯、無ければ再生位置を 1 コマ（⇧ で 10）（42.16） |
| ↑ ↓ | — | 前・次の層 |
| , . | — | 1 コマ送り（Live に無いので Rive・Jitter） |
| S・⌘L・+ −・Z・X・W | — | ソロ・ループ・拡大縮小・選んだ所に寄る・戻る・幅に合わせる（42.9、42.15、42.16） |
| ルーラーを押す | こする | そこから再生（6.3）。ドラッグはこする |
| マーカー | ダブルクリックで足す・名前（After Effects） | 右クリックで足す、押すとそこへ行って選ぶ、ダブルクリックでそこから再生、⌘R で名前、Delete で消す（6.4） |
| 数字の欄 | 押すと（少し後に）打ち始める、⇧ で 10 倍 | 押すと選ぶだけ、数字を打つと打ち始める、Delete かダブルクリックで既定に、⇧ で細かく（42.4、42.6） |
| メニュー | — | Edit に Rename・Solo・Deactivate、View に拡大・再生・ループ、File の Render は Export Video… |

変えなかったもの：Animate all（Ableton は手で動かすとオートメーションより手が勝つが、Animate all は意図して作ったので残す）。
まだ：⌘E（帯を切る）・⌘J（まとめる）・⌘⇧X/C/V/D（時間ごと）はエンジンに切る・まとめるが無い。オートメーションの線の上の操作（押して点を足す、点を押して消す、⌥ドラッグで曲げる）、⌘G（Ableton のグループトラックに当たる入れ物が無い）、選んだロケーターの見た目の印。

## 決めてほしいこと

1. **ツールのキー**：四角と楕円を Figma（R・O）か Illustrator（M・L）か
2. **矢印キー**：お手本 3 つとも「選んだ物を少し動かす」。Motolii はコマ送り。合わせるならコマ送りをどこへ
3. **⌘R**：Ableton も Figma も「名前を変える」。Motolii は書き出し
4. **値の色**（Blender の、キーの状態を色で見せる形）を足すか
5. **書き出しの中身を GStreamer に移すか**（ffmpeg の決め打ちをやめ、プリセットを GStreamer から出す）
6. **見つけるための仕組みを先に入れるか**（命令の表 → メニュー・右クリック・検索）
7. **コマの速さと長さ**を、隠してある欄から出すか、新しい文書の画面を作るか
