# Illustrator・Figma を土台にした描く側の操作の照らし合わせ（10/25）

Ableton に無い描く側（ツール、線、図形、整列、文字、色）を、Illustrator と Figma の公式の一覧から全部持ってきて Motolii に当てはめる。印は ableton_map.md と同じ 4 つ（同じ・違う・無い・外す）。

出典：
- Illustrator：Adobe「Default keyboard shortcuts | Illustrator」（2026 年 2 月 17 日更新）
  https://helpx.adobe.com/illustrator/using/default-keyboard-shortcuts.html （節の名前はページのまま。キーは Mac）
- Figma：全部の一覧は公式にはアプリの中の Keyboard shortcuts パネル（⌃⇧?）だけ（公式ヘルプ https://help.figma.com/hc/en-us/articles/360040328653 ）。そこで第三者の一覧を 3 つ集めて照らし合わせ、公式ヘルプの記事で確かめられるものは確かめた：
  - **R**：Raycast の拡張「Figma Shortcuts」のデータ（MIT、2026-07-02、140 以上）
    https://github.com/raycast/extensions/blob/c33bf4cb4b9ad70c2b93432ee713ffb7486ed331/extensions/figma-shortcuts/src/data/shortcuts.ts
  - **TT**：Tutorial Tactic「Figma Keyboard Shortcuts: The Complete Mac & Windows List (2026)」 https://tutorialtactic.com/blog/figma-shortcuts/
  - **MW**：MeshWorld「Figma shortcuts cheatsheet」 https://meshworld.in/blog/cheatsheets/figma-shortcuts-cheatsheet/ （公式のブーリアン ⌥⇧U を O と書くなど誤りがあるので、票には数えるが単独では採らない）
  - **公式**：Figma ヘルプの Boolean operations（⌥⇧U・⌥⇧S・⌥⇧I・⌥⇧E） https://help.figma.com/hc/en-us/articles/360039957534 、キーボードで使う（矢印で画面を動かす、⌥Space、Return で置く）
  - 確度：**公式**／**2 か所**（第三者 2 つ以上で同じ）／**1 か所**（R だけ）／**食い違い**

**キーのぶつかり**（いちばん先に決めること）：

| Motolii | Illustrator | Figma（ヘルプにあるもの・ツールの名前） |
|---|---|---|
| V 選択 | V 選択 | V 移動（＝選択）（2 か所） |
| M 移動 | **M 四角** | — |
| R 四角 | **R 回転** | R 四角（2 か所） |
| E 楕円 | **E 自由変形**（楕円は L） | O 楕円（2 か所） |
| P ペン | P ペン | P ペン |
| T 文字 | T 文字 | T 文字 |

Illustrator と Figma が食い違う（四角が M と R、楕円が L と O）。Motolii の R＝四角は Figma 側、E＝楕円はどちらとも違う。

ほかのぶつかり：
- **0**：Figma は不透明度 100%（数字キーで不透明度）、Ableton と Motolii は見える・見えない
- **⌘R**：Ableton と Figma はどちらも「名前を変える」、Motolii は書き出し → 2 つのお手本が揃っているので合わせやすい
- **矢印**：Illustrator と Figma はどちらも「選んだ物を少し動かす」、Ableton も「選んだクリップを少しずらす」、Motolii だけコマ送り → 3 つとも揃っている
- **Space**：Ableton は再生、Illustrator と Figma は押している間だけ手のひら

「無い」で多い所：重なり順（⌘] ⌘[）、グループ（⌘G）、隠す・鍵（⌘3 ⌘2）、矢印で動かす（Motolii の矢印はコマ送り）、貼り付けの種類（前・後ろ・同じ場所）、変形の繰り返し（⌘D）、⌥ドラッグで複製、線をつなぐ（⌘J）、複合パス・パスファインダー、クリッピングマスクのキー、表示の拡大縮小（⌘+ ⌘− ⌘1、Space で手のひら）、ガイド・スナップのキー、塗りと線の入れ替え（X ⇧X D）、スポイト（I）、文字の大きさ・字間のキー、文字を線にする（⌘⇧O）。
