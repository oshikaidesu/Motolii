# ロシア語圏（＋ウクライナほかCIS）で好まれる After Effects のスクリプト・パネル

調べた日: 2026-10-17 / ウェブのみ・読むだけ / 約25分 / ブラウザは1タブだけ使用（Motion Tools Pro の画面を見た）

## 1. 呼び名（先に集めた言葉）

- скрипты для After Effects（AE のスクリプト）… いちばん多い
- полезные скрипты / лучшие скрипты / топ скриптов（便利な・ベストな・トップ）
- бесплатные скрипты（無料スクリプト）
- плагины для After Effects / лучшие плагины（プラグイン）
- расширения / «екстеншины»（エクステンション。「スクリプトに似ているが見た目がよく Premiere でも動く」と説明される）
- панель / панель инструментов（パネル、ツールバー）
- набор инструментов / «швейцарский нож»（ツールセット、「スイスナイフ」＝Motion を指す定番の言い方）
- лаунчер скриптов（スクリプトランチャー）
- выражения / экспрешены（エクスプレッション）
- пресеты, паки（プリセット、パック。Motion Bro, AEJuice, Animation Composer は「パック」扱い）
- моушн-дизайн инструменты, автоматизация рутины（ルーチンの自動化）
- энкор-пойнт / анкор поинт, изинг, графики скорости（アンカーポイント、イージング、速度グラフ。英語の音写がそのまま使われる）
- ZXP Installer（インストールの話題で必ず出る）
- 「скачать бесплатно」（無料でダウンロード）… 検索上位に海賊版めいた「ダウンロード方法」記事が多い。ロシアからは Adobe を普通に買えない事情があり（vc.ru に「ロシアから AE のサブスクを買う方法 2026」記事あり）、これが目立つ。

## 4. 「AE に足りない」という声

- テキスト: 内蔵の段落が弱い、文字の分解ができない → Paragraph 2, TextExploder, Decompose Text
- アンカーを動かすとアニメがずれる → Motion Tools, Reposition Anchor Point
- イージングが弱い、グラフエディタが古い（弾み・行き過ぎが内蔵にない）→ Flow, Motion, Motion Tools
- 書き出し: 新しい AE では普通の圧縮の H.264 が出ない（2分で約2GB）、Media Encoder もコーデックが足りない → AfterCodecs, HandBrake, Render Garden, DuMe
- Illustrator / Figma から持ってくるのが手間 → Overlord, AEUX
- コンプの途中にフレームを足せない → Elastic Comp Changer
- 入れ子コンプの一括変更・複製ができない → rd: Comp Setter, True Comp Duplicator
- プロジェクトが散らかる → Declutter, Organize Project Assets
- スクリプトが多すぎて画面が埋まる → KBar, ランチャー類（Quick Menu は「Ramp で Gradient Ramp を出せない」と不満）
- 式でプレビューが何倍も遅くなる → キーに焼く
- Lottie 書き出しで光彩や線が落ちる
- （地域の事情）ロシアから Adobe を正規に買いにくい → 「無料ダウンロード」記事が多い

## 5. パネルの見た目

- Motion Tools Pro（画面を見た）: 黒地に角丸の四角いタイルを格子に並べる。文字はほぼ無く、記号で語る（< > × の行にスライダーと数値箱、キーフレームの菱形、四角の塗り/線、ベジェの山、イージングカーブの小さな絵、揃え4種の線の絵、「Num: 1」「Step: 1」の小さな箱）。選んだタイルだけ紫。色・アイコン・間隔は利用者が変えられ、パネルは4枚まで別配置。
- Motion Tools Classic: ScriptUI の素朴なパネル（.jsxbin を Scripts に置く）。
- KBar / Motion Lovers Tools: 利用者が自分でアイコンボタンを並べる棚。
- Flow: カーブを選ぶ簡単な画面（スクショのみ）。Motion V2: プリセット（バウンス等）の追加パネル。
- パック系（Motion Bro, AEJuice, Atom X）: サムネイルの格子から選んで置く。
