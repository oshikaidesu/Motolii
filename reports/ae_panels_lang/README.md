## パネルの見た目（どの言語でも同じ）

- **その国で作られた道具は小さい。** ボタンは1〜3個で、押すと1つの仕事が終わる（日本の GG文解は丸ボタン3つで、文字はない）。
- **記号が結果を表し、文字はほぼない。** 韓国の Easy Flow は細い帯に記号のボタンが並ぶ。Motion Tools Pro は黒地に角丸のタイルが並ぶ。
- **3×3 の向きの矢印**（スペインの Quick Animator）。
- **売り場の表紙は、パネルではなく「できた結果の絵」**（BOOTH）。

## Motolii にとって

- **言葉の穴は、どの国でも「画面の言葉」から生まれている。** 文字を隠しても分かる窓（課題26）は、それをまるごと消す方向で、ここは他の道具にない強み。
- **文字を割る穴は5つの言語にまたがる、いちばん大きな穴。** 日本語と韓国語は、1文字より細かい単位まで要る。
- **字幕と音合わせは、どの国も後付けで足している。**
- **前回の英語中心のまとめで「日本だけ」「中国だけ」と書いた道具の多くは、その国の作ではなかった。** 国の振り分けは、この5本の方が正しい。
