# 2020 年代の「過剰な」映像 20 本の要素分解(2026-09-18 取得)

課題: 「見るべきは 2020 年のもの、過剰なもの」。2020〜2026 の maximalism(うるさいほど要素が多い物)を国内外から 20 本選び、今朝の型で分解する — 素材(何種類)/ 色(何色に決め切っているか)/ 法(動きの遺伝子: 生き物 = Disney 12 原則、物 = 物理、数 = 反復・対称・写像、音 = 拍で揃う)/ 層の数の見立て / 意図の手の数の見立て(素材・箱・密度・札・例外)/ 純関数か記憶か / 道具(本人が明かした物)/ **何が過剰か 1 行**。

一次資料優先(本人インタビュー、公式クレジット、Motionographer Project Breakdown、Motion Awards の作品頁、VIDEO SALON・CGWORLD・NEWREEL・Real Sound Tech のメイキング)。**見ていない物を見たようには書かない**: 分解は breakdown・静止画・本人の説明から読める範囲、読めない項は「未確認」。判断(Motolii でどうするか)は書かない。

## 0. 要約(5 行)

1. **一次資料に「層の数」を明かした作品はほぼ無い**。数が出るのは カット数・テイク数・shot 数・version 数(ビビデバ 30 カット 200 テイク、EEAAO 481 shot / 2,819 version、CSM OP 18 オマージュ)であって、レイヤー数ではない。層の見立ては全て読み手側の推定。
2. **過剰の作り方は大きく 5 通り**に分かれた: (a) **素材種の混在**(実写 + 作画 + 3D + 紙、Spider-Verse の 6 様式、Nickelodeon の 3D/cel/sim)、(b) **引用・cameo の数**(CSM OP 18 本の映画、360 の 14+ 人、corecore の無関係クリップ)、(c) **速度・カット密度**(ダンダダン OP「息をする前に」、Von dutch、velocity edit)、(d) **1 コマ = 1 枚絵の密度**(Late Nights「各 shot が独立したイラスト」、HAPPENING の GIF マンガ)、(e) **UI 的装飾の全画面化**(Metaphor/P3R の menu、Poor Things の縁飾り文字)。
3. **色は逆に決め切る例が多い**: brat green 1 色(Charli)、海の青 1 系統(P3R)、白黒 + dither(HAPPENING app)、ブラックライト(置き手紙)。「色数で過剰」を本人が明言したのは Nickelodeon(「eclectic palette、色数を縛らない」)と Berthold Gone Wild(color blocking + holographic gradient)だけ。
4. **法の主流は「音 = 拍で揃う」+「数 = 反復・引用」**。生き物の 12 原則を主軸にした過剰は少なく(Spider-Verse の 2D FX、ダンダダン OP の紙切り)、物理はほぼ EEAAO の practical のみ。K-pop は cameo・ロケ・衣装の「数」で過剰、動きの法は未確認。
5. **道具は AE が中心**、例外が本人の言葉で明かされている: 戸惑いテレパシー(AE + L3tt3rM4pp3r + RetroDither + displacement)、EEAAO(AE + Mocha Pro + Blender、render farm 無し)、Spider-Verse(Harmony + Houdini + Rebelle)、Weirdcore(Kinect + live 生成 + 12 画面)、HAPPENING(GIF + 自作 GUI「Kindelfin」)、置き手紙(伸縮布 + ブラックライト + AE)。**純関数か記憶か**を本人が語った例は無い — 全て「作り方」からの推定。

## 2. 分解の共通項 — 過剰の作り方は何通りあるか

一次資料で確認できた範囲で **5 通り + 混合 1**。

| 型 | 何を増やすか | 該当 | 色はどうしているか | 法 |
|---|---|---|---|---|
| A. 素材種の混在 | 描画規則の数(実写/作画/3D/紙/sim) | Spider-Verse(6 様式)、Nickelodeon(3D+cel+sim)、ダンダダン OP(紙+鉛筆+作画)、ビビデバ(実写+作画)、置き手紙(布+紙+光)、Perfect Night(実写+ゲーム CG) | 素材ごとに別、または 1 つ(ブラックライト)で束ねる | 生き物 + 物 の混合 |
| B. 引用・人の数 | 参照元・cameo の数 | CSM OP(18 本)、360(14+ 人)、corecore(無関係クリップ)、Weirdcore(国ごとの有名人) | 参照元の色をそのまま持ち込む(決め切らない) | 数(並置・写像) |
| C. 速度・密度 | 単位時間の cut・take・状態変化 | ダンダダン OP、Von dutch、ビビデバ(30 カット→1 カット風)、EEAAO(481 shot)、velocity edit | 未確認が多い | 音(拍)+ 記憶(状態が積む) |
| D. 1 コマの絵の密度 | 1 フレームの情報量 | Late Nights(各 shot = イラスト)、HAPPENING(GIF マンガ)、Poor Things(縁飾り)、藍にいな(線の密度) | 白黒 + dither(HAPPENING)、白黒(Poor Things 章)— **密度が高い物ほど色を減らす** | 数(反復・対称) |
| E. UI 装飾の全画面化 | 画面を覆う札・飛沫・線 | Metaphor、P3R、戸惑いテレパシー(ゲーム画面 UI + グリッチ) | 1 系統に決め切る(P3R 青、P5 赤) | 純関数(時刻のアニメ) |
| F. live・生成 | 入力の生と画面数 | Weirdcore(12 画面 + Kinect)、Chris Kore(生成、未読) | 未確認 | 記憶(入力依存) |

観察(一次資料の範囲):
- **「層の数」を過剰の単位に選んだ作家はいない**。数えて語られるのは cut・take・shot・version・引用・人・画面・様式。
- **色で過剰**を明言したのは Nickelodeon と Berthold の 2 例。他は色を 1 系統に絞って素材/速度/引用で過剰にしている。
- **純関数の過剰**は E(UI)と Nickelodeon の 3D パイプ、HAPPENING の scratch のみ。A〜D の大半は記憶型(手描き・実写・反復修正)。
- 手の数の見立ては 1(藍にいな)〜 9(Spider-Verse)。**過剰と手の数は比例しない**: 360 は cameo 14 人でも手は 5、corecore は素材 n でも手は 3。
