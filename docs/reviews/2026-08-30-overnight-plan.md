# 夜間自走の台本(2026-08-30)

- 位置づけ: 利用者が就寝中に進める作業の**範囲と柵**。判断が要る物は入れない
- 前提: 利用者は朝に窓を見て UX 合否を出す。**合否が要る物は「見せる形にして止める」**

## 柵(これを破るなら止まって朝を待つ)

1. **意味を触らない** — `motolii-store` の property 語彙・`Value`・`LayerSource` を増やさない
2. **新しい概念を作らない** — 既にある口の組み合わせで書けない物は着手しない
3. **利用者の裁定が要る物に手を出さない** — ギズモのハンドル挙動、裁定115(層の姿勢が `Affine2`)、
   多段パス、グループレイヤーのUI
4. **窓で見えた物だけを「通った」と書く** — cargo 緑は通行証ではない
5. **全部積む** — 捨てる時も一度 commit してから(歴史を失わない、2026-08-29 利用者裁定)

## 仮コードで測った結果

**Split(切る)は新しい Intent が要らない。** `LayerTiming { start, duration, source_in, speed }` を
2本へ割り、既存の `SetTiming` / `AddLayer` / `SetMeta` / `SetTrack` / `SetEffects` を並べるだけ。
約30行。唯一足りないのは `LayerAttrs → LayerAttrsPatch` の変換口(手で組む)。

## 順番(上から。着いた所で止まる)

1. **Split at playhead**(Cmd+K / 右クリック)— 土台の一周の「切る」。当てが取れている
2. **`increment()` がエフェクト param の宣言 `MIN`/`MAX` を見る** — いま `intensity` を
   30px 引くと `1.5 → 31.5` になる(宣言の範囲 0.0〜4.0 を無視)。**今日見つけた綻び**
3. **反射の通し検分** — `docs/ui-inherited-grammar-gap.md` の Tier 1 を台本に、窓を実操作して
   「触れそうで触れない」「触ったのに何も起きない」を機械的に出す。**直すのは配線だけの物に限る**
4. **`vello_encoding config.rs:185` の減算オーバーフロー** — 仕切り(hgrip)を引きすぎると落ちる。
   `app.rs` の grid 行が0以下に潰れるのが原因の疑い。**再現条件を特定する所まで**
