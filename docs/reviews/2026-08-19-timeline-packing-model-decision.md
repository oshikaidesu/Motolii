# Timeline の配置土台 — 自由配置で確定

日付: 2026-08-19
状態: **決定**(利用者裁定)

## 決定

Motolii の Timeline は **AE 型の自由な絶対時間配置**(free absolute placement)を土台とする。
レーンは「隙間なく詰まる」保証を持たない。

利用者の言:「2 はただの便利機能で今考えるものではない。1 で進む。**まずは普通に動くものを作るべきだ**」。

## 何を採らないか(漏れではなく、設計上の除外)

gapless packing を前提とする**トラックベース系の操作族を採らない**:
ripple / roll / slip / slide / insert / overwrite / lift / extract / sync lock。

これらは Premiere / Resolve / FCP が「レーンが詰まっている」ことを前提に一体で持つ族であり、
自由配置の上に個別に足すと既存の move / trim ジェスチャ
(`timeline_move_gesture.rs` / `timeline_trim_gesture.rs`)と**機構的に衝突する**
([先例調査 §4](2026-08-19-normal-timeline-prior-art.md))。

**「以降のクリップを押し出す」操作**(自由配置のまま修飾キー付き drag で後続をずらす案)は、
利用者裁定により**便利機能として先送り**。今は設計しない。

## 根拠

1. **製品命題**: 3〜5 分の MV。映像が重なり合い、時間は絶対で決まる。ripple 編集は台詞と尺を
   詰めるナラティブ編集の道具で、MV での利得に対し代償(既存 gesture の作り直し)が大きい
2. **コードは既にそうなっている**: `video lane` / `audio lane` は AE 型の層識別語で詰め保証を持たない。
   `concept.md` の主参照も AE + Cavalry
3. **先例調査の実測**([2026-08-19 普通のタイムライン先例調査](2026-08-19-normal-timeline-prior-art.md)):
   7 製品 44 操作のうち**必須 12 件はすべて** egui 側のコードか既決文書に裏付けがあった。
   欠けていたのは個別操作ではなく土台の未選択だけだった
4. 2026-08-03 の decision-index 行「trim family は別境界へ残す」と整合(撤回ではなく確定)

## 影響

- **iced への移植は土台の議論を待たずに進めてよい**(移植中の全レーンに影響なし)
- 「普通のタイムラインとして何か足りないのでは」という問いは、本決定と先例調査で**一旦閉じる**。
  再開の条件は、利用者が実機で「詰め編集が要る」と判断した時
- 先例調査が見つけた**文書化されていない実装**(`add_locator` / `tap_locator` のマーカー、波形帯)は
  [UI 操作言語](../ui-interaction-language.md)に未記載 — 台帳側の追補として残る
- 標準・便利判定の残り(3 点編集・A/V link・track/sync lock・マルチカム・J/K/L)は
  **空席のまま**。本決定はそれらを禁止しない
