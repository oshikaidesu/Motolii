# 層のゴースト — 壊れないディレイ

利用者裁定(2026-09-07、帰り道の会話): AE の「複製して横にずらす」は UI としては直観的(ずれが見える)だが、ずらした結果しか残らず「ずらしている」という意味が Document に無い(Echo は画素を焼き、式の `valueAtTime(time − d)` は UI が無い)。層のアプローチと同じ病気。Motolii は UI を AE のままにして、意味だけを持つ: **ゴースト**。

## 定義

> **ゴーストは、ある層を「別の時刻で見た行」。** Timeline に自分の帯を持ち、帯の位置がそのまま遅れ d。中身は持たない。元の層を `t − d` で評価した物がそこに居る。

- **時刻だけ**を持つ(利用者裁定)。位置・混ぜ方・効果は元に従う。空間の違いはゴーストの仕事ではない
- **実体は縦並びの行**。ゴーストは「ずれ」の表現で、評価軸の話(利用者裁定)。重ね順は AE と同じで、元の上にも下にも置ける
- 元の層のキー・効果を直せば全ゴーストに届く。キーは元の 1 つに打つだけ
- ゴーストはゴーストを作れる(鎖 = follow-through、先端ほど遅れる)。元を消せばゴーストも消える。ゴーストを消しても元は残る
- d は帯を引いて決める。d にキーを打てるか(引き伸ばし)は後で決める

## 分担(2 か所に同じ意味を書かない)

| 意味 | 席 | 見え方 |
|---|---|---|
| 時間のずれ | ゴースト(行) | Timeline の帯が横にずれている |
| 空間の散らばり・集い | Repeater(配置効果)の Each / Random。「集う」は Random Position を 100 → 0 へキーで落とす | Inspector の格子 |
| 切れた複製 | ⌘D | 普通の層 |

2 つは積める: Repeater を掛けた層のゴースト = 散った群れが時間差で同じ動きをする。Echo(残像)は「ゴースト N 本 + 不透明度の Each」なので効果として別に作らない。Repeater の Delay each は「ゴースト N 本を 1 行に畳んだ物」と言い直せる。

## 未決(明日)

- 配置効果の裁定(2026-09-06)「増やし方は 2 つのまま(⌘D と Repeater)」との関係。案: 増やし方でなく**複製の繋がり方**の 3 段 — ⌘D = 切れた複製、ゴースト = 繋がった複製、Repeater = 複製を 1 行に畳んだ物
- ゴーストの Document 上の形(行 1 つ + 参照 + d)と、元の層の尺・タイミングとの関係(遅れた分だけ端が空くのか、ループするのか。AE の時間反転・ループも同じ席)
- 先例: Cavalry の Time Offset、C4D の Delay effector。借りる定規は「時刻の変換は純関数で、前フレームを使わない」(配置効果と同じ)

## 置き場の案: Desk の Ease レンズ(2026-09-07 利用者、案)

ゴーストの編集面は Desk(常設の 1 枚、Document を覗くレンズ)。Ease もレンズなので、**Ease レンズが 2 つのモードを持つ**: **キーフレームモード**(キーとキーの間の曲線を整える、今の Ease)と**レイヤーゴーストモード**(ゴーストの鎖の d の並びを整える — i 番目のゴーストがどれだけ遅れるかを曲線で。stagger の easing)。どちらも「時間の形を曲線で決める」同じ道具で、対象がキー間か、ゴースト間かの違い。Timeline の帯を引く操作(AE の UI)は残し、Desk は鎖全体の形を見る所。要裁定。 モードは焦点で決まる(Desk は焦点を読むだけ): 焦点がキーならキーフレームモード、ゴーストを持つ層ならゴーストモード。利用者の所感: 層を触った時にゴーストの Desk が出るのを最初は面倒に感じたが、分けるべき 2 つでなく同じ概念だから出ていた。

## 実装(2026-09-07 同日、夜に 2 度作り直し)

最初は「ゴースト = 別の行(`LayerSource::Ghost`)」、次に「層の属性 `ghosts: [d, …]`(鎖)」で作ったが、利用者訂正 2 つ:

1. **ゴーストも層も 1 つの行。ゴーストはその名の通り掴めない。** 遅れは Desk で決め、Inspector で数を直す。Timeline の別モードは後で。別の行にすると Repeater の可視化に過ぎない
2. **実物は 1 つ、ゴーストも 1 つ。** 複製が要るなら Delay の効果(Repeater)。本質はリリックモーションの文字が遅れて出てくる事で、鎖ではない

よって層属性は `ghost: Option<遅れ>`(1 枚)。Desk のゴーストモードは意味を失わない(利用者): 鎖は 1 層の中ではなく**選んだ層の並び**。Motion Tools Pro の Sequence / Stagger(複数の層を n フレームずつ順にずらす)と同じ事を、in 点を動かさず各層のゴースト 1 枚の遅れで行う。複数の層を選ぶと Ease レンズがゴーストモードになり、選んだ順に i/N を曲線に通して遅れを配る(最初の層は 0 = ゴースト無し、全体は 6 f × N か既にある最大)。

| 家 | 何を | 正本 |
|---|---|---|
| doc | 層属性 `ghost: Option<i64>`(遅れ、フレーム、1 枚)。評価は `resolved_layers` の `push_ghosts`: 層を `t − d` で解き(親も含めその時刻の world)、同じ id で `ghost = true` にして元より先に積む(奥)。Repeater が掛かっていればその時刻の配置ごと。層の帯の外(`t − d` が始まる前)・hidden では居ない | `store/attrs.rs`、`store.rs` `ResolvedLayer::ghost`、`view/resolve.rs` |
| render / native | 枠・掴み・親の world を引く所は `!ghost` の物だけを見る(4 か所)。`ghost` command(選んだ層のゴーストを On/Off、既定 6 f)、`setAttrs` の `ghost`(正の整数か null)。snapshot に `ghost` | `engine/texture.rs`、`editor/stage.rs`、`snapshot.rs`、`port.rs` |
| Flutter | Timeline: **同じ行**に、遅れの分だけ右へずれた薄い帯(輪郭)1 つ。掴めない。Inspector: 「Ghost」On/Off と遅れの数値欄(`EditorNumericField`)。Desk: 複数の層を選ぶと Ease レンズが **Sequence**(差し色反転、各層を曲線上に打つ、曲線を動かすと各層のゴーストの遅れを `setAttrs` で配る) | `timeline.dart`、`inspector.dart`、`desk.dart`、`ease_desk.dart` |

契約 test: doc(ghost 5 で 8 f 目に 3 f 目の姿が元の奥に、`t − d` が帯の前なら居ない、隠せば消える)、Flutter 31、raw_dimension。

追記(同日): 遅れは負も可(先へずらす、0 は無し)。Sequence は掴んでいる間 `previewSequence` で下書き(Stage がその場で動く)、放した時に `sequence` で 1 手(Undo 1 つ)。

まだ無い物: d にキーを打つ、Timeline の別モード、9/6 の「増やし方は 2 つ」の言い直しの裁定。

## 7 月の文字の構想との接続(2026-09-07 追記)

利用者の動機は文字アニメーション。[リリック比較(2026-07-19)](2026-07-19-lyric-motion-text-sequence-comparison.md)と [text-model](../text-model.md) を読み直すと、ゴーストは新概念ではなく、文字で決めかけていた事の層への一般化になる。

- Text Sequence は `animators[].selector.offset` を文字ごとにずらすだけ(text-model §2)。Timeline は CONTROL / RESULT の二段で、下段の文字ごとの譜面は規則からの投影、drag は疎な差分へ逆変換(§2.6)
- 子行の時間差分 `Start Offset` / `Duration Scale` は親規則の**評価入力(local time)のアフィン変換**で、位置の差分(出力加算)とは非対称(§2.8、§9)
- ゴースト = `Start Offset` を層へ持ち上げた物。3 段が同じ形: 文字(Text Sequence の offset)/ 複製(Repeater の Delay each)/ 層(ゴースト)。前 2 つは「ゴースト N 本を 1 行に畳んだ物」、展開した子行がゴースト
- 「時刻だけ」の裁定で、7 月の非対称が分かれる: 時間の差分(評価入力)= ゴースト、空間の差分(出力加算)= Repeater の Each。7 月に未決だった「timing 差分の scope(animator 1 枚か全 stack か)」は、ゴーストの規則「元を `t − d` で丸ごと評価」に揃えれば全 stack 共通で決まる(要裁定)
- 7 月の「Ghost Pose」(登場前の状態を Stage で掴む)は別の物。利用者裁定(2026-09-07): **「ゴースト」は層の方**。姿の方は「登場前の姿」と呼び替える
- 今日の意味: 文字だけの機構だった「時間のずれ」が、層・複製・文字に共通の 1 つの意味になった
