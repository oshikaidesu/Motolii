# 実機以前のUX決定の一括降格(利用者裁定による撤回)

- 日付: 2026-08-12
- 状態: 決定(利用者裁定)
- 裁定原文: 「台帳決定を覆します、台帳決定はあくまで何も見えていなかった頃の仮の決定なので信頼に値しません」

## 1. 処分

実機で触れる現物(PR #476系列)が存在する現在、**操作・UX系の旧台帳決定を「決定」から「仮説」へ一括降格**する。以後のUX authorityの順位:

1. 利用者の実機裁定
2. [「普通に使える」品質バー](../ui-quality-bar.md)(Q0〜Q9/B1〜B7)
3. [刻み込まれた文法ギャップ地図](../ui-inherited-grammar-gap.md)
4. 旧UX仮説(参考情報。挑戦に根拠を要求しない)

降格は削除ではない(歴史規律)。旧決定は「なぜそう考えたか」の参考として残るが、**品質バー・文法地図と衝突した時点で無条件に負ける**。

## 2. 本裁定で明示的に覆す対象(引用処分)

- **2026-08-08 Timeline設計決定 (4)「object barは読み取り専用。状態変更はInspectorとkeymapが持つ」→ 撤回**。M/S(mute/solo)等の行上直クリックは刻み込まれた反射であり接続対象。実測でD2にlayer mute/soloコマンドが不在のため、実装は文法地図Tier 2(D2粒→UI)の順で行う
- 同決定の他項目((5)キー縦drag値編集を持たない、(3)行高固定 等)は自動では覆らない — 仮説として残り、品質バー/文法地図/実機裁定との衝突が実測された時に個別に落ちる

## 3. 適用範囲の線引き(supervisor記載)

本裁定の対象は**操作・UX・見た目の判断**である。絶対規律1〜7(VRAM常駐・色変換一元化・single writer・Preview/Export同一評価 等)とD2/Document/journal/wireの工学契約は「見えていなかった頃のUX仮説」ではないため対象外とした。この線引き自体も利用者が広げられる。

## 4. 帰結

- 文法地図のTier 3(台帳交差)は消滅し、M/S直クリックはTier 2へ移動
- 以後のUX発注で旧台帳row との衝突を`AUTHORITY_CONFLICT`として止める必要はない(operation/UX系に限る)。品質バーQ/Bを引用していれば進んでよい
