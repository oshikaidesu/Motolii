# GSAP の動きの法 — ease・stagger・位置の文法・repeat(2026-09-17)

利用者の裁定「GSAP の動きができるまで自走してくれ、次の参考先は GSAP」。芯は [Web の欄 a](2026-09-17-web-fields-a.md) と同じ: **ソフトが持つのは意味でなく道具、名前と既定は GSAP の語、値は時刻の純関数、式はそのまま写す、離散の切替の後に連続の収まりが置ける、発明しない — GSAP が開けている所は開けたまま列挙する**。定規は GSAP の source(MIT、`src/gsap-core.js` と `src/EasePack.js`)と取説(Eases / Staggers / Position Parameter)。参照値は本物の GSAP を node で走らせて取った(`gsap.parseEase(name)(t)`、`gsap.utils.distribute(vars)`)。

## 1. Ease 棚 — GSAP の ease を鍵の型に

- **意図**: Web の写しで GSAP の ease(`power2` / `expo` / `sine.inOut` / `elastic.out(0.3)`)を Bezier で近似していた(c2・c3・c4・c7・c8・c10)。式がある物を近似しない。
- **札**: 鍵の ease に GSAP の文字列をそのまま — `"power1".."power4"` / `"expo"` / `"circ"` / `"sine"` / `"back(overshoot = 1.70158)"` / `"elastic(amplitude = 1, period = 0.3、inOut は 0.45)"` / `"bounce"` に `.in / .out / .inOut`(向きが無ければ GSAP と同じく `.out`)、`"steps(n, immediateStart = false)"`、`"slow(linearRatio = 0.7, power = 0.7, yoyoMode = false)"`、`"none"`。別名(`linear` / `quad` / `cubic` / `quart` / `quint` / `strong` / `power0`、`Power2.easeOut` の大文字形)も `_easeMap` の通り。窓の型(Hold / Linear / Bezier / Bounce / Elastic / Cyclic / Random / Steps / ElasticSteps)はそのまま。
- **先例(GSAP source の行)**: `gsap-core.js` 1016 `_configEaseFromString`(`family.dir(args)` の読み)、1022 `_parseEase`、1023 `_insertEase`(in から out = `1 − in(1 − p)`、inOut = `p < .5 ? in(2p)/2 : 1 − in(2(1 − p))/2`)、1035 `_easeInOutFromOut`、1036 `_configElastic`、1046 `_configBack`、1066 Power 1..5、1071 Elastic、1072–1077 Bounce(7.5625, 2.75)、1079 Expo(`2^(10(p−1))·p + p⁶(1−p)` — 端で 1 に着くための混ぜ)、1080 Circ、1081 Sine、1083 `SteppedEase.config`。`EasePack.js` 39 `_createSlowMo`。
- **借りた物**: 鍵の型 `Interp` の枠(`ease(u)` の純関数、validate、窓の shape JSON の `kind`)。**足した物**: `eval/gsap.rs`(`GsapEase { family, dir, p1, p2, p3 }`、`parse` = `_parseEase` の文法、`Display` は読み直せる文字列)、`Interp::Gsap`、`ease_kinds::decode` が窓の型に無い名前を GSAP として読む、prelude は文字列をそのまま渡す。
- **絵**: 台本 12 本(c2・c3・c4・c7・c8・c10 と `_x`)の Bezier 定数を GSAP の文字列へ(`{ kind: "Bezier", x1: 0.19, … }` → `"expo"`)。evidence は §5 と同じ道で焼き直す。
- **test**: `every_gsap_ease_matches_gsap_at_five_points`(40 本 × t = 0, .25, .5, .75, 1、本物の GSAP の値と 1e−9 で一致)、`the_string_grammar_is_gsaps`(向き無し = `.out`、別名、表示の往復、知らない名は断る)、script `gsap_ease_strings_become_gsap_keys`(鍵に載る、`power2.out` の 0.5 = 0.875、知らない名は窓の型と GSAP の両方を並べて断る)。
- **GSAP が開けている所(決めていない)**: (1) `CustomEase`(SVG path の ease)・`rough` / `expoScale`(EasePack)は無し。(2) `_parseEase` は知らない名前を黙って既定(`power1.out`)にするが、ここは断る(Motolii の作法)。(3) `elastic` の amplitude ≤ 0・period ≤ 0・`steps(0)` は GSAP では NaN / 無限 — ここは validate で断る。(4) 窓の Ease Desk に GSAP の型の handle は無い(文字列のまま、曲線は samples で見える)。(5) Lottie の書き出しは GSAP の型を Bezier に落とさない(他の型と同じく断る)。
