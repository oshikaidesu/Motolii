### 詰まった所(台本の書き方で避けた。Rust は触っていない)

1. **鍵の後に `set` すると曲線ごとずれる**(AE と同じ)。`group()` の後に `set("Position",[0,0])` する例の作法は、鍵より前に置く。#1 の最初の絵が全部箱の上に逃げたのはこれ
2. **Position Type: Absolute + Horizontal/Vertical Constraint の子は、箱の Width/Height に鍵があると鍵の途中で描かれない**(静止では正しい。`constraints_card.js` は Width の鍵で動くが、あちらは子が Fixed でない)。#2・#3・#5 は Relative の子 + 箱の Position と子の Position の同じ鍵で「遠い辺を留める」形にした
3. **同じ場所に重ねた箱の一方に Width の鍵があると、鍵の途中だけ下に沈む**(投影が既定のまま。全層を `projection("2D")` にすると順が保たれる。`stagger_reflow.js` が全層 2D にしている理由と同じ)。加えて **同寸で完全に重なる 2 枚の media は鍵の途中の絵が出ない**(1% ずつ Scale をずらすと出る。可視層のみ復号の篩が静止の枠で見ている疑い)— #3 はこの 2 つで「次を開く」形へ
4. 絶対配置の Position は子の**中心**(文字も画も)。`[0,0]` に置くと左上 1/4 だけ見える
5. **`watch_shot` の `MOTOLII_SCRIPT` は絶対 path で**。cargo test の cwd は crate なので相対 path だと stamp が取れず、書類が永遠に出ない(束 1 の `shot.sh` を直した)
6. **動画 clip の 0 コマ目は黒**(1 コマ目から出る。束 1 の #3x も同じ)。評価の絵は 1 コマ目以降で見る
7. **group の Rotation は左上が軸**。`Transform Origin: Center` にすると軸が中心になり、同時に **Position が中心の座標に変わる**(#10)。null と group に `Anchor` は無い
8. **重なりは group() の引数順でなく層を作った順**(後に作った層が上)。#10 の環の穴が物を隠したのはこれ — 下に置く物を先に作る
9. **物理の部屋では Absolute の子が全部 物になる**(Hardness を付けなくても)。環の線を部屋に入れると穴の楕円が落ちる — 飾りは部屋の外へ(#10x)
