## 2. 転写束の裁定(逸脱8件の処置 — 全て裁定165/167/168 の適用)

- **rail スウォッチ**: 寸=0.308×行高(8/26)・角丸=0.25×スウォッチ寸・**色は layer の label_color**(ρ で Document に差し色が入った — 「色ラベルが無いので発明しない」の旧注記は失効。スウォッチ=bar 色のプレビュー、mock と同義に復帰)

- **bar**: 縦 inset=0.154×行高(梯子中段 — 現行 0.10 の中間値は裁定167 違反)・角丸=0.111×bar高(2/18)

- 検収は比率の純関数テスト+PNG fence の理由つき追随(ε 前例)。実窓合否は利用者

## 3. Inspector 比率化(φ FINDING 0.55 の扱い)

文字寸比 0.42±0.05 帯(裁定168)は **Timeline 実測由来**。Inspector の 0.55 が違反かどうかは **Inspector mock の実測が先**(裁定: 帯はグローバル定数ではなく **pane ごとにモック実測から導出** — 比率の原則の pane 相対化)。Inspector 比率化レーンが mock(docs/mocks-ui/public/inspector-library.*)から行高:帯高:値セル幅:文字寸比の台帳を起こし、実装との差分を機械照合 → 0.55 がモック内なら合法・外なら転写対象。裁定168 の 0.42 は「Timeline の値」へ注記を修正する
