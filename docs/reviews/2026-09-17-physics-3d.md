# 物理の解き手を 3D に — rapier2d → rapier3d(面の上に錠)

2026-09-17。利用者裁定「3D にしておきます」(z = 0 の概念 = 解き手は 3D)。前提は [物理の法](2026-09-16-physics-law.md)と [箱の奥行きの法](2026-09-14-depth-law.md)。

## なぜ

箱は奥行きを持つ(奥行きの法 1)。2D の解き手では箱の Depth・押し出し・網が物になれない。今は面の上だけを解くが、世界を 3D にしておけば、Depth が付いた時に錠を外すだけで済む(解き手を差し替えない)。

## 何をしたか(`engine/physics.rs`)

| 所 | 2D(昨日まで) | 3D(今日) |
|---|---|---|
| 物 | `RigidBodyBuilder::dynamic()` | 同じ + `enabled_translations(true, true, false)` + `enabled_rotations(false, false, true)`(取説 rapier 0.32 rigid_bodies「2D game in 3D: lock Z movement」) |
| 当たり(輪郭) | 輪郭の凸分解(parry2d の VHACD)→ 凸多角形の複合 | **同じ凸分解を 2D で**(parry2d を直に依存に残す)、塊ごとに z = ±SLAB/2 の点で 3D の凸包 → 複合。3D の VHACD は閉じた三角網が要るが、面の物の当たりは輪郭が全てなので面で分けて足りる |
| 当たり(箱・丸) | cuboid(hx, hy) / ball(r) | cuboid(hx, hy, SLAB/2) / ball(r) |
| 壁 | 床・左・右(蓋は無し、法 3) | 床・左・右は同じ(z に長い) + **前後の 2 面**(箱の 6 面のうち蓋以外の 5 面)。前後は z の錠で今は届かないので、soft-CCD の予測距離の外に置く(接して置くと擦れて面の上の動きが止まる — 最初の走りで踏んだ) |
| 丸い箱 | 厚い円弧 48 枚 | 同じ(z に長い) |
| 場 | Vec2 の力 | z = 0 の Vec3。場は面の上の矢のまま |
| 回り | `rotation().angle()` | 四元数から z の角だけ(x/y は錠) |
| 板の厚み | — | `SLAB = 1 m`。全員同じなので質量・慣性の比は 2D と同じ(1 m なら質量の数も同じ) |

**Depth が外す錠**: 箱の Depth(奥行きの法 1)が物理に届いた時、(1) `enabled_translations` の z、`enabled_rotations` の x/y を外す、(2) `SLAB` を層の Depth にする、(3) 前後の面を箱の奥行きの位置に置く(`faces` の `clearance` を 0 に)、(4) 場に z を許す。まだ欄に結んでいない(code の comment に同じ 4 点)。

## 絵は同じか

- 単純な積み(settle の test の画、12 個の四角): 落ちる列は小数 1 桁まで同じ(7.6 / 28.6 / 60.7)、静止の列も同じ(92.0 / 106.1)、静止後の最大の動き 2D 0.044 px/コマ → 3D 0.046
- `web_s10` / `web_c10`(committed の証拠と比べる): c10 は落ちている 36〜66 コマだけ 5〜6% の画素が違い、前後は 0%。s10 は 1.4%
- **山になる画(gumball / tower / hero / pile)は同じ種類の絵だが並びが違う**(sheet で 9〜25% の画素)。原因は混沌で、系統の差ではない: pile は 0 コマ目に接触 13、gumball は 27(見本は物を重ねて置き、解き手が最初の歩から押し分ける)。2D と 3D では接触点の取り方(多角形の辺 vs 立体の面、点の数)が違うので、最初の歩から差が出て増幅する。`docs/reviews/evidence/2026-09-17-physics-3d/`(`*-2d.png` / `*-3d.png`)

結論: 面の物理としての法(落ちる・積もる・眠る・壁)は同じ。画素一致は接触の無い区間だけで、混沌の画は「同じ画の別の振り」。

3D は 2〜3 倍。見つけた別の穴: gumball は**毎コマ世界を組み直している**(`physics build` が 210 回、2D も同じ)— 顔ぶれの印(signature)が毎コマ変わる。1 コマ 0.75 → 累積で 27 s / 210 コマ。未着手。
