# 物を避けて流れる文字 — CSS `shape-outside` を動画の骨格へ(提案)

2026-09-15 夜間の提案(朝に取り消せる)。台帳 [CSS の恩恵](2026-09-14-css-ledger.md) の D「`shape-outside`」、ドッグフーディングの場面 3(文字が映像の中の物を避けて流れ直す)。判定の物差しは [間合いの法](2026-09-14-margin-law.md) の連続性(利用者「動きにガクつきはないか、充分に補完されているか」)。

## 先例

| 先例 | 形 | 読み |
|---|---|---|
| CSS `shape-outside`・`shape-margin` | 形を宣言するのは避けられる物(float)の側。値は `margin-box` / 形 / 画像のアルファ。同じ block の行の箱が、行ごとにその形の分だけ短くなる | 物が自分の形と間を宣言する(間合いの法 1 と同じ向き) |
| CSS Exclusions `wrap-flow: both` | 物の両側に行が流れる | float は片側だけ。動画では物が段の中ほどに来るので両側 |
| InDesign のテキストの回り込み | 「オブジェクトのシェイプで回り込む」、左右両側が既定 | 組版の普通 |

## 法(案)

1. **形は避けられる物が宣言する**。`Shape Outside`(None / Margin Box / Content)と `Shape Margin`(CSS の語)。すべての物(間合いの欄と同じ段)
   - Margin Box = 層の箱 + Margin
   - Content = 形の層は輪郭(曲線を刻む、並べた伸び込み)、Blob Track を持つ層は塊の箱、他は層の箱
2. **避けるのは同じ親の、折り返す文字**(段落の枠か、Fill で並べた文字)。折り返さない文字は物を見ない(CSS でも行の幅の無い物は回り込まない)
3. **行ごとに、帯にかかる物の横の範囲を抜いた区間を左から埋める**(`wrap-flow: both`)。1 つの物は 1 行に 1 区間(凹みは埋める、CSS の float の行と同じ)。語が入らない区間は飛ばし、どこにも入らない行は下へ
4. **縦の寄せは避けない組みで決める**。避けて行が増えたら下へ伸びる(CSS の block)。避けた組みで寄せ直すと帯が動き、2 つの組みの間を往復した(夜間の実験)
5. **移り方**: 文字の `Transition` は字を元の文字の byte で対にして、前の場所から滑らせる(組んだ順で対にすると、行頭の空白が落ちた時に隣の字と取り違えた)。物の `Transition` は少し前の時刻の形も重みつきで渡し、覆う重みが半分に届く所を塞ぐ(映像の塊の揺らぎで語が毎コマ跳ばない)
6. 解析の入力(Blob の塊)は、移り方が重なって遡るコマ数(長い順に 2 つの和)だけ前まで host が置く

## 測った(連続性の物差し、空白の字は数えない)

| 見本 | 跳び / 尖り |
|---|---|
| `flow_around.js`(丸が進んで止まる、星がゆっくり回る) | 0 / 47(語が行を渡る動き出し、14 px/コマ² まで) |
| 渋谷の俯瞰、バスと木を Color で拾って避ける(スクラッチ `flow_objects2.js`、文字 0.8 s・物 1.0 s) | 0 / 0 |
| 同、文字の移り方なし | 5065 / 6560 |
| 同、群れ(Motion の塊)を避ける | 塊が毎コマ入れ替わり、過半の塞ぎでは隙間が残らない。群れは避ける相手に向かない |

見え方: 物が止まっている間は組版として読める(「THEY PART WHERE A / SHAPE STANDS AND / CLOSE AGAIN WHEN ● IT」)。物が速く動く間は、語が次々に行を渡り、途中の字が重なる波になる。面白いかは利用者の判定。

## 残り

- 画・動画のアルファを形にする(CSS `shape-outside: url()`、`shape-image-threshold`)
- 並べる法の測り(Fill の文字の高さ)は物を見ない(巡るので)。避けて伸びた分は箱の外へはみ出す
- 縦書き・`text-wrap: balance` と組み合わせた時
