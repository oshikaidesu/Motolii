# Stencil と Silhouette — クリッピングマスクの逆

2026-09-15 利用者裁定。きっかけは花の PV のクローンで、部分の窓(同じ絵の色替えの写しを矩形で切る)が作れず、画面全体の写しを透明の矩形で包んで箱で切る回り道になったこと。利用者「ブレンドモードにマスクの切り抜きがないのが問題。クリッピングマスクの逆」「全部切るのは使い勝手が悪い」→ 案に「ok それでいこう」。

## 先例

| 先例 | 形 | 切る範囲 |
|---|---|---|
| AE の Stencil Alpha / Silhouette Alpha | この層の形が下を残す / 穴を開ける | コンポ(プリコンプ)の下の全部 |
| Figma の Use as mask | マスクが同じグループの上の層を切る | グループの中 |
| Photoshop のクリッピンググループ | 土台 + 上にクリップした層で 1 つの束 | 束 |
| Photoshop のノックアウト(浅い / 深い) | 下を抜く深さ | グループの底 / 背景 |

## 法

1. ブレンドモードに **Stencil Alpha**(形の中だけ下を残す)と **Silhouette Alpha**(形で穴を開ける)。自分は描かない
2. **範囲は既存の構造で決まる**。clip していれば **自分のクリップの束**(土台と、土台の形で切られる束の層)。clip していなければ **同じ Group の中で自分より下**(浅いノックアウト)。コンポ全体を切るのはルートに置いた時だけ
3. 板にならない Group は描かないので、その子孫を切る。板の Group は板ごと切る
4. 1 つの層に matte は 1 つ: 既に track matte を持つ層は切らない。Stencil が重なる層は一番近い物
5. 描き方は既存の matte(相手の層の最終の絵のアルファ)。形・文字の輪郭のままの層は切る前に 1 枚の絵に焼く

| clip | ブレンド | 切るもの |
|---|---|---|
| あり | 普通 | 自分が土台の形で切られる(今のクリッピングマスク) |
| あり | Stencil | 束だけを自分の形で残す(窓) |
| あり | Silhouette | 束だけに穴 |
| なし | Stencil / Silhouette | 同じ Group の下の全部 |

## 残り

- 束の中で Stencil より上にクリップした層も、土台と一緒に切られる(土台を切るので)
- **Stencil Luma / Silhouette Luma は作らない**(2026-09-15 利用者裁定「クロマキーエフェクトの役だよね」)。明るさ・色から透明を作るのは効果(キーイング)、ブレンドモードはできたアルファを使うだけ。白黒の素材はキーイング効果 + Stencil Alpha で同じになる(AE の Stencil Luma は 2 つを 1 回で済ませる近道で、同じ意味を 2 か所に持つ)
- キーイング効果を後で足す: **Extract**(明るさで抜く、AE)と **Color Key**(色で抜く、AE)から。今あるのは Set Matte の Luminance と Track Overlay の Key Color(塊を拾う用)だけ
- Lottie への書き出し(track matte の構造へ直す)
