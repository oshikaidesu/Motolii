# 演出と実装を一緒に設計する — 複数社の画作りから取り入れること

後続の代表作品: [夜間のプリズム・煙・水面・薄膜・異方性と外部資料](2026-09-09-expression-dogfood-night-plan.md)。個別の方式は比較後に採否を決める。

状態: **決定**（2026-09-09 利用者「得れるものはガンガン取り入れましょう」）。採用するのは、見せたい演出に合わせて計算・近似・制作道具を選ぶ開発方針。個々の未実装機構は下表の比較対象であり、実装済み・性能検証済みという意味ではない。

## 採用する判断

作品でどう見えるか、作者がどう調整できるか、実行時に何を省けるかを同時に考える。正確な物理を唯一の基準にせず、意図した印象と動きが保たれる近似を使う。その方法・出典・適用前後・費用・破綻条件を、第三者が追える形に残す。

## 次に実行する比較

反射の検討は[ラスタライズ反射調査](2026-09-09-glass-raster-research.md)に集約する。最初に、同一平面の複製群、奥行きの異なる平行面、任意向きの曲面群を分けて比較する。複製ごとの撮影を既定にせず、撮影・反射画像・画面処理の予算をそれぞれ測る。

各比較は「元の作品 → 共通の意味/パラメータ → 省略した仕事 → 出力 → 破綻条件」の順で記録する。低負荷であることだけでも、静止画が綺麗なことだけでも採用を決めない。正順再生・逆シーク・任意frame直行・exportで、同じDocument/時刻/camera/品質の絵が揃うことを確認する。

[共通表面の検収](2026-09-09-shared-surface-plan.md)に残る実窓の読込停止は未解決のまま明示する。新しい方式の検収に成功したことと混ぜない。

## 技術を他の作者へ渡す形

成果には、短い実行例、適用前後の画像、調整できる値、出典、測定条件と限界を添える。作者向けのパラメータは既存manifest/Document/Inspectorの経路へ載せ、値を触って結果を比較できるようにする。解説の目的は、他の作者が同じ入口から自分の表現へ作り替えられること。

この変更は採用方針と比較項目の文書化。runtime・UIの実装変更や外部への公開は含まない。

## Motoliiが自動化する対象（利用者訂正を反映）

2026-09-09 利用者: 「意図の自動補正はまだいいや、モーショングラフィックスはカメラの動き自体がユーザの意図となるため」。**意図の自動補正は延期**。現在取り込むのは、作者が定めた作品を描くための内部処理と、作者が明示的に使う表現部品。

カメラの軌道・画角・構図、オブジェクトの配置・形状・色・不透明度・動きは編集の正本として保持する。顔の角度別変形、前髪の自動透過、主役を目立たせるための自動再配置・再照明などは現行の実装対象に含めない。複数社の上記例は先例の記録として残す。

| 取り込む対象 | 機械が担当すること | 保つこと・比較条件 |
|---|---|---|
| Repeaterの描画集約 | 共通geometry/program、instance値、共有画像を再利用する。不要な描画提出と背景copyを減らす | 効果順、blend、clip、個別param、透過の前後依存。単純に全複製を一括にしない |
| 反射の近似と予算配分 | 共通SurfaceProgramへ、共有probe・平面/画面方式等から必要な反射情報を渡す。解像度・撮影対象・cacheを管理 | カメラを変えて反射を見せるのではなく、指定されたカメラの下で評価する。画面外物体、自己像、移動時の切替、透明面の重なりを比較 |
| 高価な処理の再利用 | 再利用できる生成結果やアニメーションをcache/事前計算し、作品時刻から読む | 元の編集dataを保持。関連変更で失効し、逆シーク・任意frame・exportで結果を揃える |
| 軽い表現部品 | 作者が選んだ煙・雲・投影・発光等を、Vismとしてshader/画像/particle等で表現する | 任意の3D素材を勝手に板へ変換しない。部品の定義に従ってカメラ移動・交差・輪郭の限界を検収する |

カメラ情報は描画資源の配分や可視性を計算するために読む。作者のカメラ自体は補正しない。画面占有率や距離で品質を変える時も、ポッピング、揺れ、過去frameの残像が出ないことを検証する。近似は完全なpixel一致を保証するものではないので、設定値を変えずに得られる見た目と費用を同じ作品で比較する。

実装の入口は揃っている。共通SurfaceProgramの上で、まずRepeaterによるrun分割/背景copyの増加と、反射の共有単位を一緒に扱う。その後に共有反射情報の生成・失効・品質配分を接続する。これは今後の施工範囲であり、反射の自動選択や描画集約が完成済みという意味ではない。
