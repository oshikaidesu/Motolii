1. shortcut(現行v18〜20のキー割当プロース表)は未列挙。理由: Blackmagic公式リファレンスマニュアルはv11の単独PDF「DaVinci Resolve 11 Menus & Keyboard Shortcuts」を最後に、それ以降のバージョンでは完全なキー割当てを本文形式で再発行していない(v18.5 Reference Manual Chapter 4「System and User Preferences」はKeyboard Customizationウィンドウの操作説明のみで、実際のデフォルトキー一覧はアプリ内UIでのみ閲覧可能)。Blackmagicフォーラムスレッド(forum.blackmagicdesign.com)でも同事実が確認され、代替としてユーザー投稿の非公式スプレッドシート(v17/v19)が出回っているのみ。よって本ファイルのshortcut行はv11時点の公式キー割当てを収録し、現行メニュー構造(Trim/Timeline/Clip等の分離)とは項目名が一部一致しない版差がある。
2. shortcut種別のカテゴリ分類はv11文書の9分類(DaVinci Resolve, File, Edit, View, Mark, Playback, Color, Nodes, Help)を採用。現行v18.5マニュアルのCommand階層スクリーンショット(Application > File/Edit/Trim/Timeline/Clip/Mark/View/Playback/Fusion/Color/Fairlight)は確認できたが、Trim/Timeline/Clip/Fusion/Fairlight/Workspaceの現行カテゴリに対応する具体的キー割当ては公式本文に存在しないため未列挙。
3. Panel-specific(パネル別)ショートカットカテゴリ(例: Media Pool, Edit Timeline, Metadata Editor, Sound Library等)の完全な一覧は、v18.5マニュアル本文で「一例」としてのみ言及され(網羅的リストではない)、確証が取れる範囲でのみ言及に留め、種別=shortcutの行としては列挙していない。
4. panel種別は指示通りEdit pageのみ完全列挙し、他6ページ(Media/Cut/Fusion/Color/Fairlight/Deliver)は「ページ名+役割1行」に留めた(各ページのサブパネル内訳は意図的に非列挙)。
5. pref種別のうちUser > Keyboard Customizationは項目というより機能への入口(サブウィンドウ)であるため1行のみの概要記載とした(内部のコマンド一覧はshortcut側の制約と同じ理由で本文非公開)。
