## 決めた事(裁定)

- GUI を MV より先に。「楽しい」= 見せたまま応えを速く(Ableton のガジェット、Figma の手が絵に付く)。数値を消す・隠す・幼くする・キャラは無し。
- viewport は動画プレイヤーの口で運ばない。Dart FFI で同じコマ。
- Lumit は GPLv3: 値と型だけ写す(code は写さない)。license の話は別の日に。
- 関係の口は関係の語で(anchor / parent)。時間の語(now_of)は使わない。
- 籠と取っ手は意図で。カメラの gizmo は選択中だけ。
- Layout = Inspector の 6 + 2 行、pad、desk なし。
- 今週末は課程(MV は目標だが GUI が先)。

- Layout の親の行は群だけ。**文字が物になる時(Split)は文字の層を群の層に変換する。例外は作らない**(2026-09-19 午後)。Split の口はこの規則で設計する: 文字 → 群 + 字の子、layout は群の規則そのまま。

- **リリックモーションの汎用化**(2026-09-19 午後): 群の子が時刻表に従って出て・居て・消える。子が字でも tile でも同じ札が効く(利用者「その通り」)。時刻表 = 子の層の in / out(timeline)、単位 = 群の子(Split は文字 → 群)、法 = 札。足す口は 1 つ: 札が自分の出番の時刻を読む(`Item` に born / life、prelude に `age(k)`。名前は借りる: CSS animation-delay / AE の in-point の語から決める)。

- **Layout は意図で、言葉を出さない**(2026-09-19 午後): 並べ方は格子だけ(columns × rows の 2 つの数。横一列 = rows 1)。Flex の direction は UI から消す。見えるのは数と pad と glyph だけ、CSS の語は裏(台本・書類の行・tooltip)に残す = LLM の語彙。前提の直し: Stage の籠が群そのものを掴まない(hit test は群を飛ばして子)。

## anchor / parent の口(lane の報告の要約)

- `fn parent(k) -> Offset` / `fn anchor(k) -> Offset`: 親 / Position Anchor の相手の、同じコマの前段までの Offset。無ければ NO_OFFSET。`effectors` module に `anchor_centre(k)` / `parent_centre(k)`(相手の休止の箱の中心 + translate)。
- 規則: 同じ段の中では参照される側が先に走る(`reference_depth`)。同じ batch(同じ札・同じ欄)の相手は前段の値。場の部屋の中の親は物にしない(Rapier の体になるため)。名指しだけで物になった物は最後の番号を取る(既存の絵の k を動かさない)。
- 決定行の案: `2026-09-19 | 関係の口は関係の語で: anchor(k) / parent(k)。時間の語は使わない | block_program.rs PRELUDE`
