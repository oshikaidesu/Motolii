## 要約 5 行

1. kkmfd(@kk_mfd)は中国出身・2005 年生まれ(2025-06-23「20歳の誕生日」)の文字 PV / モーショングラフィックス作家。2021-10 の「文字pv试!!!!!/1h作 #モーショングラフィックス」が最古の投稿、YouTube は 2022-07-21 開設、自己紹介は "Making video is my hobby" の 1 行だけ。
2. 道具は本人の明記が **After Effects + Mine-imator**(『Disengaging』『24:00』の "Software : Mine-imator / AfterEffects")。ミニ偏の「真のプロジェクトファイル」は紙の封筒に手書きで「ミニ偏 .Aep」。Cavalry / Blender / TouchDesigner / C4D の言及は **ゼロ**。
3. 字体は自作もする(2024-10 "Font for Astronomy"、円と斜線の幾何コンストラクション、大文字のみ)。ロゴ設計も請ける(「ロゴをデザインしました！」「設計しました——」)。
4. 手法の芯は「文字 PV」+「手描き素材の物理」。ミニ偏(18 万回)は紙に描いて切って撮った素材、『ふたつめの心臓』は「大量の手描き素材とニュートン効果」(AE の Newton プラグイン)。EXC3_CM3(93 万回)は Windows XP 壁紙・青/白・分割スリット・円の目盛りの「情報量」型。
5. 他者の語り: Sanrio V-Fes 2025 公式は「映像作家のkkmfdがゲストVJ」/ "motion graphic artist kkmfd as a special guest VJ"、scrapbox の個人メモは「モーショングラフィックス」「すごすぎる」。「過剰」「情報量」「kinetic」「glitch」「高速カット」を kkmfd 自身や第三者が使った文は **見つからず**(自作曲名に「グリッチホップ」があるだけ)。
