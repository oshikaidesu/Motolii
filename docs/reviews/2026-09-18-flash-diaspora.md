# Flash の散り先 — 作り手を人の単位で辿る(2026-09-18 取得)

課題: Flash が死んだ後(節目: 2010-04 Jobs「Thoughts on Flash」、2011-11 mobile Flash Player 終了、2015-12 Flash Professional → Animate、2017-07 EOL 発表、2020-12 終了)、Flash の開発者・作家・思想(タイムライン + 毎コマの台本 + ベクター + 開いた形式 + 段差の無さ)がどこへ散ったか。一次資料(本人ブログ・GitHub・インタビュー原文・公式・講演)だけを当日取得。Wikipedia は入口に使い引用はしない。取れなかった物・二次資料しか無い物は「未検証」「見つからず」と書いた。判断と Motolii への含意は書かない。

確度: 高 = 本人/公式の原文を当日読めた。中 = 本人発言だが二次経由(検索結果の要約・fetch 403 で原文未読)。低 = 出自の記述のみで本人の言葉が無い。取得不能だった host: Medium の大半、X/Twitter、web.archive.org、apple.com、helpx.adobe.com、newgrounds.com/bbs、arstechnica、moock.org。

## 0. 要約(5 行)

1. **ライブラリへ**: API の形を Flash から写した事を本人が明記しているのは Pixi("similar to the flash display list ie. Sprites / Movieclips" 2013)、Phaser("based heavily on Flixel"、Flixel5 と呼ぼうとして断られた)、CreateJS("an API that is familiar to Flash developers")、OpenFL("reimplementation of the Flash API")。mr.doob は "since my ActionScript days"、Doyle は "a huge shift to go from ActionScript to JavaScript"、Cannasse は MTASC を "the grandfather of Haxe"。
2. **道具へ**: Rive の Guido Rosso が最も直接に後継を自称(2025-11 "Flash was great because it unified design, motion, and code. Rive brings that back"、2026-02 "The authoring tool and the runtime were the same thing")。Wick は "there's still nothing quite like Flash with its hybrid way of combining an animation system with a programming environment"(2017)。Spine・Lottie・Hype は Flash 出身ではない。Adobe Animate は 2026-03 販売終了・保守モード。
3. **創作コーディングへ**: 行き先は Processing(Davis・Tarbell・Hodgin)、C++(Lieberman・Hodgin・真鍋)、JS/Go(Peters)、WebGL(Ulloa)、媒体を離れる(中村「ウェブじゃない媒体でいいか」)。Lieberman は Flash 世代を "pioneers"(Davis・中村・Tarbell・Natzke・Pitaru)と名指し。2021 の再興に Flash 世代は居る(Hodgin は fxhash、Tarbell は Verse)、Hobbs は非 Flash 出身。
4. **映像へ**: Newgrounds 作家は Flash を捨てず道具だけ替えた(Adam Phillips・Harry Partridge → Toon Boom、Alan Becker は Animate 継続)。Homestar Runner は 2020-12-31 に全体を Ruffle へ。日本は FROGMAN(CATMAN を見て「ひとりで作れる」)が TV へ、2020-12 のクラフトボス CM がポエ山・青池良輔・カナヘイ・キングを並べた。
5. **思想の言葉**: (a) 1 か所 = Davidson "a single interface to lay out text, shapes, images, and buttons, and animate everything together"、Lieberman "write a line of code and make something move"。(b) 開いて学ぶ = decompile より「source を配る文化」(praystation・bit-101・Davidson "find other cool stuff to copy")。(c) 作る所 = 見る所 = Skinner "write once, deploy anywhere"、Ford "to a world audience"、Newgrounds の "fair chance"。(e) 段差 = 中村「これなら俺でも書けるな」、Ford "without any code at all"、Skinner "low barrier to entry"。(d) 軽さは Davidson の dial-up の 1 文のみで薄い。
