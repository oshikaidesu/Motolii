# 配置効果 — 素材を置く効果(Repeat・粒子)

利用者裁定(2026-09-06): 複製・リピーター・粒子を、効果の棚に居る 1 つの種別**配置効果**として持つ。入口は他の効果と同じ棚、意味は「素材を受けて配置の集合を返す」。2026-08-31 の「複製は駆動の一種」を改める。番号と年齢は帯として駆動へ渡す。

## 編集の意味

- 配置効果は素材(層の中身。上に積んだ効果まで掛けた 1 枚)を受け、**配置の集合**を返す。配置 1 つ = 番号 `i`、変換、時刻のずれ、生まれた時刻、消える時刻。絵は返さない。
- 配置は `(t, params, seed)` の**純関数**。前フレーム・再生順・壁時計を使わない。スクラブしても同じ。
- **既定は通り抜け**。配置は個別に空間へ置かれ、他の層との前後・奥行きを配置ごとに保つ。配置効果より**下**に効果・マスク・混ぜ方・フリーズを積んだ時だけ全体が 1 枚になる([まとめる](../wiki/nest.md)のグループと同じ規則)。
- 配置効果より**上**の効果は素材に 1 回、**下**の効果は増えた後の全体に掛かる(Illustrator Appearance と同じ)。配置効果を積むと配置は掛け算になる(格子 = 線 × 線)。
- 配置は Document の行ではない。Timeline は 1 行のまま、効果の行が「繋がっている印」。1 個だけ別にしたい時は**展開**で N 層に切る(フリーズ/解くと同じ族。切った後は ⌘D と同じく独立)。
- ⌘D は従来どおり 1 つ複製して切れる。増やし方は 2 つのまま。

## 形(Repeater 1 枚の中のトグル。2026-09-06 裁定: 種類ごとに効果を分けない)

使う人が決める順は、いくつ → どんな形 → 1 つずつどう変えるか → どう散らすか → いつ出すか。
Repeater の欄はこの順に並ぶ。**形はトグル**で、選んだ形の欄だけが出る。粒子だけ個数が時刻で変わるので別カード。

| トグル | 形の欄 |
|---|---|
| Line | 間隔(x, y) |
| Circle | 半径、開始角、広がり(360 で一周) |
| Grid | 列数、間隔(x, y) |
| Path | どのパス、始点・終点の割合 |
| Scatter | 範囲(矩形・円・層のパス) |

形の下は全形で同じ「1 つずつの変化」の**格子**(2026-09-07): 行 = Position X / Position Y / Rotation / Scale / Opacity / Delay / Seed、列 = **Each**(番号順のずれ)と **Random**(種による散らし)。一列に並べるのは Position の Each そのもので、Circle と Grid はそれに形を重ねる。単位は欄の脇(px, °, %, s)。格子の並びは契約(`PlacementKind::grid`・`shape`)が持ち、Inspector はそれを描くだけ。触っても一見変化が無い Delay と Seed は `advanced` で、`Advanced ▸` に畳む(既定値でなければ点)。

旧: 種類ごとの 5 効果案

| 種類 | 配置 | 個数 |
|---|---|---|
| 線 | 1 個あたりのずれ × 番号 | 固定 |
| 円 | 角度 2πi/N と半径 | 固定 |
| パス上 | パスを N 等分した点 | 固定 |
| 散らし | 領域の中にランダム(矩形・円・任意パスの内側) | 固定 |
| 粒子 | 発生率・寿命・初速・重力の閉形式、種でばらつく | 時刻で変わる |

組み合わせ: 格子 = 線 × 線、蜂の巣 = 格子 + 1 行おきのずれ、螺旋 = 円 + 番号を半径へ、形を埋める = 散らしの領域にパス、頂点に置く = パス上。旧 VSM-A3 Radial Repeater(LayerSource)は円に吸収し、LayerSource としては復活させない。

## グループに掛ける — 子が素材の袋(裁定 2026-09-07)

- グループに Repeater を掛けると、**直下の子が素材の候補**になる。配置ごとに子を 1 つ引き、その子の部分木をグループの親空間で置く。子は単独では描かれず、配置を通してだけ出る。
- **Materials**: 子の名前ごとに **Share**(重み、既定 100)。脇に正規化した % を出す。param は `share.<layer id>`。
- **Copies**: One child(配置ごとに子を 1 つ引く。既定)/ Whole group(グループ丸ごと増やす。全部の子を毎回置く)。Whole の時は Pick と Materials は出ない(2026-09-07)。**2026-09-11**: 専用の `subject` param は消し、全効果に共通の掛け先 `effect.<id>.scope`(Each / Whole)へ吸収した。
- **Pick**: Random(重みと種で引く。既定)/ Iterate(重ね順に回す)。重みが全部 0 なら順番。
- 1 つの Repeater で「丸 75 %・四角 25 % を 200 個」が作れる。素材の種類を増やすのは子を足すだけ。
- **グループ自身の効果列(2026-09-11 裁定)**: 効果は「1 枚に掛かる」としか書かれず、子/全体は host が解く。効果ごとに `scope` を持ち、**Each(既定)は直下の子それぞれの効果列の末尾へ降り**(入れ子は近い親から順)、**Whole は最寄りのグループを板にする** — 板の子孫は 1 枚に焼かれ(`ResolvedLayer::plate`)、板の効果は `after_effects`、不透明度と混ぜ方はそのグループの物。Whole より下の効果は全部 Whole。板のグループへ祖先から配られた Each は板の絵に掛かる。まだ: 板の入れ子(Whole の中の Whole)は最寄りだけ、板の中の clip と matte は落ちる、番号で値を変える取っ手(遅れ・虹)は駆動の帯を待つ、Inspector のトグルは後(native は `whole` と `scopeEffect` を出している)。Expand はグループにはまだ効かない。子に付いた別の Repeater は入れ子にならない。

## クリップとの関係(2026-09-07 裁定)

置き場所で意味が決まる。新しい規則は足さない。

- **Repeater の外から**、増やされた下地にクリップした時 → **複製の和**に 1 回だけ切る(画面上の重なり、Photoshop と同じ)。複製が重なる所でも半透明のクリップ層は二重に描かれない。和を作るために下地の複製は 1 枚に焼かれる(「下に何かを積んだら 1 枚」の規則どおり)。
- **Repeater の中で**(同じグループの子同士をクリップして、グループを増やした時)→ **同じ番号の複製にだけ**切る。5 人を Circle に並べて歌詞を人にクリップすれば、各人の同じ場所に歌詞が乗る。
- 前の「複製ごとにその局所座標で切る」(外からでも N 回描く)はやめた。「各人の同じ場所」が欲しければ中に入れる、「画面の歌詞が人の形で覗く」が欲しければ外に置く。

## 散らしと遅れ(駆動の口を待たない)

- 位置・回転・大きさ・不透明・**時刻**それぞれに取っ手 2 つ: **ずれ**(番号に比例)と**ばらつき**(種でランダム)。
- 遅れ = 時刻のずれ。番号順に出る。散らし = ばらつき。種を振り直すと散り方だけ変わる。
- 粒子は年齢(生まれてから消えるまで 0→1)で減衰する取っ手(消え際の大きさ・不透明)。
- 駆動の口ができたら、配置効果は**番号・年齢の帯**を公開し、外から同じ属性へ落とせる。中の取っ手と外の帯は足し算で同じ属性に載る([動かす](../wiki/drive.md)の規則)。

## 描く側

- 素材は 1 回描いて N 個の変換で instancing。素材が動いていて時刻のずれがある配置だけ、素材を配置ごとの時刻で評価する(唯一のコスト。上限は実測して宣言する。A3 の 64 は本種別の上限ではない)。
- 描画順は番号順、粒子は生まれた順。奥行きがあれば奥から。
- 通り抜けの配置は他の層と前後を挟める。1 枚になった時だけ union の 1 枚として混ざる。

## 採らない物

- 逐次状態の粒子(衝突・風場・粒子同士の力)。Bake の口ができるまで採らない(2026-07-18 A3 の Simulation/Bake 分離を維持)。
- 配置ごとの個別上書き。必要なら展開して切る。
- 文字 1 字ずつ。Text は独自の Sequence(A8)。層単位に限る。
- 汎用の式・ノードグラフ。

## 使う資産・定規

- 効果の口(既存)、グループの通り抜け/1 枚化の規則、re_renderer の instancing。
- 先例: C4D MoGraph Cloner(Linear/Radial/Grid/Object)と Step/Random effector、Cavalry Duplicator、Blender Array/Curve/Particles、Illustrator Transform 効果(コピー数、Appearance の重ね順)、AE Repeater(Offset/Transform)。着工前に「番号 × 取っ手」の意味が一致するかをこれらで確認し、一致した組だけを test に写す。

## 効率(2026-09-06 実測、debug build、48px comp、4px の静止画 1 層)

| 配置 | 素材だけ | 上に blur | 下に blur | 時刻のずれ |
|---|---|---|---|---|
| 1 | 1.9 ms | 10 ms | 10 ms | 1.9 ms |
| 100 | 2.7 ms | 9.7 ms | 9.4 ms | 7 ms |
| 1000 | 19 ms | 29 ms | 24 ms | 95 ms(うち解決 67 ms) |

借りている物: 静止画は rerun の `texture_manager_2d` に path の鍵で 1 枚だけ載り、配置は全部同じ GPU texture を指す。配置は 1 つの `RectangleDrawData` に並ぶ(Normal/Add の run)。自前で足したのは 2 つだけ。(a) `effective_layer_textures` で同じ素材に同じ効果列が続く時、鎖を 1 回流して結果を配る(無いと 100 配置で 4 倍、1000 配置で rerun の staging belt が尽きて落ちた)。(b) `build_layer_shared` で同じ層・同じ source frame の配置は mask まで済ませた 1 枚を置き直すだけにする。
**2026-09-07 追記(5 層 × 30 配置、1920×1080)**: 実窓で重かったのは描画でなく 1 フレームごとの status だった。層ごとに `resolved_layers`(配置込み)を解き直していて 30 配置で 29.5 ms、JSON 82 KB。status で 1 回だけ解いて全層で使い、depthLayout は複製を数えず、混ぜ方の見本は選んだ層だけ、easeKinds は再生中は送らない、で 4.4 ms・40 KB(配置数に依らず一定)。描画側は画面の外に丸ごと出た素の層を組む前に落とす(`offscreen`、効果の余白込み、matte/clip に関わる層は残す)。再生中は Document の版が変わっていなければ **軽い status**(frame・playing・選択・`liveLayers` = 層ごとの値・枠・効果の値だけ)を返し、Dart が `liveLayers` を文書の層に id で重ねる(`EditorSession.liveLayers`)。40 KB → 7 KB。Document が変わればその回だけ全部入りに戻る。区間イージングや Timeline のキーは文書側にあるので影響しない。計測は `ui/native` の `frame_cost_probe`(`cargo test -p motolii-ui --lib frame_cost_probe -- --ignored --nocapture`)。
時刻のずれた配置は配置ごとに層を解き直すので、N に比例して解決が重い(祖先鎖だけ解くようにはした)。rerun に「描いた層の板」の cache は無く、mesh だけ instancing(`GpuMeshInstance`)がある。3D 素材の配置を instance に畳むのは未。個数の上限 1000 は、この実測では時刻のずれ無しなら収まる。

線の実装上の決め: ずれ・ばらつきは**親の空間**で、回転と大きさは層の位置を中心に(Expand で位置・回転・大きさ・不透明・開始時刻へそのまま焼けるため)。大きさのずれは 1 個ごとに掛ける(lottie-web `RepeaterModifier` の累積と同じ)。個数の上限は 1000(未実測。実測して直す)。

埋まる差: [gap](../wiki/gap.md) の「複製に番号が配れない」「種を振り直せない」「繋げて増やせない」。
