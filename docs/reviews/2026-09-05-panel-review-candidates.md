# Motolii パネル別レビュー候補

2026-09-05 / **候補一覧。明白な異常の修正を後続指示で一部実施。末尾の実施記録以外は未承認。**

これは仕様書や実装計画の確定版ではなく、利用者が「合っている／違う／今は不要」を選ぶための一覧です。項目が多いことは、機能が何もできていないという意味ではありません。既存の形を保ち、各パネルの仕上げを段階的に決めるために広く挙げています。

## 今回の前提

- rerunをビューの基盤とし、Lottie／AEのレイヤー・アニメーションモデルを扱う。Abletonへの敬意は密度・整頓・操作感に置く。
- 既存のパネル構成、固定Transform配置、グループレイヤー、Textにフィットするギズモを、独断で置き換えない。
- 普通の操作の参考に外部資産を使う。ただし外部ソフトの仕様をそのままmotoliiの正解にしない。
- **実装は利用者が対象項目にOKを出した後。パネルへの包括的なOKと、個別機能へのOKを混同しない。** この文書の作成で承認されたのは調査と文書化だけ。
- パネル固有の見せ方を詰めても、作品の選択・Document・Undo・プレビュー確定／取消は共通の意味を保つ。

## 読み方

| 表記 | 意味 |
|---|---|
| 実画面 | 今回開いているアプリで目視した事実。記載した状態に限る |
| コード | 現行コードを追って確認した構成・経路。操作結果の実証ではない |
| 要確認 | 不具合かどうか、実操作で確認が必要 |
| 候補 | 新機能や好みを含む案。未実装と全製品範囲で断定するものではない |
| 不備 | 現在の意味を保って正しさ・表示を直す方向 |
| 仕上げ | 見つけやすさ、読みやすさ、反応を整える方向 |
| 意図 | 選択・適用対象・配置など、利用者の設計判断が必要 |
| 追加 | 必要性から選ぶ新しい入口・機能 |
| P1 / P2 / P3 | 基本操作の信頼・理解 / 日常の仕上げ / 拡張候補。実装順の決定ではない |

返答は「COL-01 OK、COL-02は保留、MED-01は16:9だがcontainは不要」のようにID単位で可能です。**未指定は未承認のまま**です。

## 最初に目についたこと

- **Composition:** Frame rateの59.94・60等がメニュー背景の右外へ出ている。
- **Export:** Outputが一部の文字しか見えず、設定の全体を確認できない。
- **Timeline:** 時間定規に目盛線はあるが、秒／フレームの数字が見えない。
- **Colors:** 色輪は常設できている。単一項目の左欄と固定幅スウォッチに対して、面積配分を見直す余地がある。
- **Media:** 素材0件の棚がほぼ空白で、棚内の取り込み入口が見当たらない。
- **Desk:** Textを開くと、Textレイヤー選択中でも「No marker yet」。機能が壊れているというより、名前から期待する対象と実際の対象が違いそう。

この6点を同じ扱いで直さない。上3点は表示不備の候補、後3点は用途・設計の確認を含む。

- 復元記憶の保持型を変更するため、テスト変更をUndo済みのapp68431とserver67552を終了後に統合。一度の同profile baseline後、保存済み作品を開いて通常warm経路へ戻す。作品ファイルには変更しない。
