## 決めた事(利用者の言葉から)

| 言葉 | 決めた事 |
|---|---|
| 「変数はどこまで減らせる」「キャッチボール」 | 人が気にするのは 行き先・届き方・当たり の 3 つ。数値の欄は 重さ・硬さ・ばらつき だけ |
| 「既存の概念を連続体に」 | 場は Turn(引き寄せ ↔ 渦 ↔ 押し出し)と Spread(点 ↔ 一様)。Arrive は Radial(1 方向 ↔ 放射)。モードの境目は無い |

| 「動きは離散的にならないように」 | 立ち上がりを緩め、コマ間が跳ばないことを試験にした |

## 残った穴

- **つなぐ線が GPU で動いた端に付いて来ない**(線は書類側で解くため)。今は糸も同じ `Hang` で吊って合わせている
- **ループ**(Pinterest は 3〜17 秒で閉じる)
- **硬さ(潰れ)** — Offset に scale は在るが、頂点はまだ回りまでしか使っていない
- 積もりの釣り合いが粗く、数枚が宙に残る
- ハンドル(絵の上の 行き先・引き・撞点)はまだ欄のまま。**可視モード**は入った(`Physics Trace`)
- 解き手を Rapier に差し替えた(自作の押し合いは削除)。時間は列、狙いは時刻の純関数
