## 結論(利用者の裁定)

1. **ズレの正体 = 段差を段差として見ていなかった。** 良かった 3 つ(スマホゲーの嘘・CSS・Rapier)は「持っていない人」の側を向いていた。9/17 の写し 20 本・台帳・GSAP ease は既に Adobe/GSAP を知る人の要件。
2. **言葉の基準: LLM は人、機械 = 静的処理(法)。** 機械にやらせる所は LLM の手順でなく法が埋める所。
3. **軸は変わらない: 最小の意図の手で最大の画。** Cavalry 製の書体動画(29 秒)は意図の手 16(素材 1・箱 1・密度の曲線 1・札 12・例外 1)、AE なら約 320、Cavalry で約 100。
4. **正本 = 毎コマの式 + 公開されたデータ**(Flash/AS3・Processing/oF・three.js、Radiohead 2008・Wilderness Downtown 2010・Perfume 2012)。AE も Cavalry も GSAP(= Flash の TweenMax)も写し。Flash では「最小の手」は美学でなく形式が強制した(ベクター・2 鍵のトゥイーン・シンボルの複製・56k)。
5. **檻 = 天井を決めた瞬間に自動で出来る。失われた世代 = 檻の中で生まれ、床(式・データ)があった事を知らない世代。** Motolii は「鍵と層の道具に床を戻す」。
6. **コードの抽象化はしなくてよい。ユーザ(とその LLM)が勝手に拡張する。** Vism は code のまま、札とバーは頭書きから。Motolii が持つのは小さく安定した契約と、LLM が読める契約の写し。

## WESL に相乗り(利用者「Vism を単位にせず WGSL に相乗り」→「WESL でええやろ」)

棚の「`_` の file を全部の頭に繋ぐ」自前の規則を消し、WESL(wgsl-tooling-wg の WGSL 拡張、import と条件翻訳)に置き換えた。

## kkmfd の欠け 4 つの口(レーン A、doc と台本だけ、未 commit)

kkmfd の分解(`2026-09-18-kkmfd-decomposition.md`)で欠けた 4 つを、render を触らずに doc と prelude で開けた。名前は先例から。

- **Repeater の奥行き** — `Placement.offset_z` を足し、`affine3` の平行移動へ載せ、resolve の写しで `placement.z += offset_z`(2D の `affine2` は変えない)。欄は Position Z の Each / Random(`position_z_each` / `position_z_random`)。写しの模型は 2.5D/3D の `world_transform` 経由で奥行きを受けられる: 欠けていたのは Placement 側の Z 1 本だけ。test 1 本。render の `placement.z` の読み(compositor.rs:143・blocks.rs:523 の flat 判定)はそのまま、写しの z が動くだけ。
- **cuts**(`ui/native/src/editor/script/prelude.js`)— `cuts(bpm, [[layer | [layers], beats], ...])`: 拍の表を背中合わせの in/out にする(`setTiming`、始点と終点をコマに丸めてから長さを取るので枠が 1 コマ重ならない)。同じ層が 2 枠に出たら断る(複製して使う)。戻り値は合計秒。
- **shuffle** — Cavalry の Shuffle(String Manipulator)の語。`shuffle(layer, { seconds, rate, charset, seed, settle })`: 1/rate 秒ごとに未確定の文字を charset から `random(seed)` で引き、最後の `settle` 秒で左から確定、`seconds` で元の文に落ちる。本文の鍵は `toggleKey content` → `setText` の 2 手(setText は鍵 1 つ以下だと差し替えるので、先に鍵を立てる)。空白と改行は動かさない。

## 群だけでは無理が出る → 所属 / 参照 / 場(利用者、深夜)

群 = 所属(変形と配置が一緒に付いて来る)。「所属せずに見る」(別の群の物、物理の物、並びを壊したくない時)は群では言えない。
先例は同じ形に収束している: Blender の Constraint、Rive の Constraint、CSS の anchor positioning(参照)/ C4D の Effector(場)/ Figma の Frame(所属)。
Motolii の置き方: **機構は anchor 1 つ**(Item に相手の番号、block から `now_of(j)`、j は anchor があればそれ、無ければ親 = 群が既定)。**語彙は Constraint の札**(Follow / Look At / Keep Distance / Copy Rotation、Blender の名前、中身は 3〜5 行の block、積めば重なる、Strength で薄まる)。相手の要らない関係は場(neighbor と Effector、既にある)。
直感の置き場は語彙ではなく仕草 1 つ: **これをあれに引っ張る → 線が見える → 線で種類を変える**(AE の pickwhip)。語彙は仕草の後ろに隠す。UX の合否は利用者。
明日の絵 3 枚(親を動かす / 別の群の 1 個を動かす / 群の欄を動かす)は線が見える形で出し、zz_reach で比べてから名前を決める。
