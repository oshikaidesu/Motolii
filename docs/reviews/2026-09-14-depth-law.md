## 実験(2026-09-14)

bento の Group を 3D にして Tilt Y 32°・Tilt X 12°。

- **効いた**: 並びは 1 枚の面として傾く(格子・Span・角丸・隙間が崩れない)。並べる計算は面の x, y を解いて変換に渡すだけなので、面ごと 3D に入る。
- **壊れた**: セルの中の文字が消えた。背景と文字が同じ z に居て、深度で奪い合う。2D は同日の `layer_sort_key` で積み順にしたが、3D の深度の世界ではまだ。

## 先例

| 先例 | 形 | 読み |
|---|---|---|
| CSS | 並べるのは平面。3D は `transform` で並びに効かない。`transform-style: preserve-3d` の中で同じ面の物は文書の順で重なる | 面の上の積み順の規則 |
| **visionOS 26 SwiftUI**([Meet SwiftUI spatial layout](https://developer.apple.com/videos/play/wwdc2025/273/)) | 大きさに **depth**、位置に **z**、揃えに **depthAlignment**(front / center / back、Stack の既定は back)、**ZStack は奥行きを足して積む**、`rotation3DEffect`(見た目だけ)と **`rotation3DLayout`**(回した物の箱で並べる)、`SpatialContainer` / `spatialOverlay`(同じ 3D の場所に重ねる、3D の揃え `.bottomFront` など)、`scaledToFit3D`(幅・高さ・奥行きに収める) | 2D と同じやり方で 3D を並べる。Apple 自身の説明 |

visionOS の奥行きの 3 種:
- **奥行き 0**: Image・Color・Text(iOS と同じ)
- **決まった奥行き**: Model3D
- **伸びる奥行き**: RealityView、`.resizable()` の Model3D

## 法(案)

1. **箱は奥行きを持つ**。文字・画像・動画・平らな形 = 奥行き 0。押し出し(Depth・Extrude)= その厚み。メッシュ・点群 = bounds の奥行き。画像・動画・メッシュ・点群の元の寸法は host が測った値を解析の橋と同じ口で読む(書類に書かない)。
2. **並べるのは今までどおり面の x, y**(CSS)。**奥行きは容器ごとの Depth Alignment**(Back / Center / Front)で z を決める。容器の奥行きは子の最大。**既定は Back**(visionOS の Stack と同じ)。
3. **同じ面の上の重なりは積み順**。Display の Group の面に乗る物(背景・文字・形)は、3D でも深度で奪い合わず、積み順で重なる(CSS preserve-3d)。奥行きを持つ物(押し出し・メッシュ)は深度で解く。
4. **回転は 2 つ**。層の Rotation / Tilt は見た目だけ(`rotation3DEffect`、今の法 4 の続き)。**並びに効く回転**は別の欄(`rotation3DLayout`、回した bounds の軸に沿った箱で並べる)。zoom / transform と同じ分け方。
5. **奥へ積む並べ方**: 子を奥行き方向に、奥行き + Gap ずつずらして積む(ZStack)。
6. **3D の Object Fit**: Contain / Cover / Fill を幅・高さ・奥行きへ(`scaledToFit3D`)。セルにメッシュを収める。
7. **札は自動で変えない**(2026-09-12)。並べる Group の札が面を決め、子の札は子の描き方を決める。

## 裁定(2026-09-14)

1. Depth Alignment の既定は **Back**(利用者「うん」)
2. 奥へ積む並べ方は **Flex Direction に Depth を足す**(CSS の語の延長。Gap・Justify がそのまま効く)(利用者「a」)
3. 並びに効く回転は **別の欄 `Layout Rotation`**(zoom / transform と同じ 2 つ持ち)(利用者「うむ」)
4. 3D の Group の中の 2D の札の子: **実物を見てから**。仮に「札は変えず、並べた場所の画面上の位置へ世界の外で平らに描く」で作り、窓で見て決める

## 夜間の提案(2026-09-15): 奥行きでも押し合う

[間合いの法](2026-09-14-margin-law.md) 2 の押し合いを、法 1 の奥行きへ。朝に取り消せる。

- 容器の外の兄弟同士で、**両方が 2D でない**物は、箱に奥行き(Position Z + 奥行きの範囲、Margin で広げる)を足した立体の箱で重なりを測り、中心から中心の向き(3 軸)に押し戻す。ずれは Position Z にも足す(`Frame::nudges_z`)
- 片方でも 2D なら今までどおり面の上だけ(2D の物は奥行きの向きに押さない)
- 奥行きで離れていれば、面の上で重なって見えても押さない(手前と奥)
- 移り方(Transition)は奥行きのずれにも同じ重みで効く

見本 `make_way.js`(傾けた卓の上の小さな立体の群れへ、大きな立体が降りてきて横へ滑る): 跳び 0・尖り 0(物差しに世界の z を足した)。

## Repeater との関係(利用者「これってかなりリピーターでやってたことじゃないか」)

見た目は重なる(Repeater の Line / Grid はグループの子を素材の袋にして並べられる)。意味は分ける:

- **Repeater = 分配**: 素材を数で増やし、決まった刻みに置く。子の大きさは見ない。同じ子を何度も引ける。数・刻みにキー、番号の Each / 種の Random
- **Display = 交渉**: 別々の層を 1 回ずつ、互いの大きさを知って置く。Hug / Fill、奥行きの揃え

共有するのは**住所**(番号・行・列・奥行きの段)。表現の分配(stagger の from)は両方に同じ欄で掛ける。
