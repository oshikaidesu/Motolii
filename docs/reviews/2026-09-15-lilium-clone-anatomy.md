# 花の PV の中の仕組み — クローンを作るための分解

2026-09-15。利用者「要素だけをなぞりすぎてる。あの画のクローンが作れるように中の仕組みを精査し自走して」。
対象は X で @manwon_man が紹介した百合の PV(作者 instagram.com/yuk.aji、6.76 秒、1280×720)。紹介文の要点は「格子・ガイド線・編集画面のような要素と一緒に解く」「色が急に変わっても文字と花がずっと中心にいるので流れが切れない」。
読み方: ページの中で video をキャンバスへ描き写し、1/15 秒ごとのコマ(一部 1/30 秒)を並べて見た。ファイルは落としていない。

## 文法

**1 つの主題(百合)を中心に固定し、0.2〜0.8 秒ごとに「表し方」を替える。** 写真 → 箱と補助線 → 画素の影 → 寄り → 部分の窓 → 白黒 → 部分の切り抜きの列 → 文字 → 巨大な文字 → 青い図面 → 画素の星 → 文字の中の画 → X 線。
切り替えは拍の上の硬いカット(色の反転 1〜2 コマを挟む)か、**箱をくぐって寄る**。連続しているのは、主題の位置・箱・文字の列(関係)で、色と素材は離散。

## Motolii での在庫(2026-09-15)

| 仕組み | 在る | 足りない |
|---|---|---|
| M1 箱の HUD | つなぐ線(2 つの箱)、付いて置く札 | **1 つの箱をなぞる形**(外枠・角の掴み・対角線・内接円・画面を横切る補助線)。Track Overlay は塊用で、層の箱を読まない |
| M2 部分の窓 | Clip・Set Matte、同じ層の写し | **色の変換**(Hue/Saturation、Tint、Invert) |
| M3 くぐって寄る | 鍵、Transition、Motion Blur | — |
| M4 画素 | — | **Mosaic**(セル)、**Block Dissolve**(散る)、**Linear Wipe / Gradient Wipe**(階段の順) |
| M5 列 | Flex、Fill / Cover、Clip、つなぐ線、札 | — |
| M6 席の入れ替え | 時刻の外の子は並びに入らない | 確かめる |
| M7 / M8 字の席 | 字ごとの層を Flex に並べる | 1 つの文字の層のまま字ごとに席を持つ口は無い(スクリプトで字ごとに作る) |
| M9 文字の中の画 | 字ごとの層 + 画の箱を同じ列に | 同上 |
| M10 閃き・粒子・点の格子 | 鍵(Hold)、Repeater の格子 | **Noise(粒子)** |

素材: 百合の切り抜き(アルファ付き)、部分の寄り 5〜6 枚、X 線風の 1 枚。手元に無いので、まず形で組んだ仮の花で仕組みを通し、素材は利用者に依頼する。

## 作る順

1. 1 つの箱をなぞる形(M1)— つなぐ線の口に `Trace` を足す(先例: CSS `outline` / `outline-offset`、Figma の選択の掴み、Tracery 2 の Box / Marker)
2. 効果のデータ(`vism/*.fs`、AE の名前と欄): Hue/Saturation、Tint、Invert、Mosaic、Block Dissolve、Linear Wipe、Noise
3. M6 の確かめ
4. クローンのスクリプトをショットごとに組み、参照のコマと並べて見比べる

## クローンを組んで分かったこと(2026-09-15)

スクラッチ `lilium.js`(形で組んだ仮の花、6.8 秒 204 コマ)で、上の 17 ショットを仕組みどおりに通した。M1〜M10 はすべて Motolii の口で出た。素材(百合の写真)が入れば、見た目の差は主に素材の差になる。

足した口(この日): なぞる形 `Trace`、効果 7 枚、スクリプトの `effect(...).whole()` と `layer.clip()`、形の層の `Stroke Width` の欄(書類の `shape.stroke_width` を窓とスクリプトへ)。

組む途中で踏んだ物(利用者の判定が要る物を含む):

| 踏んだ物 | 事実 | 回避 |
|---|---|---|
| **既定の 3D の札で、同じ面の層の重なりが order でなく画面の中心からの距離で決まる** | 画面の中心に近い層ほど上に描かれる(同じ z の 3D の層は re_renderer の距離の並べ替えだけ)。背景の全面の矩形が文字や花を覆った | 全層を 2D の札に |
| Group の時刻が子の時刻を切らない | Group を 0.4 秒だけ出しても、子は層ごとの帯のまま映る(AE のプリコンプの感覚と違う) | ショットごとに部分木の全部に時刻を付ける |
| Group(板)に Set Matte・clip を掛けても切れない | 板の中の clip と matte は落ちる(配置効果の法の既知の未) | 画面全体の写しを透明の全面の矩形で包み、Overflow Clip の箱で切る → **本当の穴はブレンドモードに「クリッピングマスクの逆」が無いこと(利用者)。[Stencil / Silhouette](2026-09-15-stencil.md) を足した** |
| 並べる列の席は層の order の順 | 複製(duplicate)は元の隣の order に入るので、列の中の席がずれる | order を並べ直す |
| Absolute の子の Position は子の原点 | CSS の inset(箱の左上)と違う | 原点で置く |
| スクリプトの `set` は毎回その層の JSON を読み直す | 700 層を組むと 20 秒の予算を越える(予算は走り終えてから判定) | 花を 1 度だけ組み、複製する |
| 形の層に線の太さの欄が無い | 書類の property はあるが窓とスクリプトの表に出ていなかった | 欄を足した |
