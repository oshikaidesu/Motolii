# Motoliiの根本コンセプト

2026-09-05の利用者発言と既存docsを照合した根拠資料。現行の統合本文は[concept](../concept.md)。この資料自体は実装済みの宣言でも、新しい機能制限の制定でもない。

## 何を作るか

**Lottieを基幹モデルとし、Rerunをビュー・描画基盤に使う、レイヤーベースの映像編集・コンポジットソフト。AEの良い作法と表現力を、Ableton的な整頓された高密度UIと、Figma的な直接操作で扱う。**

出発点は自分のMVを完成させること。今回の継続ゴールは、AEユーザーや動画編集ユーザーが普通に、快適に使え、AEを超える制作体験へ育てること。過去の「自分用なので他の利用者の導線は対象外」という優先順位を、今回の依頼への拒否理由にしない。

## 守るもの

1. **ユーザーの意図。** コード、仮実装、過去のLLMの解釈を守ることが目的ではない。大幅な改修も可能。ユーザーが選んでいない制約を「あえての設計」にしない。
2. **構造による解決。** グループレイヤーのように、面倒な手順や回避策を必要にしている構造を解消する機能を積極的に作る。単なる操作の束ね直しやショートカット追加へ縮めない。
3. **整頓された密度と直接操作。** 操作場所が安定し、選択対象・変更結果・戻し方が分かる。説明文で補うより、配置、形、状態、直接操作で伝える。既存UIも完成品とは扱わない。
4. **レイヤーとキーフレームの良い作法。** AEの有用な編集文法を継承する。拡張機能で補われてきた日常的な便利さは、標準の編集経路へ取り込む材料として調べる。
5. **同じ3D空間。** 板、文字、立体、点群は同じStageに存在する。視点の操作と作品の変更を分離し、都合のために暗黙の2D化を強いない。

## 技術と意味の境界

| 対象 | 役割 |
|---|---|
| Lottie | 作品、レイヤー、キーフレーム、補間、変換などの基幹モデル・意味の基準。JSON入出力や保存形式だけの話へ縮めない |
| Document / Intent | 作品の編集状態と書き込みの所有者。Undo、プレビュー、確定を通す。保存・クエリにRerun部品を使っても、作品の意味の基準は変わらない |
| Rerun / re_renderer / wgpu | ビューと描画の技術基盤。Lottieの意味を、Rerunのログモデルの都合へ置き換えない。既存部品に委ねられる機構を再発明しない |
| Rustネイティブ | GPU資源を共有し、re_rendererとのゼロコピー経路を成立させる基盤 |
| Flutter（Stage 5） | LLMがUIを反復しやすい編集面。通常のUI変更はホットリロード。Dioxus / Blitzは検証後の旧経路 |
| Vism / vgpu由来の体系 | 小さい契約、宣言された入力と値・時間、ホスト内部を知らずに書ける表現データ。LLMが単独で作成・試験・並列制作できる入口 |

Motoliiが独自に持つ責任は編集の意味と表現データを中心にする。ただし「Rerunに部品がある」だけでは採用理由にせず、Lottieの意味、依存の適合、実行速度と所有責任を確認する。

## 「普通」の扱い

「普通」は一つの製品の全模倣でも、先に完全列挙できる仕様でもない。操作ごとに蓄積された利用者の予測を、具体的な制作で確認する。LLMの知識は仮説に使い、仮説を無検証で製品仕様へ昇格させない。コンパイルや一部試験の成功を、制作体験の完成と取り違えない。

## 既存の根拠と差分

- [concept](../concept.md)：目的の出発点、最小の独自責任、一般の動画編集を土台とする考え、同じ空間、Vism。下部には明示的に退役した歴史もある。
- [ideal](../ideal.md)：意図、直接操作、見せる段、見る／作るの分離、再現性、空間の原則。
- [Lottie対応表](../../motolii/reference/lottie-coverage.tsv)・[参照スキーマ](../../motolii/reference/lottie.schema.json)：語彙と対応状況。対応表の既存判定も、今回の利用者指示と実挙動に照らして再評価可能。
- [Rerun部品調査](2026-08-29-rerun-parts-catalog-survey.md)：技術委託と意味の翻訳の境界。`re_tf`不採用の理由も記載されていた。今回の試験的導入は採用確定ではなく、意味と責任の適合を再点検する対象。
- [vgpuとVism](../../motolii/reference/vgpu-vism.md)：借りる体系とホットリロードの境界。
- [現行憲法](../../motolii/AGENTS.md)：開発の制約。今回の要約で改変していない。
