# 今の映像表現の語彙 — ジャンル・場・作家・褒め言葉の索引(2026-09-18 取得)

課題: 利用者の困りは「欲しい画をどう言えばいいか分からない」= 語彙の問題。MV・モーショングラフィックス・タイトル・ライブ映像・ネットの短尺で**今(2020〜2026)使われているジャンル名**を、名前 → 見分け方 → 代表作 → 出自と道具、の表にした。根が古い物は根も書いた。一次資料(作家本人・賞の公式・Vimeo・公式 MV・レーベル/スタジオ公式・専門媒体の原文)を優先し、当たれなかった物は「未検証」と書いた。判断は書かない。

## 0. 要約(5 行)

1. **ジャンル名は 3 層で生まれる**: (a) 道具の名前がそのまま様式名になる(Cavalry 系・TouchDesigner 系・Blender Eevee 系・C4D+Redshift 系・Lottie 系・CapCut テンプレ名)、(b) 時代の見た目に後から名前が付く(vaporwave・Y2K・Frutiger Aero・acid・brutalism・anti-design・Corporate Memphis — 命名者は CARI や Eye on Design 等の批評側)、(c) 技法名がそのまま様式になる(datamosh・pixel sort・rotoscope・line boil・smear・velocity edit)。
2. **日本の文字 MV は独立した系**: ニコニコ発のボカロ MV(一枚絵 + 歌詞 → AE で動かす)が「リリックビデオ」の国内の型を作り(大橋史 GDR 2024 が「ボカロ的な様式に縛られてきた」と明記)、2022〜24 に Vaundy「置き手紙」(牧野惇、クラフトモーション)や橋本麦(MONO NO AWARE、Tokyo TDC 2025 グランプリ)がその外側を作った。
3. **賞と場の分類語が公用語**: Motion Awards(Title Sequence / Music Video / Experimental / Infographics / Show Package …)、映像作家100人(2D animation / 3DCG / Motion graphics / Live action / Stop Motion / Kinetic …)、D&AD(2D Digital / 3D Digital / Mixed Media / Motion Design / Title Sequences / Use of AI)、Stash(3D Style / 2D Characters / Explainers / Typography)。日本語の界隈語(「文字 MV」「イラスト MV」「エモい」「シュールおしゃれ」)は媒体・作家の口から拾うしかない。
4. **褒め言葉は「動きの質」と「画の質」で別**: 動き = buttery / snappy / sluggish(悪)/ floaty(悪)/ decisive / restrained / weight / juicy / satisfying、タメ・ツメ・緩急・間(間延びは悪)・気持ちいい・ヌルヌル/カクカク。画 = craft / intention / 質感・空気・手触り・粒子・余白・情報量・うるさい(悪)・綺麗すぎる(悪)。出所は Emil Kowalski の vocabulary、Figma Learn、Animator's Survival Kit、Motionographer 講評、CGWORLD(佐藤太郎・森江康太・山崎浩太朗)、sakugabooru 用語集。
5. **見つからなかった物**: 「良い ease」を直接指す日本語(決め切った・抜けがいい・キレ)の一次出典、glitch/CRT/VHS/chrome/clay の 2020 年代の**作家名付き**公式 MV、TikTok Creative Center のハッシュタグ語(JS 描画で取得不可)、Houdini を明かす日本の MV 作家、PROTO の同定。
