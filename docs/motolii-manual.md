# Motolii 操作の説明書

- 位置づけ: **窓を触る人が読む物**。何を掴むと何が起きるか。
- 語彙の意味(なぜその言葉なのか)は [concept](concept.md)、
  決めた事の経緯は [decision-index](decision-index.md) を主題で grep

## 覚える言葉は5つ

| 言葉 | 何か |
|---|---|
| **層(layer)** | 時間の上に置かれた1枚。素材・文字・形・点群のどれか |
| **属性(property)** | 層の値。位置・拡縮・回転・不透明度・アンカー |
| **キー** | ある時刻の値。2つ並ぶと間が動く |
| **エフェクト(Vism)** | 層の絵に掛ける計算。パラメータは属性と同じ扱い |
| **合成(blend)** | 下の絵とどう混ぜるか |

Motolii はこの5つしか持たない。3Dも「平面に畳んでから置く」のではなく、
**空間にそのまま置く**(点群も板も同じ空間に居る)。

## 画面の4つの部屋

| 部屋 | 役目 |
|---|---|
| **Stage** | 絵。掴んで動かす |
| **Timeline** | 時間。並べる・切る・キーを打つ |
| **Inspector / Utility** | 値と、値ではない道具(タブで切り替え) |
| **Browser** | 素材と、新しい層を作る口 |

## 手つき

### Stage

| する事 | 手 |
|---|---|
| 選ぶ | 板をクリック(⌘で足す) |
| 動かす | 板の中をドラッグ |
| 拡縮 | 角・辺のハンドル(⇧で比率固定、⌥で中心固定) |
| 回す | 枠の少し外をドラッグ(⇧で角度を刻む) |
| 向きを変える(立体) | Utility の GIZMO を「立体」にして板の中をドラッグ |
| 奥行き | 同じく立体で ⌥ドラッグ |
| 画面を動かす | 何も無い所をドラッグ |
| 寄る・引く | ホイール |

### Timeline

| する事 | 手 |
|---|---|
| 開く | 層名の左の ▸。属性の行が出る |
| キーを動かす | 菱形をドラッグ(層の行なら束ごと、属性の行ならその属性だけ) |
| 帯を動かす・伸ばす | 帯の中/端をドラッグ。近くの端と再生位置に吸い付く |
| 名前を変える | 層名をダブルクリック |
| 表示・独奏・鍵 | M / S / L |

### 打鍵

| 打鍵 | する事 |
|---|---|
| `Space` | 再生 / 止める |
| `←` `→` | 1コマ(⇧で10コマ) |
| `Home` `End` | 頭 / 尻 |
| `⌘K` | 再生位置で切る |
| `[` `]` | 層の頭 / 尻を再生位置へ動かす |
| `⌥[` `⌥]` | 再生位置で切り落とす |
| `⌘[` `⌘]` | 重ね順を下げる / 上げる |
| `↑` `↓` | 選択を上下の層へ |
| `U` | キーを持つ属性だけに絞る |
| `*` | 再生位置にマーカーを打つ / 外す |
| `⌘←` `⌘→` | 前 / 次のマーカーへ |
| `⌘A` / `Esc` | 全選択 / 選択を解く |
| `Delete` | 層を消す |
| `⌘Z` / `⌘⇧Z` | 戻す / やり直す |

### Inspector

値は数字を横にドラッグして変える。◇を押すとその時刻にキーが立つ。
**BLEND** で混ぜ方、**PARENT** で親、**EFFECTS** で効果の追加と削除。
子を持つ層には「凍らせる」が出る。

### Utility

アンカーを9つの場所へ寄せる。ギズモを平面/立体で切り替える。

### Browser

素材をクリックすると層になる。**層を選んでいる時に ⌥click すると
その層の素材が入れ替わる**(新しい層は増えない)。

## まだ窓から届かない物

| 物 | なぜ |
|---|---|
| マスク | 形は持てるが、**絵に効かせる所が繋がっていない**。UIを先に作ると嘘になる |
| 式・リンク・スロット | 見せ方が未裁定 |
| 素材の入れ替え・破棄(Browser の在庫側) | Browser が今の在庫を Document から引いていない |
