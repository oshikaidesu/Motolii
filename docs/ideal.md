# 根底 — こう作り、こう測る

理想は好みではない。**設計を生む考え方**と、**当てると落ちる物差し**が
同じ物の裏表になっている。6つ。

---

## 1. 掴んだ所が、意味を決める

利用者は道具を選ばない。手の下に在る物が、何が起きるかを決める。

**設計へ:** 同じ入力の意味を変える持続状態を持たない。
利用者に見えない前提で分岐しない。

**測り方:** 説明書に手つきの表が書けるか。
「モードAで3行、モードBで3行」に割れたら形が違う。
`if 前に触ったことがあるか` のような、窓に出ていない分岐が無いか。

*落ちた物:* 平面/立体のギズモモード。1つ目のキーが再生位置を無視して0秒に立つ。

## 2. 形が、枠を決める

前置きを要求しない。**要る物を頼んだ時に、要る物ができる。**
許可を先に出させない。

**設計へ:** 能力を許可フラグで持たない。内容から導く。

**測り方:** 説明書が「先に○○してから」と書いていないか。
書いていたら時間の欠陥。利用者に「どちらを先にやったか」を覚えさせている。

*落ちた物:* 枠の外へ出る「許し」のトグル。畳む前に大きく作っておけという注意。
グループを作った瞬間に境界にすること(境界は、マスクや効果を頼んだ時にできればよい)。

## 3. 段は、利用者が開ける

頼まれるまで世界を広げない。**教えていない物を、まだ置かない。**
置いてあれば触るので、置いた時点で教えたことになる。

そして次に触る物は、今の手の隣に在る。視線が飛ばない。

**設計へ:** 概念が「まだ無い」状態を、既定として持てること。
キーが無い属性は、ただの値でいられる。

**測り方:** その段の文に出てこない物が、窓に出ていないか。
説明書で隣り合う2文の道具が、窓の中でも隣り合っているか。

*できている物:* Media で素材をクリック → 層になって Stage に出る → そのまま掴める。
*落ちた物:* 頼んでいないのにキーが作られる。

## 4. 新しい力は、既にある物の拡張として出す

新しい種類を足さない。**「それも層です」で済ませる。**

構造の統一は**私が設計を測る言葉**であって、利用者へ渡す言葉ではない。
ノードとレイヤーで、より一般的で組み合わせが利くのはノードだった。
それでも多くの作り手はレイヤーを選んだ。**一般化そのものを手渡されると掴めない。**

**設計へ:** 既存の種類に能力を足す。新しい機構より、既にある責任へ配る。

**測り方:** 新しく覚える名前がいくつ増えたか。1つを超えたら配り直す。

*配り直した物:* 入れ子の統一 → **グループレイヤー**1語。
切り抜きはマスク、色は塗りつぶしエフェクト、畳むのはフリーズ。継承という新機構は作らない。

## 5. 見るのと、作るのは別

どこから覗いても作品は変わらない。**覗く操作に、結果を変える力を持たせない。**

**設計へ:** 視点は作品の外に置く。書き出される物は破線の枠が決める。

**測り方:** 画面を動かして、書き出しが1画素でも変わらないか。

## 6. 振り直せる

作るのは探すことなので、**気に入らない時に「もう一度、違う結果」が出せる**必要がある。
戻すだけでは足りない。

**設計へ:** 散らばりは種を持ち、**同じ種なら必ず同じ結果**になる。
偶然を、後から再現できない形で作らない。

**測り方:** 気に入らない時、直す以外の道があるか。
同じ操作を2回して、同じ絵になるか。
