# 理想の定義 — 何をもって「良い」とするか

理想は好みではない。**当てると落ちる物差し**である。
5つある。上2つは既に何度も落とした。下3つは今日足した。

---

## 1. 形 — 説明書に手つきの文が書けるか

書けないなら形が間違っている。

*落ちた物:* 平面/立体のギズモモード。取っ手の表が「モードAで3行、モードBで3行」に
割れて書けなかった。

## 2. 順序 — 説明書が「先に○○してから」と書いていないか

書いていたら窓の欠陥。利用者に「どちらを先にやったか」という見えない状態を
持たせている。手つきが書けないのは**形**の欠陥、順序を要求するのは**時間**の欠陥。

*落ちた物:* 1つ目のキーが時刻を無視する。頼んでいないのにキーが作られる。
枠の外へ出る「許し」のトグル。

---

## 3. 見せるのは段階的に — その段で使う物だけを出す

まだ要らない概念は世界に出さない。要る時に一度だけ出す。
**出す前の段で、勝手に引きずり込まない。**

*当て方:* 説明書のある段の文に出てこない物が、窓に出ていないか。

ゲームは1面で1つしか教えない。**教えていない物を使わせない**のではなく、
**教えていない物をまだ置かない**。置いてあれば触るので、置いた時点で教えたことになる。

## 4. 触るのも段階的に — 次に触る物が、今の隣に在る

視線が飛ばないこと。手が戻らないこと。

*当て方:* 説明書で隣り合う2文の道具が、窓の中でも隣り合っているか。

*できている例:* Media で素材をクリック → 層になって Stage に出る → そのまま掴める。
選ぶ・出す・触るが一直線に並んでいて、視線が戻らない。

---

## 5. 直感 — 入れ子が唯一の関係(DOM がそうしたように)

DOM が30年標準であり続けた理由は、機能の多さではない。
**一つの関係だけで、ほとんど全部を決めた**ことにある。

### DOM が正しくやったこと

**入れ子が意味そのもの。** ある物が別の物の中に在る。
その1つの関係が、位置・切り抜き・重なり・寿命・選択の単位・イベントの行き先を
**全部同時に**決める。人が世界を理解する時いちばん先に持つ関係は座標ではなく
「中に在る/外に在る」で、DOM はそれを主構造に据えた。

**木は一つしかない。** 見える物・当たる物・読み上げる物・順番が、同じ木から来る。
別々に持てば必ずずれるが、一つしか無ければずれようがない。

**内から外へ帰る。** 触るのは一番内側の物。意味は、それを気にする外側が引き取る。
座標を配線しない。

**既定は上から降り、言えば覆る。** 親に色を置けば子が従い、子が言えば子が勝つ。
これは自然言語や規則と同じ構造で、人はもともとこの形で物を考えている。

### Motolii へ当てると

**含む関係が3つに割れている。** 親(transform だけ)・flatten(焼く)・マスク(切り抜く)。
AE も同じで、precompose・親・マスク・トラックマット と4つに割れている。
**AE が難しいのはここ**で、機能が多いからではない。同じ「含む」を4回別々に覚えさせる。

理想は1つ。**入れ子が、位置も切り抜きも混ぜる範囲も継承も同時に決める。**

- **まとめる** = 入れ子。親を回せば中身が回る
- **切り抜く** = その入れ子に形を1つ与える
- **畳む** = その入れ子を1枚に焼く
- **色を抜く** = 親に置けば、中の子が全部従う

3つの機構ではなく、1つの関係の3つの面になる。

### ただし、利用者の語彙にはしない

**統一された構造は実装の性質であって、教える概念ではない。**

ノードとレイヤーで、より一般的で組み合わせが利くのはノードだった。
それでも多くの作り手はレイヤーを選んだ。**一般化そのものを手渡されると掴めない。**

「入れ子が唯一の関係」は**私が設計を測る物差し**であって、
説明書の言葉ではない。利用者に見せるのは**既にある物の拡張**にする。

- 私が測る言葉: 入れ子が唯一の関係
- 利用者が読む言葉: **中に層を入れられる層がある。それも層なので、層にできることは全部できる**

切り抜きはマスク、色は塗りつぶしエフェクト、畳むのはフリーズ。
**新しい概念を作らず、既にある責任へ配る。** 新しいのはグループだけ。

### 当て方

- 同じ「含む」を、別々の仕組みで2回作っていないか
- 見える物・掴める物・並ぶ物・出る物が、同じ構造から来ているか
- 掴むのは一番内側か。外側を掴みたい時、一段上がる手つきが在るか
- 既定は親から降りるか。子が言えば覆るか
- **統一を利用者の語彙へ漏らしていないか。** 新しく覚える名前は1つに収まっているか
