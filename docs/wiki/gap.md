# gap — 理想と窓の差

説明書は完成形を書く。ここだけが現実を書く。

## 作法 — 1本書いて、書けない所を数える

1. 理想の MV を1本、節ごとの画まで書く([一本通す](mv.md)、[もう4本](mv-more.md))
2. 手順が**書けない**所が差。書けたつもりで木に無い物も差
3. 既に出ている差なら**本数を1増やす**。無ければ行を足す
4. **新しい1本を書いて、新規の行が0だったら収束**

差は増え続けない。作り手が変われば要る物も変わるが、**同じ物が何度も出る**。
何本で要求されたかが、そのまま順番になる。

## 数えた結果(5本)

`5/5` は全ての作り手が要求した物。`1/5` はその1本の味。

### 駆動 — 値を決める物(口が無い)

| 本 | 差 |
|---|---|
| **5/5** | **音が見えない。** Timeline に波形が出ない。どこがサビか目で分からない |
| **4/5** | **拍が無い。** BPM も拍の線も無く、帯もキーも吸い付かない |
| **4/5** | **複製に番号が配れない。** 紙片20枚・文字1字ずつ・粒子数千を、別々の値で散らせない |
| 2/5 | 種を振り直して、散り方だけ変えられない |
| 1/5 | 音量・音高が値を動かさない |
| 1/5 | カメラからの距離が値を動かさない(輪郭線の太さ) |

### 素材 — 絵を生む物(口は在る)

| 本 | 差 |
|---|---|
| **3/5** | **文字が層になっていない。** 歌詞・タイトル・版ズレが作れない |
| 2/5 | 生成パターン(格子・三角)が無い |
| 2/5 | 粒子が無い |
| 1/5 | 線を伸ばせない(TRIM) |

### 効果 — 絵を変える物(口は在る)

| 本 | 差 |
|---|---|
| 2/5 | 色の一括差し替えができない。Colors に組が無い |
| 1/5 | 混ぜ方に反転が無い |
| 1/5 | ぼかしが無い |
| 1/5 | トゥーン(輪郭線+2段影)が無い |
| 1/5 | 集中線が無い |
| 1/5 | 前のコマを取り込めない(フィードバック) |
| 1/5 | マスクが絵に効かない。画面分割ができない |

### 窓

| 本 | 差 |
|---|---|
| — | 掴んでいる間の `X` `Y` `Z` 制約が無い |
| — | flatten に窓の置き場が無い |
| — | 視点を書き出しの枠へ戻す一手が無い |
| — | パネルの配置が保存されない |
| — | Media の在庫が作品を見ていない |
| — | 式・リンク・スロットの見せ方が決まっていない |

## 読み取れたこと

**上位3つは全部「駆動」。1/5 の物は全部「効果」か「素材」。**
本数の順と、口の有無が一致した。

- 効果と素材は**口が在るので並列で一気に足せる**。1本しか要求していない物でも、
  足すのは安い
- 駆動は**口が無いので直列**。ここだけが順番を決める
