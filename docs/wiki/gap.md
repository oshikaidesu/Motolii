# gap — 理想と窓の差

説明書は完成形を書く。ここだけが現実を書く。

## 作法 — 1本書いて、書けない所を数える

1. 理想の MV を1本、節ごとの画まで書く([一本通す](mv.md)、[もう4本](mv-more.md))
2. 手順が**書けない**所が差。書けたつもりで木に無い物も差
3. 既に出ている差なら**本数を1増やす**。無ければ行を足す
4. **新しい1本を書いて、新規の行が0だったら収束**

差は増え続けない。作り手が変われば要る物も変わるが、**同じ物が何度も出る**。
何本で要求されたかが、そのまま順番になる。

掴む所の必須要件は [掴む試験の必須要件](../gesture-tests.md) に、外の規格から採ってある。

## もう一つの物差し — 順序を書いたら欠陥

**説明書が「先に○○してから」と書いたら、それは窓の欠陥。**

手つきが書けないのは形の欠陥([空間](space.md)の話)。
手つきは書けるのに順序を指定しているのは、**時間の欠陥**。
利用者に「どちらを先にやったか」という見えない状態を持たせている。

ゲームは段を踏んで見せる。まだ要らない概念は世界に出さず、
要る時に一度だけ出す。出す前の段で勝手に引きずり込まない。

当てて出た物:

| 差 | 何が起きているか |
|---|---|
| **枠の外へ出る「許し」がトグル** | 行き過ぎる形を選ぶ前に許可を出す順序。形が枠を決めればよく、許しは要らない |

理想の段:

1. **キーが無い間** —— 掴めば位置が変わる。時間の話は世界に出てこない
2. **◇ を押した時** —— **今の時刻**に1つ目が立つ。ここで時間の世界が開く
3. **以降** —— 値を変えると、**その時刻**に打たれる。例外なし

1つ目を特別扱いする分岐が消えると、見えない状態も消える。

## 三つ目の物差し — 説明書だけ読んだ人に触らせる

理想の MV を書く方法は**書き手の想像が上限**になる。実際に窓を触らせると、
書いている時には気づかない所で止まる。**下の差は1つも上の数えに載っていなかった。**

説明書(このwikiだけ)を読んだ試し手に「最初の一本」を通させた(2026-09-01、3回)。
**三巡目で挙がった差は全て閉じた。次は四巡目で新規が何本出るかを見る。**

閉じた物:

| 差 | 何が起きていたか |
|---|---|
| ~~素材を入れる口が無い~~ | Media が空で、入れる手が窓のどこにも無い。説明書の一行目で止まる |
| ~~静止画が映らない~~ | 層は建ち、枠も動き、寸法も出るのに**絵だけ出ない**。操作ミスと区別が付かない |
| ~~出す口が無い~~ | 「最初の一本」なのに、一本が手元に残らない |
| ~~欄に文字が打てない~~ | 「double-click to type」と書いてあるのに打てない。名前も数値も1字も入らない |
| ~~窓と書き出しで絵が違う~~ | 間に合わない時に**古いコマを今のコマの顔で**返していた |

閉じた物(二巡目):

| 差 | 何が起きていたか |
|---|---|
| ~~置いた素材が真ん中に立たない~~ | 左上 0,0 に実寸のまま。**座標の指定なしに生まれた物は無条件で中央**(裁定) |
| ~~形の棚に名前が無い~~ | 説明書は「弾性」と名前で指すのに、棚は絵が8つ。指している間だけ名前を返す |
| ~~再生中に時刻が止まる~~ | 読むだけで**描き直す合図を購読していなかった** |
| ~~60秒の尺で0.6秒は5画素~~ | 拡縮は在ったが Ctrl に隠れ、向きも逆。目盛の帯では素のホイールで広がる |
| ~~選んだ層に枠が出ない・掴めない~~ | 静止画の道が素材の素性を棚へ置かず、寸法が出ないので枠も当たり判定も無かった |
| ~~掴んでも動かず巨大化する~~ | 取っ手の許容が箱より広く、**動かす手が1画素も残らない**(画面6.6pxの層に許容72) |
| ~~白紙から始められない~~ | 仕舞う機械は在り、`File` に New/Open/Save が無いだけだった |
| ~~ホイールが逆~~ | 上で縮小していた。上で拡大へ |
| ~~名前に `.mp4` が二重に付く~~ | 打った名前に既に付いていたら足さない |
| ~~出しても何も返ってこない~~ | 報せが Output パネルの中だけで、Stage を見ている人には無いのと同じだった |

## 数えた結果(6本)

`6/6` は全ての作り手が要求した物。`1/6` はその1本の味。

### 駆動 — 値を決める物(口が無い)

| 本 | 差 |
|---|---|
| **6/6** | **音が見えない。** Timeline に波形が出ない。どこがサビか目で分からない |
| **5/6** | **拍が無い。** BPM も拍の線も無く、帯もキーも吸い付かない |
| **5/6** | **複製に番号が配れない。** 紙片20枚・文字1字ずつ・粒子数千を、別々の値で散らせない |
| 2/6 | 種を振り直して、散り方だけ変えられない |
| 1/6 | 音量・音高が値を動かさない |
| 1/6 | カメラからの距離が値を動かさない(輪郭線の太さ) |
| **2/6** | **映像の中の動く物を追えない**(追従の帯が無い) |
| — | **効き具合を場所で変えられない**(強い所と弱い所)。帯の効きが取っ手1つしかない |

### 鏡(Stage)

| 本 | 差 |
|---|---|
| — | 主でない選択の枠が細く(1px)、似た色の層の上ではほとんど見えない。選ばれている事が分からない |
| — | 層が画面の端に居ると、奥行きの柄がパネルの外へ出て掴めない(箱が小さい時、中心から24px 離れた点は外) |

### 素材と効果 — 口が在るので並列(Vism 候補)

文字・生成パターン・粒子・線の伸び(TRIM)・反転・ぼかし・トゥーン・集中線・
色の一括差し替え・マスク。**これらは書く物ではなく置く物。**
ISF/GLSL は既に読める(`effects/isf/`、naga glsl-in)。W3C の17モードは依存ツリーの中。
1つ置くたびに順番の話にせず、**Vism 候補としてまとめて並列で足す**。

例外が1つ。**フィードバック(前のコマを取り込む)は上流を借りて終わらない。**
ISF の `PERSISTENT` は今のコードが意図して拒否している — 任意の時刻へ飛べる編集ソフトで
前フレームを持ち越すと、同じ時刻が毎回違う絵になる。ここは Motolii が意味を決める。

| 本 | 差 |

| — | **前後のコマを薄く重ねて見られない**(見る側だけの話。作品は変わらない) |
| — | 歌詞をまとめて入れて時刻に割り付けられない。1文字ずつ手で置くしかない |
| — | 波形を見ながら叩いてタイミングを置けない |

| — | 映像の中の動く物を追えない(追従の帯が無い) |
| — | 鍵で背景を抜くエフェクトが無い |
| — | 1つの作品の中に案を複数持って切り替えられない |
| — | 繋げて増やせない(複製が常に切れている。番号も付かない) |

## 読み取れたこと

**上位3つは全部「駆動」。1本しか要求していない物は全部「効果」か「素材」。**
本数の順と、口の有無が一致した。

**6本目(縦の30秒・実写)で、新規の差は1本だけだった**(セーフエリア)。
実写・縦・短尺という当てていなかった3軸を同時に入れても新規が1本なら、**収束に近い**。
6本目が使った物のうち5つ —— グループ、通過、繋がった複製、追従の帯、案 —— は
すべて同じ日に決めた形で、**手順に順序の指定が1つも出なかった**。

- 効果と素材は**口が在るので並列で一気に足せる**。1本しか要求していない物でも、
  足すのは安い
- 駆動は**口が無いので直列**。ここだけが順番を決める
