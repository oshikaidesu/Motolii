# 窓 — パネルと置き場

置き場は4つ(左・中・右・下)。**タブを掴んで別の置き場へ落とせば移る。**
窓の外へ引き出せば別窓になり、閉じれば戻る。View から出し入れ。

配置は次に開いた時も残る。

| パネル | 役目 |
|---|---|
| **Media** | 素材 |
| **Effects** | 効果 |
| **Create** | 新しい層 |
| **Colors** | この作品で使われている色 |
| **Stage** | 世界。掴んで動かす。書き出しの枠と、枠の外も見える |
| **Output** | **出る絵だけ**。書き出しのカメラが撮った物を、そのまま映す |
| **Timeline** | 時間。並べる・切る・キーを打つ |
| **Inspector** | 選んだ層の値 |
| **Utility** | 値ではない道具 — 寄せる・並べる・写す |
| **Ease** | 区間のイージング |

Stage の下帯に、作品の大きさ・コマ数・長さが出る。

Stage で画面を動かしても **Output は変わらない**。枠を回した時に何が出るのかは、
Output で確かめる。Output は見るだけで、触っても何も起きない。

## 文字

窓に出る文字は英語。**値が意味を持つ物だけが文字**で、道具は形で見せる。
説明の要る絵は、それが説明の要る道具だという印。
