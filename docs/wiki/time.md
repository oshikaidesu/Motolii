# 時間 — 並べる・キー・区間

Timeline は層の帯が並ぶ場所。帯の中を掴めば動き、端を掴めば伸び縮みする。
近くの端と再生位置に吸い付く。

層名の左の ▸ で属性の行が開く。◇ を押すとその時刻にキーが立つ。
畳んだままでも、層の帯の上に小さな ◆ で全部のキーが見える。掴めばその時刻のキーがまとめて動く(AE と同じ)。

## キーを選ぶ

菱形をクリック。⌘ / ⇧ で足し引き。**何も無い所からドラッグで囲めば範囲で選べる。**
選んだキーはまとめて動く。

キーを2つ選ぶと、その間が**区間**になる。区間が Ease の対象。

## 区間のイージング

Ease は区間が**今持っている形**を盤に映す。掴めばその場で乗る。
押して確定する手順は無い。

棚に並ぶのは形そのもの — 直線・ベジェ・バウンス・弾性・周期・乱れ・段・弾む段。
名前ではなく曲線の絵で選ぶ。

盤には再生位置の線と点が乗る。今どこを見ているかが、盤の上でも分かる。

小さい道具は**写す** —— 掴んだ形を、他の区間へ貼る。

行き過ぎて戻る形を選ぶと、**盤がその分だけ広がる**。
許しを出す手順は無い。形が枠を決める。

## 打鍵

| 打鍵 | する事 |
|---|---|
| `Space` | 再生 / 止める |
| `←` `→` | 1コマ(⇧で10コマ) |
| `Home` `End` | 頭 / 尻 |
| `⌘K` | 再生位置で切る |
| `[` `]` | 層の頭 / 尻を再生位置へ |
| `⌥[` `⌥]` | 再生位置で切り落とす |
| `⌘[` `⌘]` | 重ね順を下げる / 上げる |
| `↑` `↓` | 選択を上下の層へ |
| `U` | キーを持つ属性だけに絞る |
| `*` | 再生位置にマーカーを打つ / 外す |
| `⌘←` `⌘→` | 前 / 次のマーカーへ |
| `⌘A` / `Esc` | 全選択 / 選択を解く |
| `⌘D` | 選んだ層をそのまま増やす |
| `Delete` | 層を消す |
| `⌘Z` / `⌘⇧Z` | 戻す / やり直す |
| `F9` / `⇧F9` / `⌘⇧F9` | 選んだ区間を寝かせる(両側 / 入り / 出) |
