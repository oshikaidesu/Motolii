# 覚える言葉

Motolii が持つのはこの5つだけ。増えない。

| 言葉 | 何か |
|---|---|
| **層(layer)** | 空間に置かれた1つ。素材・文字・形・立体のどれか |
| **属性(property)** | 層の値。位置・拡縮・回転・不透明度・アンカー |
| **キー** | ある時刻の値。2つ並ぶと間が動く |
| **エフェクト(Vism)** | 層の絵に掛ける計算。パラメータは属性と同じに扱える |
| **合成(blend)** | 下の絵とどう混ぜるか |

層は時間の上に置かれ、空間に居る。この2つは同じ物の2つの面で、別の設定ではない。
