# 最初の一本

Motolii で作品を1本作る間に触る物は、順に5つだけ。

## 1. 素材を入れる

映像・音・画像・立体を Media へ落とす。クリックすれば層になって、空間に置かれる。

## 2. 並べる

Timeline で帯を掴んで動かし、端を掴んで伸び縮みさせる。
`⌘K` で再生位置を切る。`[` `]` で頭と尻を再生位置へ寄せる。
端どうしと再生位置に吸い付くので、隙間は空かない。

## 3. 動かす

Stage で層を掴む。動かした場所・大きさ・向きは、その時刻の値になる。
Inspector の ◇ を押すとその時刻にキーが立ち、2つ並べば間が動く。

## 4. 整える

キーを2つ選ぶと区間になる。Ease で区間の形を選べば、動きの表情が決まる。
Effects で層に計算を掛ける。効果のパラメータもただの値なので、同じようにキーが打てる。

## 5. 出す

破線の枠が書き出される範囲。枠の中身がそのまま出る絵で、
あなたがどこから覗いていたかは結果に入らない。

書き出す時、空間は1枚に畳まれる。**畳まれるのはこの時だけ。**
作品の中の物は最後まで空間に居る。
