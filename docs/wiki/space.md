# 空間 — 置く・掴む・覗く

素材を Stage へ落とすと、そこに**居る**。板の絵も、立体も、点群も、同じ一つの空間に。
「これは 2D の層」「これは 3D の層」という区別は無い。

## 掴む

層を掴むと取っ手が出る。**取っ手は全部いつでも出ている。**

| 掴む所 | 起きる事 |
|---|---|
| 中 | 平面に沿って動く |
| 四隅 | 縦横まとめて拡縮 |
| 辺 | その向きだけ拡縮 |
| 枠の外 | 画面に対して回す |
| 輪 | その軸で回す |
| 奥行きの点 | 手前・奥へ動く |

先にモードを選ぶ操作は無い。奥へ動かしたければ奥行きの点を掴む。それだけ。

軸を1つに固定したい時だけ、掴んでいる間に `X` `Y` `Z` を押す。
これはモードではなく、**掴んでいる間だけの制約**で、離せば消える。

## 覗く

画面を掴んで動かすのは**あなたの視点**で、作品には入らない。
書き出される絵は**破線の枠**が示す。枠を掴めば書き出しのカメラが動く。

視点と書き出しは常に別。覗き込みすぎて作品が変わることは無い。
書き出しの枠へ視点を戻す一手がある。

## 畳む

空間に居る物を1枚の絵にしたい時は、層に **flatten** を付ける。
畳んだ結果はその層の絵になり、以降は板として扱われる。
畳むかどうかは**あなたが決める**。勝手には畳まない。
