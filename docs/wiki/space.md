# 空間 — 置く・掴む・覗く

素材を Stage へ落とすと、そこに**居る**。板の絵も、立体も、点群も、同じ一つの空間に。
「これは 2D の層」「これは 3D の層」という区別は無い。

## 掴む

層を掴むと取っ手が出る。取っ手は全部いつでも出ている。先に道具を選ぶ操作は無い。

**真ん中を掴んで引っぱる**……掴んだ所が指について来ます。引いた分だけ動きます。

**四隅の四角を掴む**……角が指について来て、縦横まとめて大きさが変わります。
(⇧を押しながらだと縦横の比が崩れず、⌥を押しながらだと真ん中が動きません。)

**辺の四角を掴む**……その向きだけ伸び縮みします。

**枠の少し外を掴んで回す**……画面に対して回ります。
(⇧を押しながらだと、角度が刻まれます。)

**箱の外に出ている横の輪を掴んで左右へ引く**……右へ引けば右を向きます。引くほど深く向きます。
**箱の外に出ている縦の輪を掴んで上下へ引く**……前後に倒れます。

※ 輪は**箱の外**にあります。**箱の中はいつでも「動かす」**で、輪や点に取られません。

**真ん中から斜めに伸びた柄の先の点を掴んで上下に引く**……手前と奥へ動きます。
奥へ行くほど小さく、手前に来るほど大きく見えます。
柄は真ん中から離してあります —— 真ん中は動かすための場所なので。

※ 奥へ下げすぎると、書き出しの枠から消えます。破線の外に出た物は絵に映りません。
**外へ出た物は薄い形で見えます** —— 消えたのか、外に居るのかが分かります。

輪と点が邪魔な時は、Stage の下帯の切り替えで隠せます。
隠れている間も掴んだ所の意味は変わりません。出ている取っ手が減るだけです。

軸を1つに固定したい時だけ、掴んでいる間に `X` `Y` `Z` を押す。
これはモードではなく、掴んでいる間だけの制約で、離せば消える。

## 覗く

画面を掴んで動かすのは**あなたの視点**で、作品には入らない。
書き出される絵は**破線の枠**が示す。枠を掴めば書き出しのカメラが動く。

ホイールで寄る時、**指の下は動きません**。見たい所に指を置いて回せば、そこが中心になります。

視点と書き出しは常に別。覗き込みすぎて作品が変わることは無い。
書き出しの枠へ視点を戻す一手がある。

## 畳む

空間に居る物を1枚の絵にしたい時は、層に **flatten** を付ける。
畳んだ結果はその層の絵になり、以降は板として扱われる。
畳むかどうかは**あなたが決める**。勝手には畳まない。
