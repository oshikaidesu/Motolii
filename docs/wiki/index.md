# Motolii

映像に動きと効果を付けるソフト。素材を**空間**に置き、**時間**の上に並べ、
値に**キー**を打つ。それだけで作品ができる。

同じ仕事をする道具は他にもあるが、Motolii は物を平面に畳まない。
立体も点群も板も、最後まで一つの空間に居る。畳むのは書き出す時だけ。

初めてなら [最初の一本](start.md) から。

---

この説明書は**完成した Motolii** を書いている。窓に届いていない所は [gap](gap.md) に。

## 軸

1. **一つの空間に、全部が居る。**
   板も立体も点群も、別の世界ではない。畳むのは書き出す時と、あなたが畳めと言った時だけ。
2. **掴めば動く。** 何を掴んだかが、何が起きるかを決める。
   触る前に道具やモードを選ばない。世界を二分する札は置かない。
3. **見る事と、出す事は別。** どこから覗いても作品は変わらない。
4. **文字は、値が意味の時だけ。** 残りは形で見せる。文字は英語。
5. **一手ずつ戻せる。** 変更は全て意味を持つ一手で、順に解ける。
