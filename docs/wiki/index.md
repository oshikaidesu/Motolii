# Motolii

ロゴを右から滑り込ませる。写真を奥へ倒して並べる。撮った映像に光をにじませる。
**映像に動きをつけるソフト。**

層は平面に並ぶだけではない。板も、立体も、点群も、同じ空間に立ったまま置かれる。
奥へ下げれば小さくなり、回せば向こうを向く。畳まれるのは書き出す一瞬だけ。

初めてなら [最初の一本](start.md) から。ロゴを1つ動かすだけで、全部出てくる。

## 軸

1. **一つの空間に、全部が居る。**
   板も立体も点群も、別の世界ではない。畳むのは書き出す時と、あなたが畳めと言った時だけ。
2. **掴めば動く。** 何を掴んだかが、何が起きるかを決める。
   触る前に道具やモードを選ばない。世界を二分する札は置かない。
3. **見る事と、出す事は別。** どこから覗いても作品は変わらない。
4. **文字は、値が意味の時だけ。** 残りは形で見せる。文字は英語。
5. **一手ずつ戻せる。** 変更は全て意味を持つ一手で、順に解ける。
