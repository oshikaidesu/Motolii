# Security

Motolii is pre-release software that runs on your own Mac. If you find a security problem (for example a document, effect or script file that can run code it should not), please report it privately: open the repository's **Security** tab and choose **Report a vulnerability** (GitHub's private vulnerability reporting). Please do not open a public issue for it.

脆弱性（書類・効果・スクリプトのファイルが、してはいけない事をできてしまう、など）を見つけたら、公開の Issue ではなく、リポジトリの **Security** タブの **Report a vulnerability** から知らせてください。
