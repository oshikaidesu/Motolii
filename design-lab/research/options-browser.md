# Browser 側: 価値の高い 10 問題と、操作モデルの違う案

2026-10-02。調査のみ。問題 ID は problems.md。**案は見た目でなく操作モデルが違う**。見た目は DESIGN.md の現行(灰・1px・記号少なめ)のまま。
各案の書式: **機構** 一行 / **契約** 検査できる 1 行 / **静止時に隠す物** / **最頻の手数** / **レンズ**(有利 ▲ 不利 ▼)/ **出所** / **Widgetbook 試作** = 既存部品で作る最小の対話版。
`[新]` = 出荷されている道具に無い組合せ(先例で確かめられない分、試作で最初に手で触って判定する)。
判断の基準(利用者の方針): (1) 実制作での便利さ・速さ・手触り、(2) 実際の制作ワークフロー、(3) 良い先例、(4) Motolii 内の一貫。**実装の重さで案を選ばない・並べない**。過去の Motolii の契約(「書かない」「Esc は送らない」等)は制約として使わない。各案の末尾の「判断」節で、先例とワークフローから自分で決めた。
既存部品の呼び名: `media_set`(tile/grid/list/tree/_DragScene/import zone)、`BrowserPanel`(parts/browser.dart)、Command palette(`navigation_parts`)、`TextBox`・Curve picker(`inputs`)、`Segmented`・`PillSwitch`・`ValueWell`(parts/controls)、`Session`(book/lib/session.dart、W 3 節)。

**手癖の台帳**(案を「手癖のまま / 手癖への追加 / 手癖から外れる / 取り下げ」に分けた表)は experience-first.md §C。改訂方針: 手癖(AE/Ableton/Blender/Figma)を既定にし、分割は壊さない。I3-d・I4-c・I8-b は取り下げ(境界を壊すだけが取り柄)。

## 選んだ 10 問題とその理由
| 問題 | 選んだ理由(証拠 + 制作での価値) |
|---|---|
| B3 探す | 4 文書に出る。名前を知らない effect を探すのは motion の日課。先例(Tab・palette)が揃い、案の分岐が大きい |
| B2+B4 絞る・今絞っているか | 過去の最大の失敗(組合せ不能・合算表示無し)。Ableton が答えを出しているが、小さな panel 向けの形は未決 |
| B5+B6 見てから使う(動きの試写) | 「見た目が名前」の制作物。自分のコマで見られるかが分かれ目。先例が割れる |
| B9 差し替えて試す | 「look を試す」の核。映像/motion では先例が無い(Ableton は音)。価値が最も高い未解決 |
| B8 落とした時の置換/追加 | 先例が割れる(AE: Alt=置換、Premiere: 既定=上書き)。制作で毎回起きる。D-2 で決めた |
| B7 使う動作の一貫 | 過去に同じ gesture が棚で 2 意味になった。契約を 1 行で言えるかが評価できる |
| B10 お気に入り・最近 | 長時間作業の速さに直結。Ableton の 1-7/0 を写し損ねた(速い所が抜けた) |
| B11 自分の物を棚へ | 制作者が一番欲しがる(Layer Library・Flow・Animation Composer が全部この穴を埋めた) |
| B12 大量ライブラリ | 「素材が多い」利用者向け。「似た物」は先例が少ない |
| B13 選択で絞る(使えない物) | 初心者の迷いを最も減らす。過去は「淡色のまま押せる」で失敗 |
外した問題: B1(置き場)は Ableton が確立、B2 の中で扱った。B14 取り込みは良好な既存が多く、案の分岐が小さい。B15 狭い dock は全案に共通する審査項目として各案末の「レンズ」に L11 で入れた。B6 は B5 に統合。

## B3. 名前を知らずに探す

**案 B3-a「常設の検索欄」** 機構: panel 上端に常に開いた 1 つの欄。打つたびに結果が更新。
契約: 欄は常に見える/ 1 文字ごとに更新/ 複数語は AND/ Esc 一回目で文字を消し、二回目で欄を離れる。
隠す物: 無し(欄自体が静止時に出る)。 手数: 打つ(クリック不要。`/` で焦点)。
レンズ: ▲L1 L9 L10 ▼L11(狭い panel で縦を食う)。 出所: Ableton quick search、IO B2(Esc 規則)、BF §4.1。
試作: `BrowserPanel` の上に `TextBox` を常設。10 件の effect/preset 名で live filter、Esc 二段。

**案 B3-b「type-ahead の作成メニュー(Tab 型)」** 機構: 任意の場所で Tab/ダブルクリック → カーソルの位置に小さな検索メニューが出て、Enter で選択 layer に適用。同じキー再押下で family を巡る。
契約: メニュー表示中 Enter = 先頭候補を選択対象へ適用/ Esc で何も書かず閉じる/ 最後に使った物が空入力時の先頭。
隠す物: Browser panel 自体を開かなくてよい(静止時は何も出ない)。 手数: Tab・数文字・Enter(3 手)。
レンズ: ▲L10 L9(熟練)L11 ▼L2(試写が弱い)L9(初心者は存在を知らない)。 出所: Houdini Tab menu、TouchDesigner OP Create(IS A6)。
試作: Command palette(`navigation_parts`)を Tab 起動に付け替え、候補に effect 名と family 名を入れる。

**案 B3-c「前置き文字で領域を切替」** 機構: 1 本の欄で `#` タグ、`>` 動作、`@` layer と、先頭 1 文字で検索の領域が変わる。
契約: 先頭記号が変わると結果の見出しが変わる/ 記号を打たなければ全領域を見出し別に並べる。
隠す物: 記号の存在(欄の下に、現在の領域名を 1 語)。 手数: 欄で 1 文字余計に打つ。
レンズ: ▲L1 L10(熟) ▼L9(発見されにくい)。 出所: VS Code / Raycast / Notion(IS A7)、Ableton `#tag`(BF §3.3)。
試作: `TextBox` + 3 種の見出し付き結果。記号を消すと全領域表示に戻る。

**案 B3-d「頻度順の空入力」[新]** 機構: 空欄の時は、そのプロジェクトで最近使った物と、今の選択に効く物を先頭に並べる(打つ前から答えが並ぶ)。
契約: 空入力時の並びは「最近使った → 選択に効く → 他」/ 一文字打つと通常検索に切り替わる。
隠す物: 全一覧(スクロールで出る)。 手数: 0(開くだけで候補)。
レンズ: ▲L10 L9 L1 ▼L8(並びの理由が見えにくい)。 出所: palette の frecency(IS A7)+ Houdini の選択による絞り(IS A6)を合わせたもの。出荷物に組合せ無し。
試作: B3-b のメニューに `Session.selected` が layer の時だけ「効く」の見出しを足す。

## B2+B4. 記述で絞る・今絞っているか分かる

**案 B2-a「タグ群の帯(Ableton 型)」** 機構: 群(種類・性格など)ごとに tag の列。普通のクリック=その tag だけ、Cmd+クリック=同群で追加。群をまたぐと AND。結果帯に「N 件絞り中 / Clear」。
契約: 群をまたぐ絞りは常に狭まる(広がらない)/ 結果帯の件数 = 有効な絞りの数/ Clear 一手で絞りと検索文字が全て消える。
隠す物: 使っていない群は 1 行に畳む。 手数: 1 クリック/絞り。
レンズ: ▲L8 L4 L9 ▼L11(狭い panel で群が積もる)。 出所: Ableton Live 12(BF §3.1-3.4)。
試作: `BrowserPanel` にタグ群 3 つ+結果帯。tile 40 個にタグを付けた mock で AND を確かめる。

**案 B2-b「文は chip に変わる」** 機構: 検索欄に `kind:image` のように打つと、それが欄の中で chip になる(見える)。chip は x で消せる。chip が絞りの全て。
契約: 絞りは全て欄の中の chip として見える/ chip 数 = 絞りの数/ chip を全部消すと素の一覧。
隠す物: 帯・群が不要(欄だけ)。 手数: 打つ。
レンズ: ▲L11 L10(熟)L8 ▼L9(打てない初心者)。 出所: 過去の Motolii の `kind:/tag:` 構文(IO B2)の「不可視」を chip で解く。Gmail 検索 chip と同系 [inferred]。
試作: `TextBox` の中に chip を並べる。`kind:` `tag:` を打つと chip 化、x で消去。

**案 B2-c「現在の絞りを文章で言う」[新]** 機構: 結果の見出しが「Blur・動画・お気に入りの 14 件」のように今の絞りを一文で言い、語をクリックするとその絞りが外れる。
契約: 見出し文は有効な全ての絞りを言う/ 語クリック = その絞りだけ解除/ 絞り 0 のとき「全部の 240 件」。
隠す物: 群・chip・帯を全部持たない(見出しだけ)。 手数: 外すのが 1 クリック。
レンズ: ▲L8 L11 L9 ▼L10(足すのは別の入口が要る)。 出所: 出荷物に無い。自然文の見出し(Notion のクエリ見出しに近い [inferred])。
試作: 見出し 1 行と tile 一覧。絞りは別途 Segmented で足し、見出しが文になるだけ。

**案 B2-d「保存した絞り=置き場」** 機構: 今の絞りを名前を付けて左の置き場に保存。以後は新しく入る物にも自動で効く。
契約: 保存した絞りは置き場一覧に出る/ 条件に合う新しい物が自動で入る/ 削除しても素材は消えない。
隠す物: 置き場が増えるほど見える(畳める)。 手数: 保存 2 手、使用 1 手。
レンズ: ▲L4 L10(長時間)▼L11(置き場が増える)。 出所: Resolve Smart Bins、Ableton の保存 search(BF §4.3)。
試作: B2-a の絞り状態を `Session` 外の小さな List に保存し、左の `media_set` tree に差し込む。

## B5+B6. 付ける前に見る(動きの試写)

**案 B5-a「tile = 常に動く小さな試写」** 機構: tile 自体が自分のコマで(無ければサンプルで)小さく繰り返し動く。
契約: tile は画面に見えている間だけ動く/ 動きの周期は全 tile 同じ/ reduce-motion では最初のコマで止まる。
隠す物: 無し。 手数: 0。
レンズ: ▲L2 L9 ▼L11(数千 tile が一斉に動くと視線が散る)L10(落ち着かない)。 出所: Animation Composer の動画 preview(IE §2)、IO B4(固定サンプル)。
試作: 6 個の tile が `Ticker` で 1 周 1.2 秒。見えない tile は止める。

**案 B5-b「hover で動き出す」** 機構: pointer が tile に乗ると、その tile だけ動く。左から右へ動かすと中身を scrub する(動画・長い preset)。離れると 1 コマ目に戻る。
契約: hover 中だけ動く/ 離すと必ず最初の絵に戻る/ 観察だけで状態は変わらない(棚を流し見する間に履歴を汚さない為)。
隠す物: 静止時は 1 枚の絵。 手数: 0(乗せるだけ)。
レンズ: ▲L2 L11 L10 ▼L9(触れないと分からない)。 出所: Resolve / Premiere の hover scrub(BF §7.2)、Animation Composer。
試作: `media_set` の tile に `MouseRegion`。x 位置を 0-1 の位置へ写して mock の curve を描く。

**案 B5-c「自分のコマで試写(Stage に重ねる)」** [新] 機構: tile に乗せる/矢印で選ぶと、**選択 layer に一時的にその effect を重ねて** Stage に見せる。離す/Esc で消える。何も書かない。
契約: 20 個試しても確定までは履歴が 1 行も増えない(試すのが速くなる為)/ 離す・Esc・panel を出ると元の見た目に戻る/ 決定(click/Enter)で 1 手の書込。
隠す物: 静止時は通常の tile。 手数: 0 で試写、1 で確定。
レンズ: ▲L2 L12 L8 X2 ▼L9(「まだ確定していない」を見た目で分けないと誤解される)。 出所: Ableton Hot-Swap の発想(BF §8.3)+ Blender Ease の modal 預覧(P9)。**映像で自分のコマに一時重ねは出荷物に無い**。
試作: `Session` の layer の `fx` に `preview` 一時値を持たせ、`stage_set` が描く。離したら null。

**案 B5-d「大きな試写面(preview 面)」** 機構: panel 内の固定の大きな面に、選んだ物を自分のコマで映す。上下矢印で step。Space で再生。
契約: 面は選択を変えただけで更新(押す・書く操作無し)/ 面を閉じたら何も残らない。
隠す物: 面は開いている時だけ panel 高を食う。 手数: 選ぶだけ。
レンズ: ▲L2 L12 ▼L11 L10(面が場所を食う)。 出所: Ableton Preview タブ、過去の preview panel(BF §7.1)。
試作: `media_set` の `_DragScene` の面を流用して 1 枚大きく。

## B9. いま付いている物を差し替えて試す(Hot-Swap)

**案 B9-a「リンクモード(Q 型)」** 機構: Q で Browser を選択中の effect/preset に結ぶ。↑↓ で候補を進めると、結んだ先がその場で入れ替わる。Enter で確定、Esc/Q で解く。
契約: 結んでいる間、候補を進めるたびに結び先が 1 つ置き換わる/ Esc でリンク前の状態に戻る/ 確定までの経過は undo 履歴に 1 つにまとまる。
隠す物: モードの存在(結んでいる間だけ Browser 枠が静かに変わる)。 手数: Q・↑↓・Enter。
レンズ: ▲L3 L2 L9(熟) ▼L9(初心者が見つけにくい)。 出所: Ableton Hot-Swap(BF §8.3)。映像/effect での先例は無い。
試作: `BrowserPanel` と `inspector_parts` の `Doc.effects` を結ぶ。Q で結び、↑↓ で `Doc.effects[i]` を置換、Esc で snapshot に戻す。

**案 B9-b「ドロップは常に置換(Alt で追加)」** 機構: tile を Inspector の effect カードに落とすと置換(元の値を持ち越す)。Alt で追加。
契約: カードへ落とす=置換、旧 effect の同名 parameter 値は持ち越す/ Alt で新しいカード/ Esc で落とす前に戻る。
隠す物: 無し。 手数: drag 1。
レンズ: ▲L3 L10 ▼L2(試写が無い)L8。 出所: AE Alt=replace、Figma Alt-drag swap(P6、IS A3)。
試作: `_DragScene` の tile を Inspector の card slot に落とす実 `Draggable`/`DragTarget`。

**案 B9-c「effect カードの header に ↑↓」** 機構: 付いている effect カード自体に「同じ family の次/前」を送るキー(or ホイール)。Browser を見ずに隣の候補へ。
契約: カード上で ↑↓ = 同 family の次/前に置換/ 値は持ち越す(host が決める)/ 1 回=1 undo。
隠す物: Browser 要らず。 手数: 1 キー/候補。
レンズ: ▲L10 L11 ▼L2 L9(候補の全体像が見えない)。 出所: 出荷物には無い(Ableton の Hot-Swap の Browser 側を落とした簡易形)[新]。
試作: `inspector_parts` の card に ↑↓ の `onKey`。family 配列を巡る。

**案 B9-d「A/B の二枠」** [新] 機構: 今の effect と候補を横並びの 2 枠として Stage 分割で見る(左=今、右=候補)。気に入れば右を確定。
契約: 分割は一時で何も書かない/ 確定で 1 書込/ 取消で分割ごと閉じる。
隠す物: 通常は 1 枠。 手数: 候補を選ぶ → 分割が出る。
レンズ: ▲L2 L12 L8 ▼L10(場所を食う)。 出所: 出荷物に無し(Resolve の A/B 比較に近い [inferred])。
試作: `stage_set` を 2 枠にして、片側だけ `Session.preview` を適用。

## B8. 既にある物の上に落とした時: 置換か追加か

**案 B8-a「上に落とす=追加、Alt=置換」(Premiere/AE 慣習のまま)** 機構: 既存の layer の上でも既定は追加。
契約: 落とす先に関わらず新しい物が増える/ Alt で置換(bar・key は残す)/ Esc で何も残らない。
隠す物: 置換の存在(Alt)。 手数: 追加 1、置換 1+Alt。
レンズ: ▲L10 L9(予想が付く)▼L5(置換は隠れた力)。 出所: AE Alt=replace(P6、W6)。
試作: `_DragScene` を実 drop に。落とし先 3 種(Stage 空き・layer 上・Timeline 行)で挙動を切替。

**案 B8-b「上に落とす=置換、Alt=追加」** 機構: 既存 layer 上は既定が置換。空き地は常に新規。
契約: layer 上への drop = 絵の差替(bar・key・effect は残る)/ Alt = 追加/ 空き地 = 新規。
隠す物: 追加の存在。 手数: 置換 1。
レンズ: ▲L3 L10 ▼L9(初心者が意図せず上書き)L8。 出所: Ableton(preset 上に落とすと置換)(P6)、P6 候補 A。
試作: B8-a と同じ scene に挙動を knob で切替(置換既定 / 追加既定)。

**案 B8-c「置換は Inspector の別動作、落とすのは空き地だけ」** 機構: layer の上には落とせない(受け付けない)。置換は Inspector の素材欄に落とす/押す。
契約: layer 本体は drop を受けない(理由を言葉で出す)/ Inspector の素材欄が唯一の置換口。
隠す物: 修飾キー不要。 手数: 置換 2。
レンズ: ▲L8 L9 X6 ▼L10。 出所: P6 候補 C(Blender の link/append を前もって決める発想)。
試作: drop target を空き地と素材欄の 2 つに限る。layer 上では「ここには落とせません」を出す。

**案 B8-d「落とす直前に両方を見せる」** [新] 機構: layer 上で hover が止まると、ghost の脇に「置換 / 追加」の 2 面が出て、どちらに落とすかを選ぶ。
契約: hover 1 秒で 2 面が出る/ 面の上で離した方が実行/ 面の外で離す=取消。
隠す物: 通常の drag は無装飾。 手数: drag + 微移動。
レンズ: ▲L9 L8 ▼L10(間が一拍)。 出所: 出荷物に無い(drop 先の複数面は Finder の spring-loaded に近い [inferred])。
試作: `_DragScene` に落とし先で 2 面を出す。

## B7. 使う動作(click / dbl-click / Enter / drag)の一貫

**案 B7-a「選ぶ=click、使う=dbl-click/Enter、置く=drag」(全棚で同一)** 機構: Ableton と同じ。
契約: 単クリックは何も書かない(選択+任意で試写)/ dbl-click か Enter で選択対象へ使う/ 全棚で同じ。
隠す物: 無し。 手数: 使う 2。
レンズ: ▲L9 L8 ▼L10(1 手多い)。 出所: BF §8.2、Ableton。
試作: `media_set` と effect tile の両方に同じ `Hit` 規則。

**案 B7-b「単クリック=使う」(effect 系だけ)、media は選ぶ** 機構: 棚ごとに意味が違う(過去の Motolii)。
契約: 反例として置く(契約が 1 行で言えない)。
レンズ: ▼L9 L8。 出所: IO B5 の失敗。比較用に作ると違和感が測れる。
試作: 2 棚で意味を変えた mock(反例)。

**案 B7-c「単クリック=使う、Undo が 1 手」** 機構: 全棚で単クリックが使う。結果が見えて、Cmd-Z で 1 手戻る。
契約: 単クリック = 選択対象へ適用/ 適用後 1 回の undo で元に戻る/ 選択対象が無ければ「何に?」を出して書かない。
隠す物: 無し。 手数: 使う 1。
レンズ: ▲L10 L3 ▼L8 L9(誤爆)L2。 出所: Procreate の adjust 的な即時適用 [inferred]、過去の effect 棚の単クリック。
試作: tile クリックで `Doc.effects` に追加、undo 1 手。

## 判断(先例・ワークフローから自分で決めた。理由つき)

| # | 問い | 決めた事 | 理由 |
|---|---|---|---|
| D-1 | 試す時に書くか(覗き) | **試写は一時で、確定まで履歴に残さない。** 棚の上の hover は tile の中だけで動かす。Stage への一時重ねは「矢印で候補を進める/ Hot-Swap の間」だけにする(B5-c + B9-a)。pointer が棚を横切るだけで Stage がちらつくのを避ける為 | 実制作では候補を 10-20 個連続で見る。確定の度に履歴が増えると戻る手が増える。先例も同じ向き: Blender は modal 操作を Esc で元に戻し(P9)、Ableton は Hot-Swap を Esc で解く(BF §8.3)。過去 Motolii の契約だからではなく、この速さの為 |
| D-2 | 既存 layer への drop | **既定は追加、Alt で置換(B8-a)。落とす前に、いまどちらになるかを outline で見せる**(Alt を押す/離すで即時に変わる) | 制作で素材を落とすのは大半が「足す」操作。置換は少なく、effect の差し替えは Hot-Swap(B9)が主経路になる。先例: AE の project→comp は追加、Alt=置換(P6)。Motolii は sequence でなく layer 合成なので AE に近い。Premiere の overwrite 既定は時間位置が意味を持つ場合の都合 |
| D-3 | 単クリックの意味 | **全棚で単クリック=選ぶ+試写、dbl-click/Enter=使う、drag=置く(B7-a)** | 棚の中で連続して見るのが第一動作。誤爆を避けられ、Ableton/Premiere/Resolve が同じ。同じ gesture が棚で 2 意味になる事(B7-b)は一貫(基準 4)に反する |
| D-4 | 検索の範囲 | **検索は全置き場にまたがり、結果に置き場名を付ける。置き場を選ぶとそれが AND の絞りの 1 つ(chip)になる。検索語は置き場を変えても保つ** | 「どこにあったか」を覚えていない時が探す時。Premiere は bin 内を閉じていても検索(BF §4.2)。B2-b の chip と一貫 |
| D-5 | 「最近」 | **effect/preset は利用者単位(プロジェクトをまたぐ)、media はプロジェクト単位** | 手癖の effect はプロジェクトに依らない。素材は案件に属する |
| D-6 | 同梱 preset の扱い | **適用すると instance になり、instance を触っても棚は変わらない。棚が変わるのは「棚へドロップ」(B11-a)の時だけ。同梱は上書き不可** | AE の preset は上書きできて事故になる。Procreate/Blender は複製が基本(IS A8, A2)。自動複製(B11-b)は棚が散らかるので採らない |
| D-7 | 保存物の置き場 | **利用者の共有棚が既定、「この案件だけ」を保存時に 1 語で選べる** | 自分の curve/preset は案件を越えて使う(Flow・Layer Library の使われ方)。案件固有の素材は別 |
| D-8 | 7 色 | **色は使わない。星 1 つ(F)+ 名前を持つ collection を数字キー(1-9)で。** | DESIGN §7「新機能の為に新しい色を足さない」と、色=relation 家族の一貫(基準 4)。Ableton の速さの核は数字キーで、色でない |
| D-9 | 自分のコマでの試写 | **必須。** 選択が無い時だけサンプル画に落とす。tile の静止画はサンプルで良い | 固定サンプルでは「自分の素材でどう見えるか」が分からないのが過去の指摘(IO B4)で、制作では決め手になる |
| D-10 | 検索欄 vs Tab 型 vs 前置き | **共存。** panel の常設欄(B3-a)+ 前置き `#`(B3-c)+ どこからでも出る Tab 型(B3-b)。空入力は「最近→選択に効く→他」(B3-d) | 3 者は到達の速さの層が違う(初心者・慣れ・熟練)。レンズ L9 で互いに競合しない |
| D-11 | 絞りの表現 | **タグ群の帯(B2-a)を既定とし、打った語は chip になる(B2-b)。結果の見出しは件数と Clear(B4)。B2-c の文章見出しは試作で比べる** | 初心者は見えている物を押す。熟練は打つ。両方が同じ状態(chip)を作ると一貫する |
