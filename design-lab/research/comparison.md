# Motolii (today) vs design lab: widget comparison

Date: 2026-10-02. Sources: the four Motolii inventories (`research/inventory/*.md`, worktree `/private/tmp/wt/tok`, `motolii/ui/lib`) against `research/lab-inventory.md` (126 use cases) and the lab code in `book/lib`.
Rule used: the lab is the canonical look; only Motolii's UX (interactions) is borrowed later. Entries the inventories mark absent / classic-only are OUT OF SCOPE and not listed (examples: File/Edit/View menu bar, Settings sheet, Work area / Loop range, Stage tool column, rulers/grid/safe area, Presets shelf, Files shelf, Graph panel body is a placeholder box). Status: HAVE = lab has the same widget; CLOSE = similar, differs in form/behaviour; MISSING = nothing in the lab; SKIP = not a visual widget.
Counts are of table rows (one row per user-visible widget; trivial sub-parts merged). Counts are generated by script from the tables (section 1).

Five biggest gaps (by amount of unbuilt Motolii UI):
1. Inspector instruments: Transform (gizmo pad, mode strip, anchor pad, rows with marks), Camera (face pad, 4 groups) and Layout (diagram pad, sizing chips) have no lab card; only the value wells exist.
2. Browser shelves: Create (25 marks), Effects (15 live effect faces), Colors (hue ring, gradients), Fonts and the full Media catalog (sources, sortable list, preview, Explore map) exist only as loose parts, not as panels with wide / narrow / strip layouts.
3. Desks: Ease, Depth, Blend, History, Notes, Relations (dot map + lasso) and Web are mostly MISSING or CLOSE (curve plot, depth diagram, 19 blend marks, rail history, notes canvas).
4. Popovers, dialogs and Console: Composition and Interface popovers, Console log, document guard flow, and the whole Docking behaviour (seat strips, drop targets, dividers).
5. Timeline layer chrome and Stage overlays: twirl / switches / group nesting / drop guide / ghost / waveform / end mark; camera gizmos, extent frame, observer mark, Stage bars.

## 4. Where the lab differs from Motolii in form

Structure
- Lab Inspector is ONE panel with a header and a tab row Transform / Relations / Effects / Material (use case "Relations tab" shows only that tab). Motolii's Inspector has NO tabs: one scrolling column (Transform instrument, optional Stage rows, optional Layout, effect cards, or Camera instrument) chosen by what is selected; Relations is a separate Desk panel.
- Lab Browser is ONE panel with pill tabs Objects / Relations / Effects / Media and sections Primitives / Generators / Relations (330 px). Motolii has five separate dock panels (Create, Effects, Colors, Fonts, Media; the in-panel tab strip is dormant) and no Relations shelf.
- Lab window is Browser | Stage | Inspector over Timeline with no docking. Motolii is a dock workspace: top Browser seat | Stage seat | Inspector, bottom Timeline seat | Desk seat; seats have tab strips, drag to split / join, detach, Reset Layout.
- Lab top bar is 48 px with menu bar / title bar variants; Motolii top bar is 32 px, no menu bar, folds below 1000 / 820 / 680 px.
- Lab Stage chrome has a vertical tool column; Motolii's Stage has no tool column (tools are P / R / S keys and gestures) and uses top / bottom bars (Front, Fit, 100%, zoom field; W x H, ground switch, Extend, Frame N).
- Lab Relations is a gadget wall + cards in the Inspector; Motolii Relations is a desk panel with a dot-map graph and lasso.

Lab-only (not in Motolii today; fine to keep)
- Transport: Transport cluster as designed unit, Menu bar, Window title bar, Camera view dropdown, Loop / range toggle, Master volume + meter, Zoom control as a standalone widget.
- Inputs: Slider with ticks (partly used), Range slider, Tag input, Checkbox / radio set, Dropdown as a bordered box (Motolii has it unused), Colour swatch + hex.
- Navigation: Breadcrumb, Tree view, Command palette, Sidebar nav item, Accordion group (Motolii has only fold rows), Popover with arrow.
- Timeline: Work area bar, Time zoom slider, Mini curve editor in the timeline, Scrub / transport strip, Property lane with value and step in the lane header.
- Relations: gadget art 15 (Falloff, Direction, Scatter, Region, Along Path, Stagger, Follow, Curve, Scale, Rotation, Color, Repeat, Noise, Graph / Link, Audio), Chip, Badge on layer row, Add relation menu, Flow.
- Feedback: Progress bar, Spinner, Status bar, Toast stack, Inline banner, Skeleton loader, Keyboard shortcut chip, Badge and change dot, Error row with Why?, Render queue row (Motolii has none of toast / banner / status bar; all messages go to the Console).
- Media: Folder tree, Preset row (Motolii has no Presets shelf), Colour palette strip, Asset details card as a card.
- Stage: Guides and rulers, Grid and safe area, Cursor tooltip, Minimap / navigator, Zoom HUD and corner label, Tool column, Tool options bar.
- The lab design knob "Look" (concept / quiet / glow) and timeline tuning knobs (row height, zebra, key edge, grid) are lab only.
