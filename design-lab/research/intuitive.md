# 直感性の判定 — Phenomenon A–E / World A–E(2026-10-02、独立判定)

物差し(所有者の定義): **直感的 = 絵が「制作中にその値を触る理由」(画面で何を得たいか)と一致している**。値そのものがうまく抽象化されているかは問わない。
撮影: Widgetbook `lab_book` の既定状態(Driven Off)を全解像度で撮影。`research/shots/all/` に 65 枚(Phenomenon 30 + World 35。World C は large と inspector row の 2 枚ずつ)。
判定: YES / PARTLY / NO。「★きれいだが理由違い」= 結果ではなく仕組み(物理・信号・図解)を描いている物。
判定はスクショ + 各 use case のキャプション + ソース冒頭の操作説明(何を掴むと何が変わるか)に基づく。手での操作試験はしていない(見た目と操作の約束から判定)。

## 最も直感的な 10

1. PB3 Shadow and sun — 太陽を持って回すと影が逆へ伸びる。理由と手がそのまま一致
2. PB4 Depth of field — 写真カードの列でピント枠を滑らせると手前がボケる。結果そのもの
3. PD6 Camera shake — 手持ちファインダーを揺する = 手ぶれが欲しい
4. PC3 Warp — ゴムの格子を押すと膨らむ / 縮む
5. PE4 Echo: comet — 動く点が消えていく珠の尾を引く。尾の長さ・間隔・減衰が全部見える
6. PA3 Repeat — 複製を引き出し、末尾の空き枠を引くと増える
7. PE6 Scale: dough — 生地を横に引けば横に伸びる
8. PC4 Extrude — 六角の上面を引き上げると厚くなる
9. WD23 Trim paths — 線を端から手繰ると描き消える。AE の線描きそのもの
10. WC14 Glow — 明るさの水平線より上の粒だけが光る = 「明るい所だけ光らせたい」がそのまま見える

(次点: PB6 Mask feather、PE5 Spin、WA5 Along Path、PA5 Falloff、PD2 Spring)

## NO の項目(9)

- PA2 Stagger ★ — 扇に開いたトランプは「回転の分布」に見え、「時間差で順に出る」に見えない
- PB2 Refraction ray ★ — スネルの法則の光線図。「後ろが歪んで見える」が描かれていない
- PE1 Macro: mood ★ — 8 個のエフェクトを顔のパーツに割り当てたのは恣意的。「夢っぽい / 硬い見た目にしたい」が顔に読めない
- WB6 Audio react — 耳・ゲートの弧・珠。Driven Off では何も起きず、「キックに合わせて跳ねる」が見えない
- WC13 Gaussian Blur ★ — 絞り羽根の六角形がくっきり線で描かれ、何もボケていない
- WD19 Glass ★ — くさび形ガラスと光線(屈折の教科書図)。結果ではなく仕組み
- WD22 Fill — 色の値はピンクなのに塊が灰色に見え、「色を変えたい」の色がほぼ見えない。グラデーション角も見えない
- WE2 Spring ★ — ばね・ダッシュポット・重りの機構図、インクの軌跡は平ら。弾みが見えない(PD2 は同じ値で YES)
- WE4 Time remap ★ — 入力コマと出力コマを結ぶ糸の対応図。スローや逆再生に見えない(PD5 は同じ値で YES)

## 傾向(短く)

- **同じ値でも「結果を描いた版」が勝つ**: Spring(PD2 YES / WE2 NO)、Time remap(PD5 YES / WE4 NO)、Echo(PE4 YES / WC15 PARTLY)、Falloff(PA5 YES / WA1 PARTLY)、Glow threshold(WC14 YES / PB1 PARTLY)。
- **NO の多くは物理・機構・信号の図解**(屈折の光線図、絞り羽根、ばね-ダッシュポット、コマの対応、信号の波形)。きれいだが、理由ではなく値の中身に答えている。
- **時間系の値**(stagger、wiggle の周波数、audio)は静止画で負けやすい。既定(Driven Off)のままで結果が見える構図が要る。
