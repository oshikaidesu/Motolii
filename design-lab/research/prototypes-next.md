## 2. 試作ごとの受入(Y/N)

### 1. Look を試す
作る物: Browser の effect 一覧、Inspector の effect card、Stage。Q(結ぶ)・↑↓(候補)・Enter(確定)・Esc(戻す)。
1. layer 3 を選んで Q を押すと、Browser 上端に「→ Layer 3」と対象が 1 語で出る。
2. ↑↓ で候補を 5 つ進める間、Stage の layer 3 が候補ごとに変わり、undo の履歴は 1 行も増えない。
3. Esc で、結ぶ前の見た目と effect の並びに完全に戻る(photo で一致)。
4. Enter で 1 手の書込ができ、Cmd-Z 1 回で試す前に戻る。
5. 選択が無い時は Stage に重ねず、tile のサンプル表示だけになる(その旨が言葉で出る)。

### 2. 数値の一文法
作る物: 1 つの数値部品に scrub・入力・矢印・wheel・既定を載せる。複数の行で同じ規則を確かめる。
1. 右へ drag で必ず増え、Shift を押すと同じ距離で 10 倍、Alt を押すと 0.1 倍。
2. wheel を 1 目盛り回すと 1 表示単位変わる。ボタンを押さなくても効く。小さな値でも大きな値でも同じ量。
3. 矢印キーが drag・wheel と同じ規則(Shift で 10 倍)。
4. dbl-click で既定に戻り、その間に入力欄が一瞬も開かない。
5. 値 0.4 が 0 と表示されない、桁が欠けない(幅を 120px まで縮めて確認)。

### 3. 探す・絞る
1. `/` で検索欄に焦点が当たり、1 文字ごとに一覧が更新される。Esc 1 回で文字が消え、2 回目で欄を離れる。
2. 絞りを 3 つ重ねる(種類 + タグ + 星)と、結果帯が「3 件絞り中」と言い、Clear 1 回で全て消える。
3. `kind:video` と打つと chip になり、chip の x だけでその絞りが外れる。
4. 結果 0 件の時、理由と「全部に戻す」ボタンが出る(行き止まりで終わらない)。
5. Tab で、panel を開かずに検索メニューが出て、Enter で選択 layer に付く(Esc で何も起きない)。

### 4. 落とす
1. tile を押して動かすと ghost が付き、元の tile が淡くなる。
2. layer の上に来ると outline が出て「追加」と言う。Alt を押した瞬間に「置換」に変わる。
3. 離すと既定は追加。Alt 付きは置換で、bar と key が残る。
4. locked layer の上では「locked」と言い、受け付けない。
5. ドラッグ中に Esc を押すと、何も追加されない。

### 5. ease を選ぶ・測る
1. 2 つの key を選ぶと、ease の curve が plot に出る。
2. preset の上に pointer を置くと plot の中で curve が変わり、書込は起きない。離すと元に戻る。
3. 矢印で preset を進める間、Stage の動きが重なる。Esc で元の ease に戻る。
4. click で 1 手の書込。handle を drag している間は live、release で 1 手、Esc で mousedown 時に戻る。
5. 実際の動きで tile が選べる(I5-c)版では、1 周 1 秒で止まる tile が無い。

### 6. 空間値の三択
1. 同じ `Doc` の値を、Stage の box・panel の pad・掴んだ時の手の 3 通りで動かすと、全て同じ数値と同じ Stage の位置になる。
2. 3 通りとも Esc で drag 前に戻る。
3. panel を 120px まで縮めると、pad 版は数値行だけに落ち、数値が欠けない。
4. 「Stage を見ながら作る」場面と「Inspector だけで作る」場面の両方で、3 通りの手数を数えた表が作れる(1 動作の手数が出る)。

### 7. 掴んで結ぶ
1. 値の行から線を引き始めると、合う型の行だけが強調され、合わない行は反応しない。
2. 離した所に結べ、結んだ値の行に「← 相手」が出て、元の値は相手に従う。
3. 循環になる相手には線が付かず、理由が言葉で出る。
4. 結んだ関係を外すと、値は外す直前の見た目のまま残る。
5. 1 手で結んだ全員(lasso 版)を Cmd-Z 1 回で全員外せる。

### 8. 差分と戻す
1. 値を 3 つ変えると、その 3 行の label だけ濃くなり、他は薄い(photo)。
2. 「変えた物だけ」を ON にすると、残り行が畳まれ、「変更 3」と出る。
3. label の dbl-click で 1 行だけ既定に戻り、key はそのまま残る。
4. group の reset で全値が既定になっても、key と relation は残る。
5. reset が 1 手で undo できる。

### 9. 自分の物を棚へ・側面を運ぶ
1. effect card を Browser の「自分」へ drag すると保存でき、名前を直後に打てる。
2. 保存物は他の tile と同じ操作(dbl-click/drag)で使える。
3. ease だけを copy して別の 2 key の区間(3 組)へ paste すると、値と時間は変わらず ease だけ変わる。
4. 何を持っているか(clipboard)が常に 1 語で見える。
5. 同梱の物は上書きできない(言葉で理由が出る)。

### 10. 複数に一括・ずらし
1. 3 layer を選ぶと「3 layers」と言い、違う値は「混在」と出る。
2. Opacity を -10 scrub すると全員が 10 下がり(値の差は残る)、50 と打つと全員 50 になる。
3. locked layer が混じっていると、その layer だけ動かず、理由が出る。
4. 「ずらし」を 5 に設定すると、選択順に 5 ずつの差が付く。
5. 全体が Cmd-Z 1 回で戻る。
